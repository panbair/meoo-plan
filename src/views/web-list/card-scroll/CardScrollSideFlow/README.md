# CardScrollSideFlow — 中流砥柱 · 两侧上移

## 概念

用户竖滚时，中心主图静止于屏幕中央保持不动，两侧各三张小图从底部向上流动，形成"中流砥柱、两侧如瀑"的视觉冲击。

## 动画阶段

| 进度 | 阶段 |
|------|------|
| 0.00–0.18 | 舞台 + 标题逐个飞入 |
| 0.12–0.22 | 中心主图淡入放大，光晕亮起 |
| 0.20–0.55 | 左侧列上移（三张卡片视差交错淡入） |
| 0.25–0.60 | 右侧列上移（略晚于左侧，交错流动） |
| 0.55–0.75 | 中心光晕脉冲，背景光晕增强 |
| 0.75–0.90 | 两侧列继续上移淡出 |
| 0.85–1.00 | 标题淡出，舞台收暗 |

## ScrollTrigger

- `trigger: rootRef`
- `start: 'top 100%'`, `end: 'bottom 50%'`
- `scrub: 1.5`, `toggleActions: 'play reverse play reverse'`
