# CardScrollNestedReveal — 层层展开

## 概念

一线开天，层层递进。用户竖滚时，细线出现在屏幕中央，慢慢张开成矩形，同时一张图片随矩形展开至全屏；图片内部又出现新线，再次张开，层层揭晓新世界。

## 动画阶段

| 进度 | 效果 |
|------|------|
| 0.00–0.08 | 舞台 + 标题"深层揭秘"入场 |
| 0.08–0.10 | **横线** 亮起于屏幕中央 |
| 0.10–0.28 | 横线 **纵向张开** 成矩形，第 1 张图片随矩形展开至全屏 |
| 0.30–0.32 | **竖线** 亮起于屏幕中央 |
| 0.32–0.52 | 竖线 **横向张开** 成矩形，第 2 张图片展开覆盖第 1 张 |
| 0.55–0.57 | **横线** 再次亮起 |
| 0.57–0.77 | 横线 **纵向张开**，第 3 张图片展开覆盖第 2 张 |
| 0.80–1.00 | 标题淡出，舞台收暗 |

## 技术

- `clipPath: inset()` 控制每层张开的形状
- 横线 `/` 竖线交替方向制造节奏变化
- 发光线元素在闭合状态下可见，张开时快速扩大消失

## ScrollTrigger

`start: 'top 100%'` / `end: 'bottom 50%'` / `scrub: 1.5` / `toggleActions: 'play reverse play reverse'`
