# CardImageHoloPrism - 全息棱镜·RGB色散分离

## 效果描述

完整图片经棱镜折射后分离为RGB三色通道层，红绿蓝三层分别向不同方向偏移展示色散效果。棱镜体旋转入场，入射光束和彩虹出射光谱可视化。随滚动推进，三色通道逐步汇聚回合为完整图片。

## 技术实现

### 核心动画阶段

1. **完整图展示 + 棱镜入场** (0-15%)
   - 图片初始完整显示
   - 棱镜体从缩小旋转状态入场

2. **RGB色散分离** (15-45%)
   - 图片分离为R/G/B三色通道层
   - 各层向不同方向偏移
   - 入射光束动画

3. **彩虹光谱展示** (45-65%)
   - 出射端彩虹光谱可视化
   - 光线射散动画
   - 光斑闪烁效果

4. **三色汇聚归合** (65-100%)
   - R/G/B三层反向收缩归位
   - 棱镜退场
   - 汇聚光环 + 信息标签

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- CSS mix-blend-mode 色通道分离
- SCSS 样式
- 棱镜体3D变换

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 90%' | 元素顶部到达视口90%时开始 |
| end | 'bottom -80%' | 较长滚动距离 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- RGB三色通道分离与汇聚
- 棱镜体3D旋转入退场
- 入射光束 + 出射彩虹光谱
- 光线射散与光斑闪烁
- 汇聚光环效果
- 信息标签展示
