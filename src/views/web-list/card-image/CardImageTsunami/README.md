# CardImageTsunami - 海啸冲击·波浪卷携重组

## 效果描述

图片如被海啸巨浪卷携，碎片随波浪起伏翻卷。水浪从一侧涌入携带碎片，碎片在波峰波谷间翻滚。随滚动推进，海啸退潮，碎片随水流沉降归位，最终水面平静露出完整图片。

## 技术实现

### 核心动画阶段

1. **海啸涌入** (初始状态)
   - 碎片被巨浪卷起
   - 波浪起伏运动
   - 水色遮罩

2. **波浪翻卷** (前段)
   - 碎片随波峰波谷起伏
   - 旋转翻滚效果
   - 水花飞溅

3. **退潮归位** (滚动驱动)
   - 波浪逐步平息
   - 碎片随水流沉降归位
   - 水色遮罩消退

4. **水面平静** (末段)
   - 图片完全显现
   - 最后水波纹消散
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS 波浪动画

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 15%' | 元素顶部到达视口15%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 碎片波峰波谷翻滚
- 水花飞溅粒子
