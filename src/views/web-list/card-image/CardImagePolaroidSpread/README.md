# CardImagePolaroidSpread - 宝丽来散布相册

## 概述

一个温暖的宝丽来（拍立得）风格相册组件。12张照片卡片最初像真实的拍立得照片一样散落在桌面上，随着页面滚动，它们会漂浮到空中并优雅地排列成整齐的 4×3 画廊网格。

## 设计理念

- **复古温暖感**：暖色奶油纸背景，金色暗角，灰尘粒子营造老照片氛围
- **物理真实感**：每张卡片独立旋转、缩放和位置，模拟真实照片散落
- **图钉细节**：每张卡片顶部有一颗金属图钉，增加生活质感
- **手写风格**：底部倾斜字体和等宽日期标注，复刻经典宝丽来

## 技术实现

- **GSAP ScrollTrigger** — 滚动驱动散落→排列过渡（scrub: 1.5）
- **easeOut 缓动** — 使用 `1 - (1-t)^3` 让卡片排列时有自然的减速感
- **Canvas 粒子** — 60个漂浮的暖色灰尘粒子增强氛围
- **双位置系统** — 每张卡片预设散落坐标和网格目标坐标，线性插值

## 特效细节

| 特效 | 说明 |
|------|------|
| 散落状态 | 卡片随机分布、旋转、缩放 0.55~0.85、轻微模糊+暗色 |
| 排列过程 | 平滑过渡到 4×3 网格，卡片变清晰、变亮、旋转收拢 |
| 图钉 | 顶部随机角度金属图钉，增加真实感 |
| 暗角 | 随排列进程逐渐变淡 |
| 文字入场 | 标题/分割线/副标题分别模糊渐入 |
| 进度条 | 底部金色进度条 + SCATTERED/ARRANGED 状态文字 |
