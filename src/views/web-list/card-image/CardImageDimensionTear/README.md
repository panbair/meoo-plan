# CardImageDimensionTear 维度撕裂

> 图片从中心被撕裂成多层维度空间，每层独立3D视差翻转 — 超越碎裂重组的全新视觉范式

## 核心效果

### 🌀 超越 CardImageShatterRebuild 的创新点
- **不是碎片化，而是维度化**：图片不是简单碎裂，而是被撕裂成5层独立维度空间
- **每层独立3D翻转**：各维度层有独立的 rotateX/Y/Z + 视差速度
- **clip-path 动态撕裂线**：使用可动画的 polygon clip-path 模拟撕裂效果
- **维度间隙发光**：撕裂缝隙中有能量光线流动
- **重力坍缩归位**：最终各层被引力牵引合并，缝隙闭合

### 动画阶段

| 阶段 | 滚动范围 | 效果 |
|------|---------|------|
| 完整展示 | 0-20% | 图片完整显示，微光呼吸 |
| 维度裂开 | 20-50% | 图片沿不规则线条撕裂成5层，各层3D偏移 |
| 独立视差 | 50-70% | 各维度层独立运动，展示"多宇宙"效果 |
| 引力坍缩 | 70-100% | 各层被引力牵引回位，缝隙闭合，画面复原 |

## 技术实现

| 技术 | 说明 |
|------|------|
| Vue 3 Composition API | 响应式组件架构 |
| GSAP ScrollTrigger | 滚动驱动4阶段时间线 |
| CSS clip-path polygon | 动态撕裂线裁剪 |
| CSS 3D Transforms | 每层独立 perspective + rotate |
| CSS Hue-rotate | 各层独立色相偏移营造维度差异 |
