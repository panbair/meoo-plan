# CardImagePulseWave — 脉冲波浪

## 概述

图片如心跳般脉冲律动。随着用户滚动，图片从中心向外扩张脉冲，能量环层层扩散，如同声波或心跳的视觉化呈现。画面在脉冲中模糊→清晰→模糊过渡，充满生命力。

## 核心动画

### 入场动画
- 标题四字从中心弹入（`scale: 0.2→1`, `back.out(2.4)`）
- 心跳指示器从无到有（缩放+旋转入场）

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 动画 | 描述 |
|------|------|------|
| **Phase A — 脉冲扩散入场** (0→0.38) | `scale: 0.55→1`, `blur: 16→0` | 图片从中心向外脉冲扩散至完整大小 |
| **Phase B — 三波脉动** (0.38→0.62) | `scale: 1→1.06→1.02→1.05→1.01→1.03→1` | 三波递减脉冲 + 能量环三层扩散收缩 |
| **Phase C — 收缩退场** (0.62→0.8) | `scale: 1→0.5`, `blur↑`, 能量环收缩至消失 | 图片向内收缩脉冲退场 |
| **Phase D — 下一帧入场** (0.73→) | 同 Phase A | 新图片脉冲扩散入场 |

### 辅助动画
- Canvas 波纹涟漪：从中心向外扩散的同心圆波纹
- 心跳指示器：4层光环 + 核心亮点，随帧脉动
- 背景脉冲光晕：不透明度随脉冲波动
- 能量环：每帧图片上覆盖的环形能量场

- Vue 3 Composition API + `<script setup lang="ts">`
- GSAP ScrollTrigger（`scrub: 1.3`）
- Canvas 2D 波纹涟漪系统
- 多层脉冲叠加（img scale + energy ring scale + heartbeat indicator）
- 完整 `onUnmounted` 清理
