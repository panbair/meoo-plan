## CardImageMirrorSplit — 镜像维度分裂

### 概念

画面沿对角线一分为二。左上三角显示"白天的繁华都市"，右下三角显示"夜晚的赛博世界"。滚动时分裂线从左上角平滑移动到右下角，两侧有完全不同的色彩滤镜和粒子效果。分裂线上有能量裂隙锯齿发光效果。

### 七层架构

| 层级 | 内容 | 核心技术 | z-index |
|------|------|----------|---------|
| Layer 1 | 图片A (白天都市) — 左上半三角 | `clip-path: polygon(0 0, split% 0, 0 split%)` + `saturate(0.82) brightness(1.08)` | 1 |
| Layer 2 | 图片B (赛博夜晚) — 右下半区域 | `clip-path: polygon(100% 100%, 100% 0, split% 0, 0 split%, 0 100%)` + `hue-rotate(120deg) contrast(1.35)` | 2 |
| Layer 3 | SVG 分裂线 (锯齿路径 + 多层发光) | 28 段 jitter 锯齿 + 3 级 feGaussianBlur + feMerge 叠加 | 3 |
| Layer 4 | 左侧冷色调粒子 (蓝/冰色) | Canvas `clip-path` 限制在左上半三角，60 个蓝调漂移粒子 | 5 |
| Layer 5 | 右侧暖色调粒子 (橙/红色) | Canvas `clip-path` 限制在右下半区域，60 个暖调漂移粒子 | 5 |
| Layer 6 | 能量溢出光晕带 | 沿对角线 `rotate(-45deg)` 定位的 `linear-gradient` + `blur(16px)` 条带 | 4 |
| Layer 7 | 世界标签 | 左上 "REALITY / real world" + 右下 "DIGITAL / cyber space" | 10 |

### 分裂线移动

```
split ∈ [8, 92] 随滚动进度 p 变化
splitEase(p):
  p < 0.4 → (p/0.4)² × 0.3       前段慢加速 (0→0.3)
  p ≥ 0.4 → 0.3 + (1-(1-p')²·⁸)×0.7  后段强力加速 (0.3→1)
```

分裂线从左上 (split=8%, 微小三角) 平滑移向右下 (split=92%, 占据绝大部分画面)。

### 双滤镜对比

| 属性 | 左侧 (REALITY) | 右侧 (DIGITAL) |
|------|---------------|----------------|
| saturate | 0.82 | — |
| brightness | 1.08 | 0.9 |
| hue-rotate | — | 120deg |
| contrast | — | 1.35 |

### 技术实现

| 技术 | 具体实现 |
|------|----------|
| **对角分割** | 左上半三角形 + 右下半多边形（含右侧/底部边界点），两多边形恰好覆盖全画面 |
| **SVG 锯齿线** | 28 段确定性伪随机 jitter，幅度随 split 动态调整（0.3-3.5 px 等效） |
| **三层发光** | feGaussianBlur(4/12/24px) → feMerge 叠加 → 主路径 + 外层彩色光晕 |
| **双 Canvas 粒子** | 两个独立 Canvas 分别被各自 clip-path 裁剪，60+60 个独立色调粒子 |
| **粒子色调** | 左侧 `hue: 190-220` (冰蓝) + 右侧 `hue: 25-50` (橙暖) |
| **能量光晕带** | 绝对定位 div → `rotate(-45deg)` 对齐对角线 → 中心渐变 + blur |
| **标签渐显** | 当 split > 20 时左标签渐显，当 split < 72 时右标签渐显 |
| **图片资源** | 白天都市 (`1494522855154`) + 赛博夜景 (`1563089145`) |
