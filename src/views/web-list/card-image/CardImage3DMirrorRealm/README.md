# CardImage3DMirrorRealm — CSS3 3D 镜像翻转 · 视错觉倒影

## 概述

利用 `scaleY(-1)` + 同步反向 3D 变换 + `opacity` 渐变遮罩，制造极其逼真的镜面倒影视错觉。5 个物体悬浮在镜面地平面之上，每个物体的倒影精确同步其 3D 旋转——但方向相反——完美模拟真实镜面反射。

## 核心技术：scaleY(-1) + 反向3D变换

### 倒影三要素

```
主体 (地面以上)
  rotateY: +25°        ← 向右旋转
  rotateX: -8°         ← 微仰
  translateZ: +30px    ← 向前

═══════════════════════ 镜面地平面 ═══════════════════════

倒影 (地面以下)
  rotateY: -25°        ← 🔑 取反! (镜面反射)
  rotateX: +8°         ← 🔑 取反!
  translateZ: -30px    ← 🔑 取反!
  transform: scaleY(-1) ← 🔑 Y轴翻转
  opacity: 渐变衰减     ← 🔑 越远越淡
```

### 倒影材质层次

```
┌──────────────────────────────┐
│  .mr-reflection__fade        │ ← 🔑 透明度渐变遮罩
│  linear-gradient(180deg,     │   靠近镜面: rgba(0,0,0,.05)
│    transparent → black)      │   远离镜面: rgba(0,0,0,.95)
│  模拟镜面反射的衰减           │   完全融入背景
├──────────────────────────────┤
│  .mr-reflection__img         │ ← 与主体相同的图片
│  filter: brightness(0.6)     │   暗化处理 (反射光弱于入射光)
│  + saturate(0.8)             │   降低饱和度
├──────────────────────────────┤
│  transform: scaleY(-1)       │ ← 🔑 Y轴翻转 制造倒影
│  z-index: 2 (在主体下方)     │
└──────────────────────────────┘
```

## 5物体空间布局

物体在 3D 空间中分布在不同 Y 位置和 Z 深度：

```
        (俯视)
  Z:-150  Z:-60   Z:+40   Z:+130  Z:+200
   ○       ○       ○       ○       ○    ← 5个物体
  Y:-28   Y:-12   Y:+5    Y:+20   Y:+30

  ───────────────────────────────────── 镜面地平面

   ▽       ▽       ▽       ▽       ▽    ← 5个倒影
  scaleY(-1) 各方向反向旋转
```

## 动画：5阶段视角变化

| 阶段 | 场景旋转 | 效果 | 倒影表现 |
|------|---------|------|---------|
| 0→1 | Y:+15° X:+5° | 右倾侧视 | 倒影向左拉长 |
| 1→2 | Y:-5° X:-10° | 仰视角度 | 倒影压缩变形 |
| 2→3 | Y:-18° X:+2° | 左倾观察 | 倒影与主体交错 |
| 3→4 | Y:+5° X:+12° | 俯视角度 | 倒影极度压缩 |
| 4→5 | Y:0° X:0° | 回归正面 | 完美对称倒影 |

### 每阶段主体/倒影同步反转

```
主体 rotateY → +25°    倒影 rotateY → -25°   (取反)
主体 rotateX → -8°     倒影 rotateX → +8°    (取反)
主体 translateZ → +30  倒影 translateZ → -30  (取反)
```

## 镜面地平面

```
一条 1px 渐变发光横线 (top: 52vh)
  作为视觉分隔：
  · 上方 → 主体空间 (暗色)
  · 下方 → 倒影空间 (极暗 → 纯黑)
  · 光晕 → 模拟镜面边缘的微光
```

## 技术要点

- 🔑 `scaleY(-1)` Y轴翻转是倒影的基础
- 🔑 主体/倒影 3D 变换全部取反：`rotateY` → `-rotateY`，`rotateX` → `-rotateX`，`translateZ` → `-translateZ`
- 🔑 `linear-gradient` 透明度渐变从半透明到完全不透明，模拟反射衰减
- 🔑 倒影图片 `filter: brightness(0.6) saturate(0.8)` — 反射光弱于入射光
- 🔑 `z-index` 层级：主体(10) > 倒影(2)
- 🔑 镜面地平面线 (1px 渐变发光) 作为视觉锚点
- GSAP ScrollTrigger scrub: 1.4 驱动视角变化
- 场景 `rotateX`/`rotateY` 变化 → 所有物体+倒影同步响应
