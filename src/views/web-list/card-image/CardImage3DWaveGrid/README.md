# CardImage3DWaveGrid — CSS3 3D 卡片矩阵波动

## 概述

纯 CSS3 3D 构建的 4×5 卡片矩阵，每张卡片在 Z 轴上独立起伏，形成从第一行向后传播的正弦波浪。用户竖滚驱动波浪逐行推进，同时矩阵整体倾斜形成强力透视纵深。每张卡片底部有地面投影阴影，强化 "悬浮高度" 的视觉感知。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 700px | 3D透视距离 |
| `transform-style` | `preserve-3d` | 保持每个卡片和网格的3D空间 |
| `transform: rotateX(45deg)` | 网格初始 | 倾斜矩阵形成俯视透视 |
| `translateZ(n)` | 0→80px 波动 | 每张卡片独立Z轴起伏 |
| `rotateX/Y` | ±4-8° 微调 | 卡片起伏时自然倾斜 |

## 动画流程

| 滚动进度 | 波动阶段 | 效果 |
|---------|---------|------|
| 阶段1 | 波峰升起 | 卡片按 (row×0.25 + col×0.12) 相位依次升到Z=56px |
| 阶段2 | 峰值弹跳 | 短暂反弹到 Z=80px 后开始回落 |
| 阶段3 | 第一波回落 | 卡片逐渐降至 Z=15px |
| 阶段4 | 第二波小浪 | 较小的二次波动 Z=32px |
| 阶段5 | 恢复平展 | 全部卡片回到 Z=0 |

## 矩阵规格

| 参数 | 值 |
|------|-----|
| 列数 | 4 |
| 行数 | 5 |
| 总卡片数 | 20 |
| 卡片尺寸 | min(20vw, 170px) × min(16vw, 135px) |
| Z轴波幅 | 80px |

## 特色元素

- **正弦波传播**：每张卡片有独特的相位延迟，形成自然的波浪推进
- **地面投影**：每张卡片底部有 radial-gradient 椭圆阴影，随Z轴高度动态变化
- **波动仪表**：底部实时显示当前波动强度的仪表条
- **卡片交互**：hover 时卡片亮度提升，诱惑点击

## 技术要点

- 纯 CSS3 3D，Grid 布局 + transform-style: preserve-3d
- GSAP ScrollTrigger 驱动波浪传播（`scrub: 1.5`）
- 每行一种 Unsplash 主题图片（海/山/森/星/花）
- 20 张卡片独立动画时间线
- 入场动画：卡片从 rotateX(90deg) 翻转弹入
