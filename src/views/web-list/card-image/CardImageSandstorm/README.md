# CardImageSandstorm - 沙暴侵蚀·风化重塑

## 效果描述

图片被猛烈沙暴侵蚀，表面覆盖沙尘粒子。碎片如被风化剥离的岩层，随沙暴方向飘散。随滚动推进，沙暴逐渐平息，沙尘粒子沉降，碎片从风化状态回收归位，露出完整图片。

## 技术实现

### 核心动画阶段

1. **沙暴肆虐** (初始状态)
   - 沙尘粒子从侧面横向飞扬
   - 碎片被风化偏移
   - 黄褐色沙尘遮罩

2. **沙暴减弱** (滚动驱动)
   - 风力逐步减弱
   - 粒子密度降低
   - 碎片偏移恢复

3. **沙尘沉降** (中后段)
   - 粒子向下沉降
   - 遮罩透明度降低

4. **风化恢复** (末段)
   - 碎片完全归位
   - 沙尘消散
   - 清晰图片显现

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- 沙尘粒子系统

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 35%' | 元素顶部到达视口35%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 横向沙暴粒子飘飞
- 碎片风化偏移
- 黄褐色沙尘遮罩
- 沙暴平息沉降
- 风化到清晰渐变
