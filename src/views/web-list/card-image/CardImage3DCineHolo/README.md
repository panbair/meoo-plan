# CardImage3DCineHolo — 电影级光影 · 全息锻造 (双模融合)

## 概述

将 **金属质感 (filter 动态光照)** 与 **全息投影 (mix-blend-mode: screen)** 融合到同一个 3D 元素中。6张面板组成3D晶体结构，随滚动旋转。每张面板根据其与虚拟光源的角度，在"金属反射模式"和"全息投影模式"之间平滑切换——面对光源时呈现金属光泽，背离光源时转化为全息幻象。

## 核心创新：双模切换

### 同一面板的两种视觉身份

```
面板法线 vs 光源方向

  面对光源 (angleDiff≈0°)         背离光源 (angleDiff≈90°+)
  ┌─────────────────────┐        ┌─────────────────────┐
  │  ◆ 金属反射模式      │        │  ◈ 全息投影模式      │
  │                     │        │                     │
  │ brightness: 1.35    │   ←→   │ brightness: 0.3     │
  │ contrast: 1.15      │        │ contrast: 0.75      │
  │ drop-shadow: 33px   │        │ drop-shadow: 3px    │
  │ 金属层 opacity: 1.0 │        │ 金属层 opacity: 0.3  │
  │ 镜面高光: 强        │        │ 镜面高光: 无        │
  │                     │        │                     │
  │ 全息层 opacity: 0   │        │ 全息层 opacity: 0.85│
  │ 全息边框: 微弱       │        │ 全息边框: 强烈发光   │
  │                     │        │ screen blend: 激活  │
  └─────────────────────┘        └─────────────────────┘
```

### 双模权重计算

```typescript
lightFactor = cos(angleDiff)              // 0(背离) ~ 1(面对)
metalWeight = lightFactor^2.5             // 陡峭曲线，快速切换
holoWeight  = 1 - metalWeight             // 互补关系
```

## 面板材质层次

每张面板由3个独立的视觉层叠加：

```
┌────────────────────────────────────┐
│  全息边框 (holo-edge)     Z:1      │ ← box-shadow 青/品红发光
│  opacity 随 holoWeight 变化        │
├────────────────────────────────────┤
│  全息投影层 (holo)        Z:5      │ ← mix-blend-mode: screen
│  · cyan色散层 (screen混合)         │   在黑色背景上发光
│  · magenta色散层 (screen混合)      │   CSS animation 色相偏移
│  · 扫描线 (multiply混合)           │   opacity 随 holoWeight 变化
├────────────────────────────────────┤
│  金属质感层 (metal)       Z:2      │ ← filter: brightness/contrast/
│  · 原始图片                        │    drop-shadow 动态响应
│  · 金属拉丝纹理 (overlay混合)      │   opacity 随 metalWeight 变化
│  · 镜面高光 (soft-light混合)      │
└────────────────────────────────────┘
```

## 技术要点

- 🔑 双模融合：同一面板同时拥有金属层(overlay混合)和全息层(screen混合)，通过 opacity 动态切换
- 🔑 陡峭权重曲线 `lightFactor^2.5` 确保模式切换干脆利落，避免中间灰态
- 🔑 金属层 filter (brightness + contrast + drop-shadow) + 全息层 filter (hue-rotate) 独立控制
- 🔑 镜面高光 radial-gradient 随光照权重动态偏移
- 🔑 全息边框 box-shadow 双色（青/品红）随全息权重动态增强
- 色散层 CSS animation hue-rotate 持续循环
- GSAP onUpdate 每帧计算6面板的光照角度 → 实时更新双模权重
- 扫描线使用 GSAP 关键帧循环扫描
- 鼠标视差微调晶体倾斜
