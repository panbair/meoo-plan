# CardImageDNAHelix - DNA双螺旋·碱基对重组

## 效果描述

图片被切割为24个碎片节点，沿DNA双螺旋结构排列。碎片分为两条链（strand），如碱基对一样交错螺旋分布。随滚动推进，碎片从螺旋轨道收缩归位，伴随SVG骨架连线动画，最终拼合成完整图片。

## 技术实现

### 核心动画阶段

1. **DNA螺旋展开** (初始状态)
   - 24个碎片沿双螺旋路径分布
   - 两条链(strand)交替排列
   - 螺旋相位差π，形成双链结构

2. **SVG骨架连线**
   - 双螺旋骨架线条动画
   - 碱基对连接线

3. **螺旋收缩归位** (滚动驱动)
   - 碎片从螺旋位置向原始网格位置收缩
   - 旋转和缩放逐步恢复

4. **闪光完成** (末段)
   - 白色闪光确认重组完成

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SVG 骨架线条
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 45%' | 元素顶部到达视口45%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 24节点DNA双螺旋排列
- 双链碱基对交错结构
- SVG骨架连线动画
- 蓝/紫双色（strand区分）
- 螺旋收缩归位效果
