# CardImage3DMirrorFloor — CSS3 3D 镜面地板

## 概述

纯 CSS3 3D 构建的镜面地板画廊——图片如实体画框般矗立在3D空间中，下方产生真实透视的倒影反射。5个展示架在Z轴上等距排列（从远到近），用户竖滚驱动相机沿Z轴前进，依次经过每个展示架。地板平面用 `rotateX(82deg)` 铺设，多层透视线强化纵深。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 800px | 3D透视距离 |
| `perspective-origin` | 50% 30% | 视角偏高，看到更多地板 |
| `transform-style` | `preserve-3d` | 保持展示架的3D空间 |
| `rotateX(82deg)` | 地板平面 | 铺设纵深地面 |
| `translateZ(-300→300)` | 展示架 | Z轴等距排列 |
| `scaleY(-1)` | 倒影图片 | 🔑 垂直翻转形成镜像 |
| `mask-image: linear-gradient` | 倒影容器 | 渐变淡出模拟反射衰减 |

## 倒影实现原理

```
原图片 (正常方向)
  │
  │  ← 地面接触线
  ▼
倒影 (scaleY(-1) + 渐变mask淡出)
```

1. `transform: scaleY(-1)` — 垂直翻转图片
2. `mask-image: linear-gradient(180deg, rgba(0,0,0,.7) 0%, transparent 100%)` — 越远越淡
3. 倒影 `opacity: 0.35` — 整体半透明
4. `filter: blur(0.5px)` — 微模糊模拟真实反射
5. 叠加渐暗层 — 模拟深色地板的吸光

## 动画流程

| 滚动进度 | 相机位置 | 聚焦展示架 |
|---------|---------|-----------|
| 0→1 | 最远处 | 黎明 (z=-300) |
| 1→2 | 前进 | 远山 (z=-150) |
| 2→3 | 中间 | 星辰 (z=0) |
| 3→4 | 继续 | 密林 (z=150) |
| 4→5 | 最近处 | 繁花 (z=300) |

## 场景元素

| 元素 | 说明 |
|------|------|
| 地板平面 | rotateX(82deg) 深蓝灰色调，有微光 |
| 透视线 | 6条水平线增强纵深透视 |
| 聚光灯 | 随滚动扫过的柔光 |
| 展示架 | 5个画框在Z轴等距排列 |
| 倒影 | scaleY(-1) + mask渐变 |
| 接触光斑 | 画框与地面接触点的发光 |

## 技术要点

- 纯 CSS3 3D，无 3D 库
- GSAP ScrollTrigger 驱动相机Z轴前进（`scrub: 1.5`）
- scaleY(-1) + CSS mask 实现真实反射倒影
- 大气透视：远处展示架 scale 缩小 + opacity 降低
- 地板透视线随滚动位移增强动态感
- 地面接触点光斑强化 "物体站在地板上" 的实感
