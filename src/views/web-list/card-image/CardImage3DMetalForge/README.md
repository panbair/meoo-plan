# CardImage3DMetalForge — CSS3 3D 金属锻造质感 · 动态光影

## 概述

突破纯几何变换的局限，结合 CSS `filter` 高级特性模拟真实的金属物理质感。6张金属卡片排列在3D旋转环上，每张卡片根据其与虚拟光源的角度差，动态调整 `brightness`（亮度）、`contrast`（对比度）、`drop-shadow`（高光阴影）等 filter 参数，模拟金属表面与光源的真实交互。

## 核心技术：动态光照响应

### 光源模型
- 虚拟点光源固定在场景左前方约 30° 位置
- 3D 金属环随滚动旋转（0° → 360°）
- 实时计算每张卡片法线与光源方向的角度差
- 角度差 → 光照响应因子 → 动态 filter 参数

### Filter 动态计算（每帧更新）

| 角度差 | 光照因子 | brightness | contrast | drop-shadow |
|--------|---------|------------|----------|-------------|
| 0° (面对光源) | 1.0 | 1.3 | 1.2 | 32px 金色强光 |
| 45° | 0.7 | 1.0 | 1.1 | 18px 暖色中光 |
| 90° (侧对光源) | 0.0 | 0.35 | 0.85 | 4px 微弱暗光 |
| 135° | 0.0 | 0.35 | 0.85 | 4px + 环境遮蔽阴影 |
| 180° (背离光源) | 0.0 | 0.35 | 0.85 | 双重阴影(AO) |

### 金属材质层次

```
┌─────────────────────────────────┐
│  镜面高光层 (specular)          │ ← radial-gradient, GSAP动态位移
│  mix-blend-mode: soft-light     │
├─────────────────────────────────┤
│  金属拉丝叠加 (metal overlay)    │ ← linear-gradient 多层叠加
│  mix-blend-mode: overlay        │
├─────────────────────────────────┤
│  图片层 (img)                   │ ← 原始图片
├─────────────────────────────────┤
│  边缘光泽 (rim light)           │ ← inset box-shadow 菲涅尔模拟
├─────────────────────────────────┤
│  filter 动态层                  │ ← brightness + contrast + saturate
│                                 │   + drop-shadow (GSAP每帧更新)
├─────────────────────────────────┤
│  环境光遮蔽 (AO shadow)          │ ← 底层模糊阴影
└─────────────────────────────────┘
```

## 动画流程

| 滚动阶段 | 金属环旋转 | 面对光源的卡片 | 效果 |
|---------|-----------|--------------|------|
| Stage 0→1 | 0°→60° | 卡片0(黄金) | 黄金高亮，镜面高光左移 |
| Stage 1→2 | 60°→120° | 卡片1(紫铜) | 铜色闪耀，暖调增强 |
| Stage 2→3 | 120°→180° | 卡片2(白银) | 银白冷光，高对比 |
| Stage 3→4 | 180°→240° | 卡片3(青铜) | 青铜沉稳，低亮度 |
| Stage 4→5 | 240°→300° | 卡片4(玫瑰金) | 玫瑰金色，柔和粉金光 |
| Stage 5→6 | 300°→360° | 卡片5(铂金) | 铂金极亮，近乎白色高光 |

## 技术要点

- GSAP ScrollTrigger `onUpdate` 中每帧计算6张卡片的 filter 参数
- 使用三角函数 `cos(angleDiff)` 计算光照响应曲线
- 镜面高光使用 `radial-gradient` + GSAP 动态偏移位置和透明度
- 金属拉丝纹理用多层 `linear-gradient` + `mix-blend-mode: overlay`
- 菲涅尔边缘光用 `inset box-shadow`
- 环境光遮蔽用底层模糊阴影 + 背离光源时的额外 drop-shadow
- `mix-blend-mode: soft-light` 镜面高光层
- `mix-blend-mode: overlay` 金属拉丝层
