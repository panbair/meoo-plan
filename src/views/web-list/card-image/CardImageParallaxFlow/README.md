# CardImageParallaxFlow — 视差流动

## 概述

三层深度视差效果——每张图片被分为远景、中景、近景三个图层，以不同的速度响应滚动。用户竖滚时，近景移动最快（1.8x）、中景正常（1.0x）、远景最慢（0.4x），创造出强烈的3D深度感，如同透过窗户观看立体世界。

## 核心动画

### 入场动画
- 标题四字带深度感入场（近/中/远三种层级颜色）
- 景深指示器从右侧滑入（显示"近·中·远"）

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 远景 (bg) | 中景 (mid) | 近景 (fg) |
|------|----------|-----------|----------|
| **Phase A — 视差入场** (0→0.45) | y: 40→0, blur 10→6, 速度 0.4x | y: 65→0, blur 16→0, 速度 1.0x | y: 90→0, blur 8→0, 速度 1.8x |
| **Phase B — 驻留** (0.45→0.62) | blur 4⇄6 微呼吸 | scale 1.0⇄1.02 | y -4⇄0, opacity 0.55⇄0.6 |
| **Phase C — 视差退场** (0.62→0.82) | y: 0→45 (慢) | y: 0→70 | y: 0→100 (快) |
| **Phase D — 下一帧入场** | 同 Phase A | 同 Phase A | 同 Phase A |

### 三层视觉参数

| 层级 | z-index | scale | 默认 blur | 移动速度 | clipPath | opacity |
|------|---------|-------|----------|---------|----------|---------|
| 近景 | 3 | 1.35 | 0px | 1.8x | `inset(8% 5% 55% 5%)` | 0.55 |
| 中景 | 1 | 1.0 | 0px | 1.0x | 无 | 1.0 |
| 远景 | 0 | 0.72 | 6px | 0.4x | 无 | 1.0 |

### 辅助动画
- Canvas 深度粒子：粒子按近/中/远三层分别以不同速度、大小、模糊度移动
- 景深指示器：每帧脉冲
- 深度光斑：3个光斑以不同速度漂移

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 暖桃 / 珊瑚金 / 琥珀 / 天蓝 |
| 标题字色 | 近=深橙 / 中=暖金 / 远=淡灰（呼应景深主题） |
| 氛围 | 深度、立体、身临其境 |

## 技术要点

- 三层同步图片以不同 scale 实现视差（前景 1.35x / 中景 1.0x / 远景 0.72x）
- 三层以不同 y 速度移动（1.8x / 1.0x / 0.4x）
- 不同 blur 值营造景深虚化效果
- Canvas 粒子也按深度分层渲染
- `scrub: 1.4`
