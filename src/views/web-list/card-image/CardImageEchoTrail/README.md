## CardImageEchoTrail — 时光残影回声

### 概念

同一场景的 5 层图片副本叠加，每层有递增的**时间偏移**、**位移模糊**和**透明度衰减**。滚动时基准帧保持清晰，影子层依次向不同方向漂移、变淡、变模糊，像长时间曝光摄影中移动物体留下的残影。运动方向随滚动持续旋转 270°，结尾快门暗角快速闪烁。

### 七层架构

| 层级 | 内容 | 偏移 | 透明度 | 模糊 | z-index |
|------|------|------|--------|------|---------|
| Layer 1 | 基准帧 (最高清, 始终不透明) | 0 | 1.0 | 0 | 5 |
| Layer 2 | 残影 1 | max 18px | 0→55% | 0→1.5px | 4 |
| Layer 3 | 残影 2 | max 38px | 0→35% | 0→3.5px | 3 |
| Layer 4 | 残影 3 | max 62px | 0→20% | 0→6.0px | 2 |
| Layer 5 | 残影 4 | max 90px | 0→10% | 0→10px | 1 |
| Layer 6 | 方向轨迹 Canvas | — | — | — | 6 |
| Layer 7 | 快门暗角 | — | 闪烁 0↔0.7 | — | 8 |

### Boomerang 发散曲线

```
echoSpread(t):  t ∈ [0, 1],  输出 ∈ [0, 1, 0]

  t < 0.55  →  smoothstep(t/0.55)        // 0 → 1 (发散)
  t ≥ 0.55  →  smoothstep((1-t)/0.45)   // 1 → 0 (收敛)

峰值在 t=0.55 (略微偏后, 留给快门闪效果区间)

运动方向: angle = p × 270° (滚动从 0°→270° 旋转)
```

### 残影配置表

| 残影层 | maxOffset | baseOpacity | blurBase | 视觉角色 |
|--------|-----------|-------------|----------|----------|
| Echo 1 | 18px | 0.55 | 1.5px | 最近残影，半清晰 |
| Echo 2 | 38px | 0.35 | 3.5px | 中等距离，轮廓模糊 |
| Echo 3 | 62px | 0.20 | 6.0px | 远距残影，明显虚化 |
| Echo 4 | 90px | 0.10 | 10px | 最远残影，几乎消融 |

### 关键技术

| 技术 | 具体实现 |
|------|----------|
| **background:inherit** | 5 层全部使用 `background:inherit` 共享舞台图，无需重复 URL 加载 |
| **boomerang 曲线** | `echoSpread(t)` 在 t=0.55 峰值，前后对称 smoothstep |
| **方向旋转** | 角度 `p × 1.5π` (0°→270°)，`Math.cos/sin` 分解为 XY 偏移 |
| **分层模糊** | `filter: blur()` 与 spread 线性正比，4 层递增 blurBase |
| **轨迹 Canvas** | spread>8% 时沿运动方向生成 100 上限轨迹点，life 衰减绘制 |
| **快门效果** | p∈[0.85,0.95] 区间 4 次 50/50 闪烁，`radial-gradient` 暗角 0↔0.7 切换 |
| **收敛重置** | `onLeaveBack` 将所有残影 `translate3d(0,0,0)` + `opacity=0` + `blur(0)` |
