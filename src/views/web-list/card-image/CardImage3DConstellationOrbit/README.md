# CardImage3DConstellationOrbit — 星座轨道画廊

## 概述
12张照片分布在3层同心轨道上，每层轨道以不同速度旋转。近景轨道最快、远景最慢，形成壮丽的差速轨道视差。照片悬浮在深空星野中，底部投射光柱代替传统倒影，中央光核脉动如恒星。

## 核心动画
```
3层轨道环(近/中/远) 差速旋转 →
近景(1.0x速, r=380px) : 4张照片 ⚡快速穿行
中景(0.55x速, r=620px) : 4张照片 🌀中速旋转
远景(0.28x速, r=880px) : 4张照片 🌌缓慢漂移
→ 中央光核脉动呼吸 + 粒子场漂浮
```

## 空间分布（与原版 CardImage3DGalleryFloor 对比）

| 维度 | GalleryFloor (原版) | ConstellationOrbit (新版) |
|------|-------------------|--------------------------|
| 空间拓扑 | 线性Z轴走廊 | 3层同心环形轨道 |
| X轴 | 固定左右交替 | 环形连续分布（0°-315°） |
| Y轴 | 无变化（地面高度） | 每张不同高度（-110~+100px） |
| 深度编码 | 亮度+透明度线性衰减 | 轨道半径+缩放+旋转速度 |
| 倒影 | 镜面地板scaleY(-1) | 底部光柱投射（星空光瀑） |
| 滚动驱动 | 整体translateZ推进 | 各轨道独立rotateY差速旋转 |
| 空间感来源 | 走廊透视 | 多层轨道视差+缩放 |

## 视觉元素
- 深空星野背景（3层星星视差 + 3片星云色块 + 银河平面辉光）
- 中央脉动光核（类恒星效果）
- 轨道环装饰线（旋转椭圆投影）
- 照片卡：白色半透明边框 + 彩色光晕 + 底部光柱
- 60个CSS动画浮动粒子
- 暗角 + 深度雾

## 技术要点
- CSS 3D环形布局：`rotateY(θ) translateZ(r) rotateY(-θ)` 标准模式
- 3层独立的GSAP rotateY动画，各层不同时长（差速旋转）
- ScrollTrigger scrub: 1.5（比原版更平滑，匹配旋转运动）
- 每张照片单独Y偏移 + 光晕颜色配置
- 光柱使用线性渐变 + rotateX(40deg) 投射效果
- 粒子系统使用CSS animation + randomized delay（零JS开销）
- 响应式：移动端缩小卡片+隐藏轨道线
