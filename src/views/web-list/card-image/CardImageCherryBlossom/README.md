# CardImageCherryBlossom - 樱花飘落·花瓣碎片归位

## 效果描述

图片被切割为6×5花瓣形碎片，碎片如樱花花瓣般从上方飘落飞舞，伴随左右摇曳和旋转。随滚动推进，花瓣碎片缓缓飘落归位，拼合成完整图片。装饰粒子和柔光营造春日氛围。

## 技术实现

### 核心动画阶段

1. **花瓣飘散** (初始状态)
   - 6×5网格碎片向上方飘散
   - 每片带有随机左右摇曳和旋转
   - 飘散距离100-200px

2. **装饰粒子**
   - 小型粒子飘浮营造氛围
   - 柔光辉光层叠加

3. **花瓣归位** (滚动驱动)
   - 碎片从上方飘落至原位
   - 摇曳和旋转逐渐消失
   - 各碎片有随机延迟

4. **柔光收尾** (末段)
   - 暖色柔光闪烁确认完成

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- 装饰粒子系统

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 85%' | 元素顶部到达视口85%时开始 |
| end | 'top 30%' | 元素顶部到达视口30%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 6×5花瓣形碎片飘落
- 左右摇曳 + 旋转运动
- 装饰粒子飘浮
- 柔光辉光氛围
- 春日暖色调

  <CardImageCherryBlossom />
