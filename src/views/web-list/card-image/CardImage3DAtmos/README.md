# CardImage3DAtmos — CSS3 3D 大气透视景深

## 概述

纯 CSS3 3D 大气透视景深效果。4层图片分布在不同的 Z 深度（-500px → +180px），通过 `perspective` + `transform-style: preserve-3d` + `translateZ` 构建真正的 3D 空间。用户竖滚时，摄像机推入 3D 场景，各层以不同速率视差移动，配合大气散射、体积光射线、浮动粒子，营造出穿越大气层的沉浸感。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 1200px (桌面) | 3D 透视距离，控制深度感强度 |
| `transform-style` | `preserve-3d` | 保持子元素在 3D 空间中的位置关系 |
| `translateZ` | -500 ~ +280 | 各图层在 Z 轴上的深度位置 |
| `backface-visibility` | — | 无需设置（图层平行于屏幕） |
| `filter: blur()` | 0~6px | 模拟景深，远景模糊 |
| `filter: brightness()` | 0.95~1.35 | 模拟大气散射，远景偏亮偏蓝 |

## 大气透视原理

真实世界的大气透视（Atmospheric Perspective）：
- 远景：更亮、更蓝、对比度更低、更模糊
- 中景：自然色彩和对比度
- 近景：最暗、最饱和、最清晰

CSS3 实现：
```
远景层 → brightness(1.35) + blur(6px) + 蓝色雾覆盖
中远景 → brightness(1.08) + blur(1.5px) + 淡蓝雾覆盖
中近景 → brightness(1.0) + blur(0px)
前景层 → brightness(0.95) + blur(0px)（最清晰）
```

## 图层结构

| 图层 | Z 深度 | 内容 | 效果 |
|------|--------|------|------|
| 远景 | -500 → -280 | 山脉 | 高亮、模糊、蓝色雾 |
| 中远景 | -200 → +20 | 森林 | 轻微雾化 |
| 中近景 | 0 → +140 | 湖面 | 清晰 |
| 前景 | +180 → +280 | 花卉 | 极致清晰、最暗 |
| 雾平面A | -350 | 散射雾 | 远景与中景之间 |
| 雾平面B | +80 | 薄雾 | 中景与前景之间 |
| 光线层 | -100 | 5条体积光 | 旋转扫过场景 |
| 粒子场 | +100 → +250 | 40个光点 | 漂浮漂移动画 |

## 动画流程

| 滚动阶段 | 摄像机 Z | 远景模糊 | 光线 | 效果 |
|---------|----------|---------|------|------|
| Stage 1 (0→1) | 0 → 120 | 1.5px | 淡入 | 远景展开，场景建立 |
| Stage 2 (1→2) | 120 → 280 | 2.5px | 亮起 | 穿越中景，雾消散 |
| Stage 3 (2→3) | 280 → 450 | 4px | 持续 | 深入中近景 |
| Stage 4 (3→4) | 450 → 600 | 6px | 减弱 | 前景特写，模拟微距景深 |

## 附加特效

| 特效 | 技术 | 说明 |

| 环境光晕 | 3个大型模糊渐变圆 | 随滚动漂移，模拟动态光照 |

## 技术要点

- 纯 CSS3 3D，无 Three.js 等 3D 库依赖
- GSAP ScrollTrigger 驱动摄像机推入（`scrub: 1.5`）
- 4层图片 + 2层雾平面 + 光线层 + 粒子场 = 8层 3D 场景
- 大气散射模拟（filter 组合：brightness + blur + fog overlay）
- 40个 CSS 动画粒子，伪随机分布
- 入场动画：标题字符从 3D 远方飞入（blur + scale + z）
- 完整动画清理机制（onUnmounted + cleanupFns）
- 响应式：桌面/平板/移动端分别调整 perspective 和图层尺寸
