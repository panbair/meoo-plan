# CardImageMagneticField - 磁场力线·南北极碎片归位

## 效果描述

图片被切割为6×4碎片，碎片沿磁力线弧形路径分散于南北极之间。两极标记发光脉动，SVG磁力线弧形连接南北极。随滚动推进，碎片沿磁力线弧形路径滑入归位，磁场消散。

## 技术实现

### 核心动画阶段

1. **磁场分散** (初始状态)
   - 6×4碎片沿弧形路径弹出
   - 基于角度和距离计算弧形偏移
   - 碎片带旋转和缩放 + 模糊
   - 按距离分层

2. **南北极标记**
   - 两极位置发光标记
   - 脉动效果

3. **SVG磁力线**
   - 弧形力线连接南北极
   - 不同颜色区分

4. **磁力归位** (滚动驱动)
   - 碎片沿弧形路径反向归位
   - 磁力线渐隐
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SVG 磁力线路径
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 85%' | 元素顶部到达视口85%时开始 |
| end | 'top 50%' | 元素顶部到达视口50%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 6×4碎片弧形分散
- 南北极发光标记
- SVG弧形磁力线
- 弧形路径归位运动
- 磁场消散效果
