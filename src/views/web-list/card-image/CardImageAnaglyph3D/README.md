# CardImageAnaglyph3D — 红蓝立体幻影

## 组件概述

经典红蓝立体眼镜效果 × GSAP 滚动控制。通过 `feColorMatrix` 将图像分离为红/青两通道，利用视觉视差偏移产生 3D 深度感。**滚动时偏移从 0px 发散到 ±15px，立体特效逐步增强。**

## 多层级架构

| 层级 | 内容 | 技术 | z-index |
|------|------|------|---------|
| Layer 1 | 左眼视图（红色通道） | `feColorMatrix` 提取 R 通道，`translateX: 0 → -15px` | 1 |
| Layer 2 | 右眼视图（青色通道） | `feColorMatrix` 提取 G+B 通道，`translateX: 0 → +15px` | 2 |
| Layer 3 | 3D 深度图 | Canvas 渐变纹理，`mix-blend-mode: overlay`，透明度 0.08→0.65 | 3 |
| Layer 4 | 视差辅助网格 | CSS Grid 12×8 线框，透明度随偏移增强 | 4 |
| Layer 5 | 立体指示器 | 红蓝双环图标 + "3D" 标签，渐显放大 | 15 |
| Layer 6 | 深度热点 | 3 个脉冲环（远景→中景→近景），深度增强时分区弹出 | 8 |

## 核心技术

- **feColorMatrix 通道分离**：`(1,0,0,0,0)` 提取红通道，`(0,1,1,0,0)` 提取青通道
- **screen 混合模式叠加**：红层 + 青层 `mix-blend-mode: screen` 叠回完整图像
- **smoothstep 偏移曲线**：`offset = MAX × p²(3-2p)`，前半段缓慢积累、后半段快速分离
- **深度热点分区弹出**：远景 p 0.15-0.42 / 中景 p 0.32-0.58 / 近景 p 0.55-0.85

## 交互效果

- 初始：红/青两层完全对齐，无 3D 效果，画面清晰平坦
- 滚动 0→1：偏移逐步扩大 → ±15px，红蓝重影渐强，3D 深度感越来越强烈
- 深度图从透明逐渐浮现，辅助网格在后段显形
- 深度热点按远景→中景→近景顺序依次脉冲闪烁
- 右上眼镜图标渐显放大升起，提示"佩戴红蓝眼镜"体验最佳 3D 效果
