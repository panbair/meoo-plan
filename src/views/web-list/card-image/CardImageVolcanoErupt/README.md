# CardImageVolcanoErupt - 火山喷发·岩浆碎片重铸

## 效果描述

图片如火山喷发般，碎片如熔岩弹从火山口喷射而出。底部火山口发光涌动，碎片带着炽热光晕向上抛射后落回归位。岩浆纹理和火山灰粒子营造喷发氛围。

## 技术实现

### 核心动画阶段

1. **火山口酝酿** (初始状态)
   - 底部火山口发光
   - 碎片堆积于底部
   - 岩浆纹理涌动

2. **喷发抛射** (前段)
   - 碎片如熔岩弹向上喷射
   - 炽热光晕效果
   - 火山灰粒子飞扬

3. **碎片落回归位** (滚动驱动)
   - 碎片在重力作用下落回
   - 逐步冷却（发光减弱）
   - 归位至原始位置

4. **冷却成像** (末段)
   - 炽热效果完全消退
   - 图片清晰显现
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS 发光/炽热滤镜
- 火山灰粒子系统

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 40%' | 元素顶部到达视口40%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 火山口发光涌动
- 熔岩弹喷射抛物线
- 炽热光晕 + 冷却渐变
- 火山灰粒子飞扬
- 岩浆纹理效果
