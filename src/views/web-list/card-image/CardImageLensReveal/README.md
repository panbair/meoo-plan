## CardImageLensReveal — 镜头聚焦揭示

**3焦平面景深 × 动态模糊 × 镜头光晕跟随**

### 📸 对焦三阶段

| 进度 | 焦点层 | 模糊变化 | 光圈 | 焦距 |
|:---:|:---:|------|:---:|:---:|
| 0-33% | 远景 FAR | 远景 blur 8→0, 中景5, 近景3 | f/16→f/8 | ∞ |
| 33-66% | 中景 MID | 远景 blur 0→3, 中景5→0, 近景3 | f/8→f/16 | 85mm |
| 66-100% | 近景 NEAR | 远景 blur 3→7, 中景0→3, 近景3→0 | f/16→f/2 | 35mm |

### 🎬 5层架构

| 层级 | 内容 | 技术 |
|:---:|------|------|
| L1-3 | 远/中/近景图 | CSS 3D `perspective` + `translateZ` 深度分层, `filter:blur()` GSAP 动态控制 |
| L4 | 镜头光晕 | 主光斑 300px radial-gradient + 光环 + 3个次级鬼影光斑, 位置跟随鼠标 `--flare-x/y` |
| L5 | 对焦框 | 四角 L 形标线 + 十字准星 + 脉冲对焦环, `--frame-color` 随阶段变色(蓝→绿→橙) |

### 🔧 技术要点

- **GSAP scrub=1.2**：单条 `onUpdate` 驱动三阶段模糊插值计算
- **光晕颜色映射**：远景冷蓝 `rgba(180,210,255)` → 中景青绿 `rgba(180,240,210)` → 近景暖橙 `rgba(255,200,150)`
- **光晕强度曲线**：每阶段峰值 0.7→0.8→0.9，近景特写时光晕最强 (f/2 大光圈)
- **对焦框脉冲**：每阶段对焦完成时 `opacity` 短暂冲高 0.8→0.85→0.9
- **混合模式**：光晕 `mix-blend-mode: screen`，暗角 `multiply`
- **鼠标跟随**：`requestAnimationFrame` 循环更新 `--flare-x/y` CSS 变量
