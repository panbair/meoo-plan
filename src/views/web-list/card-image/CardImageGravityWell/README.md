# CardImageGravityWell - 引力阱·螺旋吸入重组

## 效果描述

图片被切割为6×5碎片，碎片如被黑洞引力场吸入般沿螺旋轨道旋转分散。中心引力核心发光脉动，引力透镜扭曲效果叠加。随滚动推进，碎片逐层从外到内沿螺旋轨道归位，引力场消散。

## 技术实现

### 核心动画阶段

1. **引力场分散** (初始状态)
   - 6×5碎片沿切线方向螺旋弹出
   - 距中心越远旋转越大（180°/360°）
   - 碎片缩放0.3-0.7 + 模糊

2. **引力核心脉动**
   - 中心核心发光
   - 引力透镜扭曲效果

3. **螺旋归位** (滚动驱动)
   - 碎片分层（按距中心距离）逐层归位
   - 沿螺旋轨道反向旋入
   - 模糊和缩放恢复

4. **引力消散** (末段)
   - 核心光晕消散
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- 引力透镜扭曲效果

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 85%' | 元素顶部到达视口85%时开始 |
| end | 'top 60%' | 元素顶部到达视口60%时结束 |
| scrub | 1.2 | 平滑系数 |

## 视觉效果

- 6×5碎片螺旋分散
- 引力核心发光脉动
- 引力透镜扭曲
- 分层螺旋归位
- 切线方向旋转运动
