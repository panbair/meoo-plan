# CardImage3DStage — CSS3 3D纵深舞台

## 概述

5层图片分别位于真实CSS3 Z轴空间的不同深度（-400→-200→0→200→400），通过 `perspective` + `transform-style: preserve-3d` 构建3D场景。用户竖滚时，"相机"在Z轴上前后移动，穿越五层深度空间。近大远小、近快远慢的天然3D透视配合动态景深模糊，营造出真实的空间穿越感。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 1000px | 3D场景透视 |
| `transform-style` | `preserve-3d` | 保持子元素3D位置 |
| `translateZ` | -400 / -200 / 0 / 200 / 400 | 5层Z轴深度定位 |
| `scale` | 0.4 → 1.0 | 近大远小（按zNorm缩放） |
| `filter: blur()` | 4px → 0px | 远景模糊、近景清晰 |

## 五层深度配置

| 层 | Z值 | 初始scale | 初始blur | 初始opacity |
|----|-----|----------|---------|------------|
| Layer 1 远山 | -400 | 0.7 | 4px | 0.5 |
| Layer 2 森林 | -200 | 0.8 | 2px | 0.65 |
| Layer 3 海岸 | 0 | 0.9 | 0px | 0.75 |
| Layer 4 田野 | 200 | 1.0 | 0px | 0.85 |
| Layer 5 花朵 | 400 | 1.1 | 0px | 1.0 |

## 动画流程

| 阶段 | 相机Z位置 | 效果 |
|------|----------|------|
| 0→1 | 0→150 | 相机推进，远层逐步清晰 |
| 1→2 | 150→300 | 中远层成为焦点 |
| 2→3 | 300→400 | 锚点层(海岸)最佳观看 |
| 3→4 | 400→500 | 近层(田野)被放大突出 |
| 4→5 | 500→0 | 相机回到初始，循环 |

每阶段焦点层会短暂提升亮度+饱和度+scale（`highlight: 1.15`），非焦点层略微增加blur。

## 辅助动效
- Canvas 深度粒子：粒子Z位置影响屏幕大小和透明度
- 深度指示条：从"远"到"近"填充

## 与 ParallaxFlow 的区别

| | ParallaxFlow | 3DStage |
|------|-------------|---------|
| 实现方式 | Y轴位移模拟视差 | 真实translateZ + perspective |
| 层数 | 3层 | 5层 |
| 深度感 | transform模拟 | CSS3 原生3D透视 |
| 相机 | 固定 | Z轴移动 |
