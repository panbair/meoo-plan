# CardImageXRayScan - X射线扫描·骨骼透视显影

## 效果描述

图片以X射线负片模式显示，明暗反转。扫描线从一侧扫过，扫描区域从X射线负片恢复为正常色彩。扫描过程中显示骨骼结构标注和医疗UI界面，最终完全还原为正常图片。

## 技术实现

### 核心动画阶段

1. **X射线模式** (初始状态)
   - 图片反色显示（invert滤镜）
   - 高对比度 + 蓝绿色调
   - 医疗UI框架

2. **扫描线推进** (滚动驱动)
   - 垂直扫描线从左到右推进
   - 扫描线经过区域恢复正常色彩
   - clip-path 分割正常/X射线区域

3. **医疗UI展示** (中段)
   - 骨骼标注浮出
   - 数据面板展示

4. **完全还原** (末段)
   - 扫描完成，全图正常色彩
   - UI消退
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- CSS invert/contrast 滤镜
- CSS clip-path 区域分割
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 15%' | 元素顶部到达视口15%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- X射线负片反色显示
- 垂直扫描线推进
- 区域渐进色彩还原
- 医疗UI标注和面板
- 骨骼结构可视化
