# CardImage3DInertiaRibbon — CSS3 3D 惯性飘带 · 物理拟真

## 概述

摒弃机械匀速运动，追求真实世界"轻盈飘动"的物理质感。5条飘带面板在3D空间中排列，受"阵风"驱动产生连锁飘动响应——每条飘带依次经历 **加速 → 超调 → 回弹** 三阶段，通过 `cubic-bezier(0.175, 0.885, 0.32, 1.275)` 自定义贝塞尔曲线实现物理惯性特征。鼠标移动时，飘带以相同的惯性曲线跟随光标微调姿态。

## 核心技术：物理惯性拟真

### 核心缓动曲线

```
cubic-bezier(0.175, 0.885, 0.32, 1.275)

阶段分解:
  0.0 → 0.3  : 缓慢启动 (缓入)      ← 飘带刚开始响应风力
  0.3 → 0.7  : 快速加速 (中段)      ← 风力推动飘带加速
  0.7 → 1.0  : 超过目标值 (超调)    ← 惯性导致飘带冲过平衡点
  1.0 → 1.05 : 回弹修正             ← 飘带弹性恢复
  1.05 → 1.0 : 稳定                 ← 飘带在平衡位置静止
```

等价 GSAP 缓动：`back.out(1.275)`

### 阵风物理模型

每次"阵风"分三个精确阶段：

| 阶段 | 持续时间 | 缓动函数 | 物理含义 |
|------|---------|---------|---------|
| ① 加速期 | 0.13s | `power3.in` | 风力骤起，飘带被快速推动 |
| ② 超调期 | 0.09s | `back.out(1.7)` | 惯性过冲，飘带超越平衡位置 |
| ③ 回弹期 | 0.22s | `cubic-bezier(0.175,0.885,0.32,1.275)` | 弹性恢复，飘带稳定到新位置 |

### 波纹传播

5条飘带各有不同的 `phaseOffset` (0 → 1.4s)，风力沿飘带链依次传播：

```
阵风发生 (t₀)
  │
  ├─ 0.00s → 飘带#0 响应 (SILK.WHISPER, 最远)
  ├─ 0.35s → 飘带#1 响应 (VELVET.DRIFT)
  ├─ 0.70s → 飘带#2 响应 (CHIFFON.WAVE, 中间)
  ├─ 1.05s → 飘带#3 响应 (SATIN.SWAY)
  └─ 1.40s → 飘带#4 响应 (ORGANZA.FLOW, 最近)
```

## CSS3 3D 技术

| 属性 | 应用 |
|------|------|
| `rotateX()` | 飘带前后倾斜 (-12° → +14°)，构建深度层次 |
| `rotateY()` | 飘带左右偏转 (-15° → +12°)，模拟风向 |
| `scale3d()` | 运动时 Z 轴拉伸 (1.04→0.98→1.0)，模拟飘带弹性形变 |
| `perspective: 1200px` | 3D 透视空间 |
| `transform-style: preserve-3d` | 飘带嵌套3D |
| `translateZ` | 5条飘带分布在 -250 → +240 深度范围 |

## 双层动画架构

### 第一层：GSAP ScrollTrigger (滚动驱动)
- 6次阵风周期，scroll scrub 1.8
- 每条飘带经历完整的 加速→超调→回弹 物理响应
- 环境光/微粒/指示器同步脉动

### 第二层：CSS transition + 鼠标视差 (光标驱动)
- `requestAnimationFrame` 持续读取光标位置
- 飘带通过 CSS `transition: transform 0.9s cubic-bezier(0.175, 0.885, 0.32, 1.275)` 平滑跟随
- 前景飘带响应幅度 > 远景飘带 (深度因子 0.6→1.4)
- 鼠标离开 → 所有飘带弹性回归基础姿态

## 技术要点

- 🔑 `cubic-bezier(0.175, 0.885, 0.32, 1.275)` 贯穿整个动画系统
- 阵风模型：每个周期 = 加速(0.13s) + 超调(0.09s) + 回弹(0.22s) = 0.44s/周期
- 波纹传播：phaseOffset 增量 0.35s 确保视觉上清晰的波浪传递
- CSS transition 处理鼠标视差 → GSAP 不直接操作飘带的 transform
- 当 GSAP 驱动滚动时，CSS transition 被暂时覆盖 (GSAP 设置内联 style)
- 鼠标移动时，requestAnimationFrame 设置新的 transform → CSS transition 接管平滑
- 飘带光泽随运动强度动态变化 (filter: brightness + drop-shadow)
