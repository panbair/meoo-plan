# CardImageMorphTransition — 变形转场

> **组合**：图片A → 液态变形 → 图片B × 网格顶点变形

## 概念
图片A通过11×11网格顶点变形效果逐渐扭曲，最终定格为图片B。Canvas实时渲染100个变形Quad，配合SVG液态波纹和交叉淡化，实现流体般的转场过渡。

## 多层级架构
```
Layer 1-2: Canvas 网格变形渲染 (图片A → 100个Quad逐帧变形)
Layer 3:   图片B 交叉淡化层 (40%进度时开始淡入)
Layer 4:   液态波纹遮罩 (SVG涟漪扩散 + feDisplacementMap)
Overlay:   网格顶点可视化 (121点 + 网格线实时绘制)
```

## 核心技术

| 技术 | 实现 |
|------|------|
| **网格变形** | 11×11=121顶点，GSAP插值从identity位置到warped位置，每帧渲染100个Quad |
| **顶点位移** | 四重叠加：低频正弦波浪 × 中频PRNG湍流 × 漩涡效应 × 边缘向外拉伸 |
| **Quad渲染** | Canvas `clip()` 路径 + `translate/scale` 仿射变换 + `drawImage` 片段映射 |
| **液态扭曲** | SVG `feTurbulence(fractalNoise)` + `feDisplacementMap` scale 0→40→0 |
| **交叉淡化** | 图片B opacity 0→1 在进度40%-88%完成 |
| **涟漪遮罩** | 两个同心SVG圆，scale 0.3→1.8 循环扩散动画 |

## 5阶段动画时间线

| 阶段 | 进度 | 变形 | displacement | 图片B |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 0-15% | 0→8% | 0→12 | 不可见 |
| 2 | 15-50% | 8→65% | 12→40(峰值) | 不可见 |
| 3 | 40-65% | 继续加速 | 保持峰值 | 0→85%(交叉淡化) |
| 4 | 50-80% | 65→95% | 40→5 | 85%+ |
| 5 | 80-100% | 95→100% | 5→0 | 100% |
