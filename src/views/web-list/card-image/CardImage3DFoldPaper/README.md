# CardImage3DFoldPaper — CSS3 3D 纸张折叠 · 物理锚点控制

## 概述

模拟真实世界纸张沿中线弯折的物理形态。将一张完整图片分为左/中/右三个面板，通过 `transform-origin` 将旋转基点精确锚定在折痕位置，施加相反方向的 `rotateY` 旋转——左右面板像对开门一样向内折叠，顶部横幅向下弯折，完美模拟真实的纸张折叠展开过程。

## 核心技术：transform-origin 物理锚点

### 三面板对开门布局

```
           ┌──────────┬──────────┬──────────┐
           │  LEFT    │  CENTER  │  RIGHT   │
           │  PANEL   │  PANEL   │  PANEL   │
           │          │  (固定)  │          │
           └──────────┴──────────┴──────────┘
                    ↑            ↑
              折痕A(右边缘)  折痕B(左边缘)
```

### 锚点配置

| 面板 | transform-origin | rotateY 方向 | 折叠效果 |
|------|-----------------|-------------|---------|
| 左面板 LEFT | **right center** | +85° | 以右边缘为轴，向右后方折叠 |
| 中面板 CENTER | (不旋转) | 0° | 固定不动，作为基底 |
| 右面板 RIGHT | **left center** | -85° | 以左边缘为轴，向左后方折叠 |
| 顶部横幅 TOP | **bottom center** | +80° | 以底边缘为轴，向上方折叠 |

### 折叠物理

```
完全展开 (0°):
┌──────────┬──────────┬──────────┐
│  LEFT    │  CENTER  │  RIGHT   │
└──────────┴──────────┴──────────┘

半折叠 (85°):
     ╱
    ╱ LEFT     ┌──────────┐    RIGHT ╲
   ╱  (折叠中) │  CENTER  │ (折叠中)  ╲
               └──────────┘

完全折叠 (130°):
   LEFT ┐              ┌ RIGHT
   (重合)│  ┌────────┐ │(重合)
         └──│ CENTER │──┘
            └────────┘
```

### transform-origin 详解

```
左面板:
  transform-origin: right center
  ↓
  旋转轴在面板的右边缘中心
  rotateY(+85°) → 面板绕右边缘向后旋转
  右边缘不动 (贴在中心面板左边缘)
  左边缘向后移动 → 折叠效果

右面板:
  transform-origin: left center
  ↓
  旋转轴在面板的左边缘中心
  rotateY(-85°) → 面板绕左边缘向后旋转
  左边缘不动 (贴在中心面板右边缘)
  右边缘向后移动 → 折叠效果
```

## 折痕阴影

每个折叠边缘有一条 8px 宽的渐变阴影：

```
左面板折痕 (右边缘):
  transparent → rgba(0,0,0,.08) → rgba(0,0,0,.15)
  模拟纸张折叠处的暗角

右面板折痕 (左边缘):
  rgba(0,0,0,.15) → rgba(0,0,0,.08) → transparent
```

## 5阶段折叠循环

| 阶段 | 左/右 rotateY | 顶部 rotateX | 效果 |
|------|-------------|-------------|------|
| 0→1 | 0° → ±85° | 0° → +80° | 对开门式向内折叠 |
| 1→2 | ±85° → ±130° | +80° → +110° | 完全折叠（面板重合） |
| 2→3 | elastic弹回 ±120° | 保持 | 纸张弹性回弹 |
| 3→4 | ±120° → ∓40° | +110° → -30° | 反向折叠（向外折） |
| 4→5 | ∓40° → 0° | -30° → 0° | back.out(1.4) 弹回展开 |

## 技术要点

- 🔑 `transform-origin` 精确锚定折叠轴：`right center` / `left center` / `bottom center`
- 🔑 左右面板反向旋转：左 +Y / 右 -Y → 对折
- 🔑 三面板共享一张大图，通过 `background-position` 各显示1/3
- 🔑 折痕渐变阴影增强纸张折叠的立体感
- 🔑 弹性回弹 `elastic.out(1, 0.4)` 模拟真实纸张的物理弹性
- 🔑 归位反弹 `back.out(1.4)` 模拟展开时的超调回弹
- 顶部横幅独立旋转轴 (`bottom center`) 展示不同方向的折叠
- `backface-visibility: hidden` 防止折叠时背面穿透
