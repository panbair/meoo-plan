# CardImageWiggleShake — 扭动摇摆

## 概述

图片如Q弹果冻般扭动摇摆。x轴快速左右摆动（wiggle），配合 scaleX/scaleY 交替形变模拟挤压拉伸效果，再加上轻微旋转抖动。底部8段彩色摆动条逐段波浪式跳动，Canvas糖果色弹珠粒子在画面中弹跳碰撞，充满欢乐的节奏感。

## 核心动画

### 入场动画
- 标题四字从两侧弹入（`x: ±60→0`, `elastic.out(1, 0.5)`）
- 底部摆动条从无到有

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 动画 | 描述 |
|------|------|------|
| **Phase A — 扭动入场** (0→0.38) | `x: 60→-25→18→-10→6→-2→0`, `scaleX: 0.6→1.35→0.75→1.15→0.92→1.03→1` | 6次衰减扭动 + 弹性形变逐渐恢复正常 |
| **Phase B — 摇摆舞蹈** (0.38→0.62) | `x: 0→-8→7→-4→3→0`, scale XY 交替起伏 | 5次小微摆，如同果冻余震 |
| **Phase C — 扭动退场** (0.62→0.8) | `x: 0→-55`, `scaleX: 1→0.65`, `scaleY: 1→1.35` | 向左扭动拉长退场 |
| **Phase D — 下一帧扭入** (0.73→) | 同 Phase A（2次快速微摆+弹性恢复） | 新图片扭动入场 |

### 辅助动画
- 底部摆动条：8段彩色方块逐段波浪跳动（每段有相位差）
- Canvas 弹珠：糖果色弹珠受重力影响弹跳碰撞
- 标题入场使用 `elastic.out` 缓动（橡皮筋效果）
- 文字信息也使用 `elastic.out` 缓动入场

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 糖果粉 / 青柠绿 / 橘子橙 / 葡萄紫 / 柠檬黄 |
| 氛围 | 欢乐、Q弹、充满节奏感 |

## 技术要点

- `elastic.out` 缓动是核心特色（标题入场、文字入场、摆动恢复）
- 6次衰减扭动序列模拟物理阻尼振动
- `scaleX`/`scaleY` 交替变形（压扁→拉长→正常）
- 8段摆动条每段有独立相位偏移（波浪传播效果）
- `scrub: 1.2`
