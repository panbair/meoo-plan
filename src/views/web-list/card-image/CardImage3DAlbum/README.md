## CardImage3DAlbum — 3D 记忆相册

### 概念

10 张照片以 3D 圆柱体排列在透视空间中，滚动时圆柱体旋转 360°。照片离正面越近越亮，越接近侧面越暗，模拟真实 3D 光照效果。中心有光柱脉动，地面有反射光晕。当某张照片转到正面时，底部会显示照片名称。

### 六层架构

| 层级 | 内容 | 行为 | z-index |
|------|------|------|---------|
| Layer 1 | 粒子背景 | 50 颗随机飘浮光点，带辉光 | 1 |
| Layer 2 | 3D 圆柱舞台 | 10 张照片卡片旋转排列，perspective: 1400px | 2 |
| Layer 3 | 中心光柱 | 脉动光环 ×3 + 光束，随滚动增强 | 3 |
| Layer 4 | 地面反光环 | 椭圆形径向渐变，随滚动展开 | 4 |
| Layer 5 | 快门暗角 | radial-gradient 暗角，滚动逐渐减淡 | 8 |
| Layer 6 | 覆盖层 | 标题、分隔线、副标题、照片名、进度条、滚动提示 | 14-15 |

### ScrollTrigger 联动

```
progress: 0 → 1
├── 圆柱体旋转:      0° → 360° (rotateY)
├── 卡片亮度:        0.35~1.0 (正面最亮，背面最暗，余弦衰减)
├── 卡片 z-index:    随亮度动态调整
├── 中心光柱:        透明度 0.15→0.65，缩放 0.3→1.3
├── 地面反光环:      透明度 0.1→0.45，水平缩放 0.4→1.5
├── 暗角:           0.3→0.09
├── 进度条:          0%→100%
├── 滚动提示:        0.5→0
├── 照片名:          progress>0.1 时淡入
└── 文字入场:        title/sub 在 progress 起始阶段
```

### 关键技术

| 技术 | 具体实现 |
|------|----------|
| **perspective + rotateY** | 透视空间 1400px，圆柱体 `transform-style: preserve-3d` |
| **卡片排列** | `rotateY(i*36°) translateZ(380px)`，10张卡片均匀分布 |
| **光照模型** | 计算每张卡片与正面夹角，余弦衰减：`0.35 + 0.65 * max(0, 1 - diff/90)` |
| **粒子背景** | Canvas 2D，50颗光点随机飘逸，含双圈辉光 |
| **中心光柱** | 3层环形边框 + 径向渐变光束，CSS动画脉动 |
| **地面反射** | 水平椭圆 `radial-gradient` + `blur(20px)` |
| **onLeaveBack** | 重置所有元素到初始状态 |
