# CardImageTimeSlice — 时间切片流转

> **时间轴 × 百叶窗切片 × 日夜流转**

## 核心概念

同一场景的 **3 个时间节点**（黎明 → 正午 → 黄昏）图片，像竖直百叶窗一样被切成 **12 条切片**。滚动时，**奇数条先切换、偶数条后切换**，形成"时间波纹"般的视觉效果。

## 多层级架构

```
Layer 1-12:  奇数切片 (黎明图, 垂直条带)
Layer 13-24: 偶数切片 (正午图, 垂直条带)
Layer 25-36: 前景切片 (黄昏图, 垂直条带)
Layer 37:    时间轴指示器 (底部 DAWN/NOON/DUSK 标签)
Layer 38:    时钟装饰层 (SVG 模拟时钟 + 数字时间显示)
Layer 39:    色温滤镜覆盖层 (冷蓝 → 中性 → 暖橙)
Layer 40:    切片边缘辉光线 (过渡时发光)
Layer 41:    标题标签 + 进度条
```

## GSAP 动画时间线 (ScrollTrigger)

| 进度段 | 效果描述 | 技术实现 |
|--------|----------|----------|
| 0~5%   | 标题入场淡入 | `gsap.to` opacity + y |
| 0~25%  | 奇数条开启黎明→正午切换 | `onUpdate` opacity 计算 |
| 18~43% | 偶数条延后开启黎明→正午切换 | 0.18s offset 延迟 |
| 35~65% | 奇数条保持正午，偶数条追逐 | 三阶段 opacity 分段 |
| 60~95% | 交替切换正午→黄昏 | 错峰 offset 形成波浪 |
| 85~100%| 标题淡出 | `gsap.to` opacity 0.15 |
| 0~100% | 色温滤镜渐变、时钟旋转、进度条 | `onUpdate` 每帧计算 |

## 核心技术

- **切片裁剪**：CSS `clip-path: inset()` 创建 12 条精确垂直条带（每条 8.333% 宽，含 0.25% 间隙）
- **错峰动画**：奇数条偏移 0~0.072，偶数条偏移 0.18，形成 0.18 秒波浪延迟
- **三阶段透明度**：黎明→正午 (0-35%) → 正午保持 (35-65%) → 正午→黄昏 (65-100%)
- **色温滤镜**：`mix-blend-mode: overlay` + 动态 RGBA 渐变（冷蓝 → 中性 → 暖橙）
- **边缘辉光**：过渡时 strip 边缘 1.5px 发光线条 + box-shadow 闪烁

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| stripCount | 12 | 垂直切片数量 |
| stripPct | 8.333% | 每条宽度百分比 |
| gapPct | 0.25% | 切片间隙 |
| baseDelay(odd) | i × 0.012 | 奇数条偏移 |
| baseDelay(even) | 0.18 | 偶数条偏移 |
| span | 0.72 | 动画区间跨度 |
| scrub | 1.2 | ScrollTrigger 平滑度 |
