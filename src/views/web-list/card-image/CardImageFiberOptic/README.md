# CardImageFiberOptic - 光纤传输·脉冲汇聚重组

## 效果描述

图片被切割为6×4碎片，碎片沿光纤路径从四面八方的边缘传输至中心汇聚。SVG光纤线条带有脉冲光点沿路径流动，中心hub节点闪烁。碎片沿曲线路径滑入归位，如数据通过光纤网络传输。

## 技术实现

### 核心动画阶段

1. **碎片分散至边缘** (初始状态)
   - 6×4碎片从四个边缘方向散出
   - 每个碎片随机分配到上/下/左/右边缘
   - 带模糊效果

2. **SVG光纤路径**
   - 从每个碎片到中心的曲线光纤路径
   - 脉冲光点沿路径流动

3. **碎片沿光纤归位** (滚动驱动)
   - 碎片沿光纤曲线路径滑入原位
   - 脉冲粒子伴随传输
   - Hub中心闪烁

4. **完成闪光** (末段)
   - 中心hub爆发光芒

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SVG 光纤路径动画
- SCSS 样式
- 粒子脉冲系统

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 50%' | 元素顶部到达视口50%时结束 |
| scrub | 1.2 | 平滑系数 |

## 视觉效果

- 6×4碎片光纤传输
- SVG曲线光纤路径
- 脉冲光点沿路径流动
- 中心Hub节点闪烁
- 四面八方汇聚效果
