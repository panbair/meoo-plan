# CardImage3DInfinityTunnel — CSS3 3D 图片长廊隧道

## 概述

纯 CSS3 3D 构建的"飞越图片长廊"——12层结构框作为隧道骨架，左右墙壁各有6幅巨幅图片面板，隧道尽头设有一张"终极影像"。用户竖滚驱动所有元素向相机推进，如同穿越一条两侧挂满艺术品的无限画廊，最终抵达尽头的震撼画面。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 500px | 短焦强化隧道纵深感 |
| `transform-style: preserve-3d` | 隧道容器 | 保持所有子元素的3D空间 |
| `translateZ(0→-3000)` | 12层框+12面板+终点 | Z轴深度排列 |
| `rotateY(±25°)` | 隧道整体 | 左右摆动展示侧壁 |
| `scale + opacity递变` | 远处元素 | 大气透视效果 |

## 场景元素结构

```
隧道骨架：12层发光矩形框（Z轴间距250px）
  ├─ 上横梁：70px，贴Unsplash图片纹理
  ├─ 下横梁：70px，贴Unsplash图片纹理
  └─ 框发光边框

左墙画廊：6幅巨幅面板（200px宽 × 360px高）
  └─ 12张不同Unsplash大片（海边/山谷/星空/森林/花海/麦田）

右墙画廊：6幅巨幅面板（200px宽 × 360px高）
  └─ 12张不同Unsplash大片（银河/极光/日出/海洋/山峦/花田）

隧道终点：1张终极影像（340px × 240px）
  └─ 从极远处(scale=0.05)→逐渐放大到面前(scale=1)
```

## 动画流程

| 阶段 | 效果 |
|------|------|
| 入场 | 文字从Z=-600模糊飞入 |
| 推进 | 所有结构框+面板向相机推进 |
| 壁面 | 左右面板由远及近从身边飞掠 |
| 摆动 | 隧道 rotateY ±25° 让侧壁清晰可见 |
| 终点 | 终极影像从 blur(8px)→清晰→充满视野 |

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 电光紫 / 霓虹青 / 深空蓝 / 星光银 |
| 氛围 | 科幻画廊、穿越感、沉浸式 |

## 技术要点

- 三组独立元素（结构框/墙壁面板/终点影像）各自在Z轴推进
- 左右墙壁面板与隧道轴向平行排列（贴在两侧墙面上）
- 远处元素 scale + opacity 渐低模拟大气透视
- 隧道整体 rotateY 摆动让侧壁面板清晰可见
- GSAP ScrollTrigger scrub: 1.2 驱动全部推进
- 共使用 15 张不同 Unsplash 图片丰富视觉
