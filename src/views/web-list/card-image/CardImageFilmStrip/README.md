# CardImageFilmStrip - 胶片卷轴相册

## 概述

经典电影胶片风格的水平卷轴相册。8张照片以35mm胶片帧的形式排列在一条连续的胶片带上，垂直滚动驱动胶片水平卷动，营造老电影放映的怀旧氛围。

## 设计理念

- **35mm胶片美学**：上下两排经典齿孔（sprocket holes），每帧带有编号
- **暖色怀旧**：深棕底色 + 暖色调照片叠加 + 金色漏光效果
- **动态高亮**：滚动时当前帧自动提亮，其他帧略微变暗
- **胶片颗粒**：Canvas 生成的动态颗粒覆盖层，复刻真实胶片的质感

## 技术实现

- **GSAP ScrollTrigger** — 垂直滚动驱动胶片水平位移（scrub: 1.3）
- **动态帧高亮** — 当前帧 brightness(1.0)，非当前帧 brightness(0.55)，平滑过渡
- **Canvas 颗粒** — 250个随机生成/消散的暗色颗粒，混合模式 overlay
- **漏光效果** — 左右两侧渐变漏光，强度随进度正弦波动

## 特效细节

| 特效 | 说明 |
|------|------|
| 胶片卷动 | 8帧 × 420px 水平排列，从右侧起始向左卷动 |
| 齿孔 | 上下各60个矩形齿孔，随胶片同步移动 |
| 帧编号 | 每帧底部 01-08 编号，高亮帧有发光效果 |
| 漏光 | 左右暖色调漏光，滚动时强度正弦波动 |
| 暖色色调 | 照片叠加对角线暖色渐变 + 底部减淡 |
| 暗角 | 随滚动略微变淡 |
| 帧指示器 | 底部 8 颗圆点指示器 + FRAME XX 标签 |
| 文字入场 | 标题/分割线/副标题带模糊渐入 |
