# CardImagePortalOpen - 传送门开启·次元裂缝显影

## 效果描述

图片从一扇传送门中显现。圆形传送门从中心开启，边缘能量环旋转发光，次元裂缝向外扩张。碎片从传送门内部被推送出来归位，如同从另一个维度传送而至。

## 技术实现

### 核心动画阶段

1. **传送门关闭** (初始状态)
   - 圆形遮罩从中心缩小
   - 能量环旋转
   - 暗色背景

2. **传送门开启** (滚动驱动)
   - 圆形遮罩逐步扩大
   - 能量环脉动加速
   - 次元裂缝边缘效果

3. **碎片传送归位** (中后段)
   - 碎片从门内推出
   - 沿径向方向归位

4. **传送完成** (末段)
   - 传送门完全打开
   - 能量环消散
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- CSS clip-path / mask 圆形遮罩
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 50%' | 元素顶部到达视口50%时结束 |
| scrub | 1.2 | 平滑系数 |

## 视觉效果

- 圆形传送门开启
- 能量环旋转脉动
- 次元裂缝边缘光效
- 碎片从门内传送
- 径向扩张动画
