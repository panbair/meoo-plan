# CardImageAuroraWave - 极光波浪·光带撕裂重组

## 效果描述

图片被切割为12条水平光带，每条光带如极光一样沿不同方向波浪式飘散，带有彩色辉光和模糊效果。随滚动推进，光带从波浪状态逐渐归位拼合成完整图片，极光辉光逐渐消散。

## 技术实现

### 核心动画阶段

1. **光带波浪飘散** (初始状态)
   - 12条水平条带各自偏移不同的X/Y方向
   - 交替方向 + 距中心越远偏移越大
   - 每条带有独立的旋转角度和模糊值

2. **极光辉光层** (全程)
   - 3层极光辉光叠加，HSL色相渐变
   - 辉光随动画消散

3. **光带归位拼合** (滚动驱动)
   - translateX/Y → 0, rotation → 0, blur → 0
   - 各光带有延迟差异，形成波浪归位效果

4. **闪光收尾** (末段)
   - 全屏白色闪光确认拼合完成

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS 渐变极光辉光

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 40%' | 元素顶部到达视口40%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 12条水平光带波浪飘散
- 极光色彩辉光叠加（绿→青→蓝渐变）
- 交替方向的波浪运动
- 距中心越远模糊越强
- 归位时的阻尼波浪效果
- 闪光收尾
