# CardImageFloatBounce — 漂浮弹跳

## 概述

图片如气泡般从底部漂浮上升，带着弹性弹跳的物理感。图片从下方浮起→过冲到上方→回弹→再次小幅弹跳→最终稳定。Canvas 泡泡粒子从底部升起，配合光泽扫过效果，整体轻盈灵动。

## 核心动画

### 入场动画
- 标题四字从上方弹入（`y: -30→0`, `back.out(2.5)`）
- 浮动指示点从下方升起

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 动画 | 描述 |
|------|------|------|
| **Phase A — 浮起入场** (0→0.36) | `y: 80→-10→0`, `scaleY: 0.7→1.08→1`, `scaleX: 1.3→0.93→1` | 弹性浮起：过冲上方→回弹稳定 |
| **Phase B — 弹跳舞蹈** (0.36→0.62) | `y: 0→-18→0→-8→0`, scale XY 交替变形 + 轻微晃动 | 两次递减弹跳 + 左右晃动 |
| **Phase C — 向上浮起退场** (0.62→0.8) | `y: 0→-70`, `scaleY: 1→0.75`, `scaleX: 1→1.22` | 加速上浮 + 压扁形变 |
| **Phase D — 下一帧浮起** (0.74→) | 同 Phase A | 新图片从底部浮起入场 |

### 辅助动画
- Canvas 泡泡：带高光点的半透明泡泡从底部升起
- 浮动指示点：3个圆点上下浮动
- 光泽扫过层：一道光从图片表面扫过
- 背景光斑：向上漂移（呼应漂浮主题）

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 天空蓝 / 珊瑚粉 / 薄荷绿 / 阳光黄 |
| 氛围 | 轻盈、灵动、朝气蓬勃 |

## 技术要点

- GSAP `bounce.out` 缓动模拟物理弹跳
- `scaleX`/`scaleY` 交替变化模拟弹性形变
- Canvas 泡泡高光渲染
- `scrub: 1.3`
