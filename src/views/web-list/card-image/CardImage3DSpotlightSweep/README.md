# CardImage3DSpotlightSweep — 追光扫射画廊

## 概述
15张照片散落在3层空间平面上（近/中/远景各5张），分布在X轴-52vw到+52vw的宽幅画布上。一束暖色追光从左向右扫过，每张照片在追光波峰处绽放：亮度飙升、光晕亮起、照片微放大——追光过后留下淡淡余晖。不同深度层对追光的响应不同：近景锐利（窄峰）、远景柔和（宽峰）。

## 核心动画
```
scroll驱动 → 追光光源X轴滑动 (-60vw → +60vw) →
每张照片在追光抵达时触发"绽放三联":

  (a) brightness: 0.35 → 近1.35/中1.22/远1.12 → 0.35
  (b) scale:      0.88 → 近1.07/中1.05/远1.03 → 0.88
  (c) glow aura:  0.08 → 近0.80/中0.55/远0.35 → 0.08

深度差异：
  近景(Z=0):   窄窗口(0.8x), 高峰值(1.35), 锐利过渡
  中景(Z=-380): 中窗口(1.1x), 中峰值(1.22), 平滑过渡
  远景(Z=-760): 宽窗口(1.5x), 低峰值(1.12), 柔和过渡
```

## 与 CardImage3DGalleryFloor 的对比

| 维度 | GalleryFloor (原版) | SpotlightSweep (新版) |
|------|-------------------|----------------------|
| **揭示机制** | 相机translateZ推进 → 照片顺序经过"前台" | 追光X轴滑动 → 照片在光波中绽放 |
| **同时高亮数** | 1张（严格线性独占） | 2-3张（光波覆盖范围内的） |
| **运动方式** | gallery容器Z轴位移 | 追光光源X轴位移 + 光晕/亮度/缩放三重响应 |
| **深度编码** | 亮度+透明度线性 | 响应窗口宽度+峰值+过渡曲线（三维差异化） |
| **视觉隐喻** | 走廊漫步（穿越空间） | 追光灯扫射（光波掠过） |
| **余晖效果** | 无 | 照片保留微弱光晕（磷光效应） |
| **光源可视化** | 无 | 独立的光源层（core+rays+spill） |
| **scrub** | 1.2 | 1.3 |

## 视觉元素
- 暗黑虚空背景 + 星空 + 尘埃雾
- 追光光源层：暖色核心(core) + 旋转光线(conic-gradient rays) + 柔光溢出(spill)
- 3层空间平面：每层5张照片，共15张
- 彩色光晕（每张照片独立配置，近=暖色高饱和，远=冷色低饱和）
- 2层深度雾（物理分隔各层）
- 暗角

## 技术要点
- GSAP对每张照片独立创建3条tween（brightness/scale/glow），共计45条
- xToProgress() 将照片X坐标映射到scroll进度，实现"位置决定时机"
- 不同深度的窗口宽度倍数(0.8x/1.1x/1.5x)模拟真实光照的平方衰减
- 追光光源使用conic-gradient旋转光线模拟体积光
- 入场动画按X坐标排序（从左到右），与追光方向一致
- 响应式：移动端等比缩小卡片和光源
