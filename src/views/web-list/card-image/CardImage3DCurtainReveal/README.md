# CardImage3DCurtainReveal — CSS3 3D 帷幕拉开

## 概述

纯 CSS3 3D 模拟剧场大幕拉开效果——12道天鹅绒幕布面板排成一行覆盖画面，每道面板通过 `transform-origin` 设在边缘，用户竖滚驱动幕布从中间向两侧旋转折叠打开（rotateY ±130°），揭示幕后的全景图片。幕布正面有织物褶皱纹理和鎏金边缘。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 900px | 场景3D透视 |
| `transform-origin: 100%/0% 50%` | 幕布面板 | 🔑 左面板右边缘旋转，右面板左边缘旋转 |
| `rotateY(-130°/130°)` | 12道面板 | 向两侧折叠 |
| `transform-style: preserve-3d` | 面板 | 正反面独立 |
| `backface-visibility: hidden` | 正反面 | 折叠后只显示正面 |

## 面板结构

```
左侧6道：transform-origin: right center → rotateY 0→-130°
右侧6道：transform-origin: left  center → rotateY 0→+130°
中间两道先动（delay=0），两侧依次延迟（delay=0.06递增）
```

## 动画流程

| 阶段 | 效果 |
|------|------|
| 0-0.5 | 中间面板率先开始折叠 |
| 0.5-2 | 延迟传播到两侧面板 |
| 0.5-4 | 背景图片 opacity 从0.2→1.0 + scale微扩 |
| 2-4 | 两侧最后的面板也完全折叠 |
| 4+ | "大幕已开"指示器显示 |

## 视觉元素

| 元素 | 说明 |
|------|------|
| 幕布正面 | 深红色天鹅绒渐变 + 4条垂直褶皱 |
| 边缘鎏金 | 垂直金色渐变光线 |
| 幕布背面 | 暗红色，折叠后不可见 |
| 幕后全景 | 占满屏幕的Unsplash大图 |
| 聚光灯 | 两个径向光斑缓慢移动 |

| 要素 | 说明 |
|------|------|
| 色调 | 天鹅绒红 / 金丝镶边 / 暗夜黑 |
| 氛围 | 剧场感、仪式感、渐次揭示 |
| 背景 | 暗黑幕布覆盖全屏 |

## 技术要点

- 左右不同 `transform-origin` 实现镜像折叠
- 中间面板 delay=0，向两侧递增 — 形成"从中间向两侧拉开"的波浪
- 幕布背景从 opacity: 0.2 渐显与幕布折叠同步
- 褶皱用 flex 均分 + alternating gradient 模拟
