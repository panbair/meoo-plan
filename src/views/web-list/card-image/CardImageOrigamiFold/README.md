# CardImageOrigamiFold - 折纸展开·纸面翻转显影

## 效果描述

图片如一张折纸作品，初始为多层折叠状态。碎片像折纸面板一样通过3D翻转逐层展开，每个面板翻转时露出背面图案。随滚动推进，折纸面板逐层展开归位，最终铺展为完整图片。

## 技术实现

### 核心动画阶段

1. **折叠状态** (初始状态)
   - 碎片以折叠状态堆叠
   - 3D透视变换
   - 折痕阴影效果

2. **逐层翻转展开** (滚动驱动)
   - 面板沿折痕线3D翻转
   - 翻转露出图片内容
   - 按序逐层展开

3. **折痕消退** (后段)
   - 折痕线逐步淡出
   - 阴影消散

4. **铺展完成** (末段)
   - 图片完全铺展
   - 闪光确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- CSS 3D Transform (perspective, rotateX/Y)
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 10%' | 元素顶部到达视口10%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 多层折纸折叠效果
- 3D翻转展开动画
- 折痕线 + 阴影
- 逐层序列展开
- 纸面纹理质感
