# CardImageKaleidoscope - 万花筒·旋转对称展开

## 效果描述

图片被切割为6片花瓣形扇区，如万花筒一样从中心对称旋转展开。每片花瓣带有色相偏移和边缘光晕。中心装饰核心旋转缩放。随滚动推进，花瓣从收缩旋转状态展开归位，色相恢复正常。

## 技术实现

### 核心动画阶段

1. **万花筒收合** (初始状态)
   - 6片花瓣缩小至0.4倍 + 旋转偏移
   - 每片间隔60°排列
   - 带模糊和色相偏移

2. **色彩背景渐现**
   - Hue背景层渐现
   - 营造万花筒色彩氛围

3. **花瓣旋转展开** (滚动驱动)
   - 花瓣scale恢复 + rotation归位
   - 模糊消除 + hue-rotate恢复
   - 边缘光晕显现后消退

4. **中心核心动画** (同步)
   - 中心装饰旋转放大
   - 闪光收尾

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS hue-rotate 色相偏移
- 对称几何布局

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 30%' | 元素顶部到达视口30%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 6片对称花瓣扇区
- 万花筒旋转展开
- 色相渐变偏移
- 边缘光晕效果
