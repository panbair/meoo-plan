# CardImageNebulaBirth - 星云诞生·气体云聚合成像

## 效果描述

图片如宇宙星云般从弥散的气体尘埃中凝聚成形。碎片初始为模糊的星云气团，散布在黑暗背景中。随滚动推进，气体云逐步聚合收缩，尘埃粒子被引力吸入，碎片逐步清晰并归位拼合成完整图片。

## 技术实现

### 核心动画阶段

1. **星云弥散** (初始状态)
   - 碎片以模糊气团形式散布
   - 暗色宇宙背景
   - 粒子尘埃漂浮

2. **引力聚合** (滚动驱动)
   - 气团逐步向中心收缩
   - 模糊度逐渐降低
   - 透明度逐步增强

3. **尘埃吸入** (中后段)
   - 粒子被引力吸入
   - 光晕收缩

4. **成像完成** (末段)
   - 图片完全清晰显现
   - 星光闪烁确认

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- 粒子尘埃系统

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 82%' | 元素顶部到达视口82%时开始 |
| end | 'top 40%' | 元素顶部到达视口40%时结束 |
| scrub | 1.5 | 平滑系数 |

## 视觉效果

- 星云气体弥散效果
- 宇宙暗色背景
- 引力聚合收缩
