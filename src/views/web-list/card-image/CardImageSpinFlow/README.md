# CardImageSpinFlow — 旋转流动

## 概述

图片如同陷入优雅的漩涡，随用户滚动旋转流动。顺逆交替的旋转、伴随水平偏移和呼吸缩放，配合围绕中心螺旋扩散的粒子流，营造令人着迷的动态视觉。

## 核心动画

### 入场动画
- 标题四字旋转弹入（`rotation: -20°→0`, `back.out(2.3)`）
- 中心涡旋指示器从无到有（旋转+缩放）
- 两侧环形装饰持续旋转

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 动画 | 描述 |
|------|------|------|
| **Phase A — 旋转入场** (0→0.4) | `rotation: 15°→0`, `x: 70→0`, `scale: 0.75→1`, `blur: 15→0` | 图片从右侧旋转滑入中心 |
| **Phase B — 旋转舞蹈** (0.4→0.6) | `rotation: 0°→-5°→4°→0°`, `scale: 1→1.05→1` | 顺逆交替旋转 + 呼吸缩放 |
| **Phase C — 旋转退场** (0.6→0.8) | `rotation: 0°→-14°`, `x: 0→-65`, `scale: 1→0.78`, `blur↑` | 图片反向旋转滑出并模糊化 |
| **Phase D — 下一帧入场** (0.73→) | 同 Phase A | 新图片从右侧旋转入场 |

### 辅助动画
- Canvas 螺旋粒子：围绕中心点向外螺旋扩散
- 中心涡旋指示器：持续360°旋转 + 每帧脉冲
- 背景光斑：旋转漂移
- 粒子爆发：每帧有40个粒子从中心释放

## 技术要点

- Vue 3 Composition API + `<script setup lang="ts">`
- GSAP ScrollTrigger（`scrub: 1.25`）
- Canvas 2D 轨道螺旋粒子系统
- Vue 3 `ref<T>()` 获取全部 DOM 引用
- 完整 `onUnmounted` 清理
