# CardImageBloomRise — 绽放升起

## 概述

图片从视口底部如花朵般绽放升起，随着用户向下滚动，图片从底部"生长"出来，从模糊朦胧逐渐变得清晰锐利，配合飘浮的花瓣粒子和柔和光晕，营造青春浪漫的视觉体验。

## 核心动画

### 入场动画
- 标题从上方滑入，两侧文字分别从左右弹入
- 标题装饰线展开
- 底部生长光条从无到有

### 滚动控制动画 (ScrollTrigger)
- **绽放升起 (Phase 1)**: `clipPath: inset(85% 0% 0% 0%)` → `inset(0% 0% 0% 0%)`，图片从仅可见底部 15% 展开至完全可见
- **清晰过渡**: `blur(18px)` → `blur(0px)`，`scale 0.7` → `1.0`，`y: 35vh` → `0`
- **驻留呼吸 (Phase 2)**: 图片完全清晰后轻微呼吸脉动
- **向上收拢退场 (Phase 3)**: 图片向上收缩、模糊化，为下一帧让位
- **下一帧升起 (Phase 4)**: 新图片从底部绽放升起

### 辅助动画
- Canvas 花瓣粒子系统：圆瓣、尖瓣、心形三种花瓣飘浮
- 底部生长光条脉冲
- 背景光斑缓慢漂移
- 进度条填充

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 蜜桃、珊瑚、薄荷绿、薰衣草紫、阳光金 |
| 背景 | 暖白到蜜桃色的柔和渐变 |
| 字体 | Inter / PingFang SC / Microsoft YaHei |
| 氛围 | 青春、明亮、温暖、浪漫 |

## 技术要点

- Vue 3 Composition API + `<script setup lang="ts">`
- GSAP ScrollTrigger 滚动驱动动画
- Canvas 2D 粒子系统
- 所有 DOM 引用通过 Vue 3 `ref<T>()` 获取
- 完整的动画清理机制（`onUnmounted` 中清理所有 GSAP 动画和 ScrollTrigger）

## 图片来源

所有图片来自 Unsplash，尺寸参数 `w=1920&q=80`。
