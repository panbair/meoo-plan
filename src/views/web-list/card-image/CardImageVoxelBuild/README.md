# CardImageVoxelBuild — 体素堆叠建造

> **从未有过的组合**：3D 体素化 × 逐层堆叠 × 透视旋转 × 像素到体素

## 概念

图片被 3D 体素化 —— 变为 8×8 的彩色方块阵列（64 个体素）。每个方块携带正面图像颜色 + 侧面厚度 + 顶部高光。方块从画面深处（Z=-20）沿 Z 轴逐层飞入、带弹跳缓动定位、最终堆叠成完整画面。ScrollTrigger 控制堆叠进度，鼠标位置影响摄像机视角微旋转。

## 核心技术

### 3D 体素渲染管线

```
图像加载 → 8×8 离屏 Canvas 下采样 → 64 个颜色采样
           ↓
    生成立方体数据（位置 + 颜色）
           ↓
  每帧渲染循环:
    1. 计算摄像机角度（鼠标视差）
    2. 根据滚动进度更新每层 Z 偏移（弹跳缓动）
    3. 投影 8 个顶点 → 2D 屏幕坐标
    4. 按深度排序（Painter's Algorithm）
    5. 面可见性检测 → 绘制前面 + 顶面 + 侧面
    6. 地面阴影 + 粒子尘埃
```

### 3D 数学

| 操作 | 公式 |
|------|------|
| Y 轴旋转 | `x' = x·cos(θ) - z·sin(θ)` `z' = x·sin(θ) + z·cos(θ)` |
| X 轴旋转 | `y' = y·cos(φ) - z·sin(φ)` `z' = y·sin(φ) + z·cos(φ)` |
| 透视投影 | `scale = focalLength/(focalLength + z)` |
| 面可见性 | 旋转法向量后 `z > 0.005` → 可见 |
| 面着色 | `baseColor × shade` (前 1.0 / 顶 1.3 / 右 0.7 / 左 0.6) |

### 立方体面管理系统

| 面 | 法向量 | 顶点索引 | shade | 描边 |
|:---:|--------|:-----:|:---:|:---:|
| 前面 | (0,0,1) | 0,1,2,3 | 1.00 | ✓ |
| 后面 | (0,0,-1) | 4,5,6,7 | 0.35 | ✗ |
| 顶面 | (0,1,0) | 3,2,6,7 | 1.30 | ✓ |
| 底面 | (0,-1,0) | 0,1,5,4 | 0.45 | ✗ |
| 右面 | (1,0,0) | 1,2,6,5 | 0.70 | ✓ |
| 左面 | (-1,0,0) | 0,3,7,4 | 0.60 | ✓ |

每个面按深度排序后逐一填充 + 描边。

### 动画时间线

```
ScrollTrigger: start='top 85%', end='bottom 15%'
onUpdate → targetProgress

逐层飞入:
  Row 0: 0% → 24%     ┐
  Row 1: 11% → 35%    │
  Row 2: 22% → 46%    │
  Row 3: 33% → 57%    │ bounceOut 弹跳缓动
  Row 4: 44% → 68%    │
  Row 5: 55% → 79%    │
  Row 6: 66% → 90%    │
  Row 7: 78% → 100%   ┘

鼠标视差:
  mouseX (0~1) → rotY (-0.325 ~ 0.325)
  mouseY (0~1) → rotX (0.205 ~ 0.555)
  lerp 平滑: 0.05
```

## 视觉细节

### 色系
| 元素 | 颜色 |
|------|------|
| 背景 | `#0a0f14` 深灰蓝径向渐变 |
| 方块正面 | 原图采样色 (8×8 下采样) |
| 方块顶面 | 原色 ×1.3 亮调 |
| 方块侧面 | 原色 ×0.6~0.7 暗调 |
| 描边 | 面颜色微亮 + 白色微线 |
| 地面阴影 | `rgba(0,0,0,0.08~0.14)` 椭圆 |
| 地面光晕 | `rgba(60,140,220,0→0.18)` 径向蓝光 |
| 浮动尘埃 | `rgba(120,180,240,0.15~0.35)` 上升粒子 |
| 文字 | 冰蓝白 + 三层 text-shadow + 像素图标 |

### 字体
- 标题：`Segoe UI`/`PingFang SC`/`Microsoft YaHei`，粗体 800，大间距
- 副标题：大写宽松字距 `letter-spacing: 0.24em`
- 状态标签：小号字 + 半透明蓝色边框

### 性能设计
- 64 个体素 × 最多 3 个可见面 = 192 face draw calls
- 每个面 4 个顶点投影 → 256 vertex projections
- 无 Canvas `shadowBlur`（移除昂贵操作）
- `dpr ≤ 2` 限制像素填充
- 30 颗轻量尘埃粒子
- 渲染循环内的数学全部预计算、零 DOM 操作
