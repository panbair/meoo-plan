# CardImageKaleidoscopePrism — 万花筒棱镜

> **组合**：6面棱镜反射 × 旋转分割 × 多图拼接

## 概念
6张不同图片置于虚拟六棱镜各面。每个60°扇形切分为两个30°子扇形，后半个子扇形用 Canvas 精确镜像反射，形成12切片的万花筒对称图案。旋转时各面内容相互反射、分割、重组。

## 多层级架构
```
Layer 1-2: Canvas 万花筒渲染 (6扇区 × 镜像反射 = 12切片)
Layer 3:   SVG 六边形框架 + 彩虹棱镜边缘 (animated linearGradient)
Layer 4:   中心旋转曼陀罗 (6臂旋转，速度 3.5x)
Overlay:   6顶点光斑 (flares) + 暗角
```

## 核心技术

| 技术 | 实现 |
|------|------|
| **三角形切片** | 6张图片各切为60°扇形，Canvas `clip(path)` 精确裁剪 |
| **镜像反射** | 每个扇形后30°：`rotate(bisector) → scale(-1,1) → rotate(-bisector)` 沿二分线镜面翻转 |
| **旋转同步** | GSAP ScrollTrigger scrub=1.2，全局旋转0°→360°，曼陀罗旋转3.5x速度 |
| **彩虹棱镜边缘** | SVG 6色 `linearGradient` + SMIL `animate` 颜色轮播 + `feGaussianBlur` 发光 |
| **光斑系统** | 6个六边形顶点光斑，`radial-gradient` + 交错延迟 `flare-pulse` 动画 |

## 4阶段动画

| 阶段 | 进度 | 旋转角度 | 效果 |
|:---:|:---:|:---:|------|
| 1 | 0-20% | 0°→45° | 缓慢启动，展示初始面 |
| 2 | 20-55% | 45°→210° | 快速旋转，多面展现 |
| 3 | 55-80% | 210°→280° | 减速，光斑峰值 |
| 4 | 80-100% | 280°→360° | 完整一圈，文字入场 |
