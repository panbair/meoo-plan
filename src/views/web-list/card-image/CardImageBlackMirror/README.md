# CardImageBlackMirror - 黑镜碎裂·冲击波碎片重组

## 效果描述

图片如黑色镜面被冲击波击碎，5×4网格碎片从冲击中心向四周放射状弹飞。SVG裂纹线条从撞击点扩散。随滚动推进，碎片沿原路径反向回收归位，裂纹消退，镜面恢复完整。

## 技术实现

### 核心动画阶段

1. **冲击波碎裂** (初始状态)
   - 5×4碎片从中心放射状弹飞
   - 每个碎片根据距中心距离和角度计算弹飞方向
   - 碎片带旋转和Y轴坠落

2. **SVG裂纹扩散**
   - 从冲击中心向外生成裂纹路径
   - 裂纹线条动画扩散

3. **碎片回收归位** (滚动驱动)
   - 碎片反向回收，距离近的先归位
   - translateX/Y → 0, rotation → 0

4. **冲击闪光** (末段)
   - 冲击点白色闪光

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SVG 裂纹路径动画
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 55%' | 元素顶部到达视口55%时结束 |
| scrub | 1 | 平滑系数 |

## 视觉效果

- 5×4网格镜面碎裂
- 放射状碎片弹飞
- SVG裂纹线条扩散
- 冲击中心闪光
- 碎片反向回收归位
