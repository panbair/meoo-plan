# CardImageInfraredShift - 红外热成像·光谱偏移还原

## 效果描述

图片以红外热成像模式显示，覆盖热力色彩映射。扫描条从上到下扫描，热点标记逐个激活显示温度数据。随滚动推进，热力色彩逐步偏移褪去，还原为真实色彩图片。UI面板展示科技数据。

## 技术实现

### 核心动画阶段

1. **热成像模式展示** (初始状态)
   - 图片覆盖热力色彩遮罩
   - 热点标识器隐藏

2. **扫描条扫描** (前段)
   - 扫描条从顶部扫到底部
   - 热点标识器逐个激活
   - 温度标尺UI入场

3. **UI面板展示** (中段)
   - 数据面板滑入
   - 温度色阶标尺显示

4. **光谱偏移还原** (后段)
   - 热力色彩逐步褪去
   - 真实色彩逐步显现
   - 闪光确认还原完成

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS hue-rotate/saturate 滤镜
- 热成像UI组件

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 10%' | 元素顶部到达视口10%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 红外热成像色彩映射
- 扫描条从上到下扫描
- 热点标记 + 温度数据
- 科技UI面板
- 光谱偏移色彩还原
