# CardImage3DFoldingFan — CSS3 3D 折扇展开

## 概述

纯 CSS3 3D 模拟中国传统折扇的物理展开——16根扇骨围绕底部枢轴，每根在3D空间中 rotateY 到不同角度，总展开170°。每根扇骨的扇面上贴 Unsplash 图片，如同"一扇一景"。扇轴有鎏金装饰，顶部有骨端圆珠。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `transform-origin: 50% 100%` | 扇骨 | 🔑 从底部旋转而非中心 |
| `rotateY(-85°→+85°)` | 16根扇骨 | 每根不同角度形成扇形 |
| `transform-style: preserve-3d` | 扇骨 | 3D折叠空间 |
| `backface-visibility: hidden` | 扇面 | 遮挡背面 |

## 动画流程

| 阶段 | 效果 |
|------|------|
| 入场 | 文字逐字Y轴90°反转弹入 |
| 展开 | 16根扇骨从重叠(0°) → 扇形展开(±85°) |
| 微弹 | 每根到位后交替±3°微弹 |
| 视角 | 整体 rotateX: -8° → +5° 展示扇面 |

## 扇骨结构

| 元素 | 说明 |
|------|------|
| 扇面(leaf) | 140px宽的图片区域，8张Unsplash图轮流使用 |
| 扇骨(bone) | 14px宽深色木质渐变 |
| 骨端(bone-tip) | 圆形鎏金珠 |
| 强调骨(accent) | 每第3根稍宽(18px) |
| 扇轴(pivot) | 底部鎏金轴心+光环 |
| 绸带(ribbon) | 展开后横向渐显 |

## 技术要点

- `transform-origin: 50% 100%` 是实现"从底部旋转"的关键
- 16根扇骨的 openAngle 均匀分布在 [-85°, +85°]
- 扇骨到达目标角度后有微小弹跳模拟物理手感
- GSAP ScrollTrigger scrub: 1.5 驱动展开
