## CardImageCinematicWipe — 电影划像转场

**5张图片序列 + 4种经典划像 + 胶片颗粒模拟**

### 🎬 划像类型

| 顺序 | 划像 | 切换 | 效果 |
|:---:|------|:---:|------|
| 1 | 线形 Horizontal | 都市→远山 | 垂直线从左向右推进 |
| 2 | 百叶窗 Blinds | 远山→海滩 | 10条竖条前后交错展开 |
| 3 | 圆形 Circle | 海滩→森林 | 圆形从中心向外扩散 |
| 4 | 星形 Star | 森林→沙漠 | 五角星从中心旋转展开 |
| 5 | 菱形 Diamond | 终场 | 菱形装饰揭示收尾 |

### 🔧 技术要点

- **Canvas 双层**：主层渲染图片切换 (ctx.clip 划像遮罩)，上层 60fps 噪点叠加 (mix-blend-mode: overlay)
- **GSAP scrub=1.2**：4段转场分别对应 0-22% / 22-44% / 44-66% / 66-100% 滚动区间
- **百叶窗算法**：每条的局部进度 = `clamp((t - i/N) × N/(N-1), 0, 1)`，确保前后条带自然错开
- **电影边框**：8% 黑边 + `box-shadow` 加深 + 两侧胶片齿孔装饰
- **5张 Unsplash 高清图**：自动预加载，加载完成后初始化渲染
