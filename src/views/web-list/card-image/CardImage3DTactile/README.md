# CardImage3DTactile — CSS 3D 拟物化 · 物理按压交互

## 概述

摒弃简单的 `scale` 缩放，使用 `translate3d` 结合 **7层 box-shadow** 创造比真实物理按钮还要逼真的按压触感。默认状态多层阴影在 Z 轴"堆叠"出厚度，`:active` 时 `translateZ(-8px)` 真实 3D 凹陷 + 阴影同步压缩，`:hover` 微微浮起，GSAP `back.out(1.8)` 弹性回弹——光影与位置的完美同步。

## 核心技术：7层 box-shadow + translateZ

### 阴影厚度堆叠 (默认状态)

```
┌──────────────────────────────────────┐
│  L7: 0 24px 48px rgba(..,.02)  柔光 │ ← 最远扩散
│  L6: 0 16px 32px rgba(..,.04)  环境 │
│  L5: 0 10px 20px rgba(..,.05)  远层 │
│  L4: 0 6px  12px rgba(..,.07)  中远 │
│  L3: 0 4px  8px  rgba(..,.10)  中层 │
│  L2: 0 2px  4px  rgba(..,.12)  近层 │
│  L1: 0 1px  2px  rgba(..,.15)  紧贴 │ ← 最锐利
├──────────────────────────────────────┤
│  inset 0 1px 0 rgba(255,255,255,.25)│ ← 顶部高光
│  ████████████████████████████████████│ ← 按钮表面
└──────────────────────────────────────┘
```

### 三态对比

| 状态 | translateZ | 阴影层数 | blur范围 | offset范围 | 过渡 |
|------|-----------|---------|---------|-----------|------|
| 默认 | 0px | 7层+inset | 2→48px | 1→24px | — |
| :hover | GSAP 微微升起 | 7层+inset | 4→80px | 2→40px | .15s ease-out |
| :active | **-8px** (GSAP) | **5层** (压缩) | **1→10px** | **0→5px** | **.05s** ease-in |

### 按压时的光影变化

```
默认 (浮起):                   按下 (凹陷):
  ████████                      ░░░░░░░░
  ████████  ← 7层阴影厚        ░░░░░░░░  ← 5层阴影薄
  ████████                      ░░░░░░░░
  ════════  表面                 ════════  表面

  translateZ: 0                 translateZ: -8px
  阴影扩散远                     阴影压缩近
  凸起感                         凹陷感
```

### GSAP 增强按压

```javascript
// 按下: 快速陷入
gsap.to(btn, { translateZ: -8, duration: 0.12, ease: 'power2.in' })

// 松开: 弹性回弹 (比真实按钮更Q弹!)
gsap.to(btn, { translateZ: 0, duration: 0.35, ease: 'back.out(1.8)' })
```

### 三种色调

| 色调 | 阴影色 | 氛围 |
|------|--------|------|
| warm | rgba(120,60,20) | 暖木/皮革质感 |
| cool | rgba(40,60,120) | 冷钢/金属质感 |
| neutral | rgba(60,50,40) | 自然石材质感 |

## 技术要点

- 🔑 7层 box-shadow 在 Z 轴"堆叠"出 3D 厚度
- 🔑 `:active` 时阴影偏移/模糊减半 → 接触面增大的错觉
- 🔑 GSAP `translateZ(-8px)` 真实 3D 空间凹陷
- 🔑 `back.out(1.8)` 弹性回弹 — 比真实按钮更有"灵魂"
- 🔑 `transition: box-shadow 0.05s ease-in` 按下瞬间响应
- 🔑 `inset 0 1px 0` 顶部高光增强立体感
- 🔑 三色调 (warm/cool/neutral) 展示不同材质
- 6张卡片 + GSAP ScrollTrigger 场景旋转
