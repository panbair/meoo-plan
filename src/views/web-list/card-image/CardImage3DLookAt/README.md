# CardImage3DLookAt — CSS3 3D 沉浸式视线追踪 (Look-at Effect)

## 概述

让静态 3D 元素仿佛具有生命，能够"注视"用户的鼠标光标。通过 JavaScript 实时计算光标与元素中心的相对位置，动态注入 CSS 变量（`--gx`、`--gy`）到 3D 旋转中，实现视角的实时偏移——1张中央主卡 + 6张环绕卡片同时追踪光标，各有不同的"注视个性"。

## 核心技术：CSS变量桥接 JS → 3D

### 视线追踪管线

```
mousemove 事件
    ↓
计算光标相对视口中心偏移 (-1 ~ 1)
    ↓
lerp 平滑插值 (模拟眼球运动惯性, factor=0.12)
    ↓
中央卡片: CSS变量 --gx/--gy → rotateX/rotateY
环绕卡片: JS构建完整 transform 字符串 (基础定位 + 视线旋转)
    ↓
CSS transition 有机平滑 (不同卡片不同延迟)
    ↓
3D 卡片实时"注视"光标
```

### 技术分层

| 层 | 技术 | 用途 |
|----|------|------|
| 输入层 | `mousemove` 事件 | 获取光标坐标 |
| 平滑层 | `requestAnimationFrame` + lerp | 模拟眼球运动惯性 |
| 输出层 | CSS变量 `--gx`/`--gy` (中央卡) | 桥接 JS 计算到 CSS transform |
| 输出层 | 内联 `transform` 字符串 (环绕卡) | 合并基础3D定位 + 注视旋转 |
| 过渡层 | CSS `transition` | 有机平滑追踪 (0.15s ~ 2.4s) |
| 反馈层 | 光标辉光 + 镜面高光 + 阴影联动 | 增强沉浸感 |

## 7张卡片的注视个性

| 卡片 | 追踪速度 | 最大角度 | 反应距离 | 个性描述 |
|------|---------|---------|---------|---------|
| PRIMARY.GAZE (中央) | 即时 (15ms) | ±35° | 全屏 | 灵敏注视，瞳孔+高光+阴影三层联动 |
| SWIFT.GAZE | 1.0× (0.6s) | ±28° | 全屏 | 快速响应，如同警觉的哨兵 |
| CALM.WATCH | 0.5× (1.2s) | ±20° | 全屏 | 沉稳观察，从容不迫 |
| SHY.PEEK | 0.25× (2.4s) | ±12° | 0.15 阈值 | 害羞窥视，仅在光标靠近时反应 |
| KEEN.STARE | 0.8× (0.75s) | ±25° | 全屏 | 锐利凝视，目光如炬 |
| LAZY.GLANCE | 0.35× (1.7s) | ±14° | 0.08 阈值 | 慵懒一瞥，爱理不理 |
| CURIOUS.TILT | 0.65× (0.92s) | ±22° | 全屏 | 好奇歪头，活泼俏皮 |

## 中央卡片的三层联动

```
┌──────────────────────────┐
│  镜面高光 (glint)         │ ← --glint-x/y, 随视线反向偏移
│  radial-gradient          │   光标在右 → 高光在左
├──────────────────────────┤
│  瞳孔指示器 (pupil)       │ ← --pupil-x/y, 在卡片表面微移
│  发光圆点                 │   如同眼球追踪光标
├──────────────────────────┤
│  阴影平面 (shadow)        │ ← --sx/--sy/--sb, 偏移+模糊联动
│  translate + blur         │   模拟光源固定的投影变化
└──────────────────────────┘
```

## 视觉反馈

| 元素 | 技术 | 说明 |
|------|------|------|
| 光标辉光 | `position: fixed` div | 跟随鼠标的径向渐变光晕 |
| 中央卡片 | CSS变量 rotateX/Y | 即时响应，15ms transition |
| 环绕卡片 | JS完整transform | 各有个性的追踪延迟 |
| 镜面高光 | CSS变量 radial-gradient 偏移 | 光标方向"驱赶"高光到对面 |
| 瞳孔指示器 | CSS变量 top/left + transition | 中央卡片上的小光点 |
| 阴影 | CSS变量 translate + blur | 随注视方向偏移 |

## 技术要点

- 🔑 CSS变量桥接：JS计算 → `--gx`/`--gy` → CSS `rotateX(var(--gx)) rotateY(var(--gy))`
- 🔑 lerp平滑插值 (factor=0.12) 模拟眼球运动惯性
- 环绕卡片在 JS 中构建完整 transform 字符串 (Vue `:style` 无法拆分合并 transform)
- `transition-duration` 动态控制不同卡片的追踪速度
- 距离衰减算法：卡片距离光标越远，注视强度越低
- `reactDistance` 阈值：SHY.PEEK 仅在光标足够近时反应
- 鼠标离开 → 所有卡片缓慢回归正面 (lerp factor=0.04)
- ScrollTrigger 驱动场景深度变化 (卡片随滚动拉近/推远)
