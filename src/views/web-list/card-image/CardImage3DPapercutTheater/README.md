# CardImage3DPapercutTheater — CSS3 3D 纸雕剧场

## 概述

纯 CSS3 3D 实现多层剪纸艺术效果——7层纸张在Z轴上排列，每层有不同形状的 clip-path 镂空窗口（圆形、菱形、六边形、星形、拱门、心形、方窗），窗口内展示 Unsplash 图片。用户竖滚驱动层间距拉开，配合背光穿透和视角旋转，形成温暖的手工纸雕剧场。

## CSS3 3D + CSS 核心结合

| 技术 | 用途 |
|------|------|
| `translateZ(-40→-240)` | 7层纸张Z轴等距排列 |
| `rotateY(±15°)` | 整体旋转展示层次 |
| `clip-path: circle()/polygon()/ellipse()/inset()` | 🔑 各层镂空形状 |
| `mask-image: radial-gradient` | 纸张纹理渐变 |
| `box-shadow: inset` | 镂空边缘柔光 |
| `rotateX(90deg)` | 纸张厚度侧边 |

## 七层剪纸

| 层 | 形状 | clip-path |
|----|------|-----------|
| 0 | 圆窗 | `circle(38%)` |
| 1 | 菱格 | `polygon(50% 5%, 95% 50%, 50% 95%, 5% 50%)` |
| 2 | 六边 | `polygon(50% 0%, 100% 25%, ...)` |
| 3 | 星芒 | 十角星形 polygon |
| 4 | 拱门 | `ellipse(35% 42%)` |
| 5 | 心窗 | 心形 polygon |
| 6 | 方窗 | `inset(8% round 18px)` |

## 动画流程

| 阶段 | 效果 |
|------|------|
| 入场 | 文字淡入 + 场景俯仰复位 |
| 展开 | 7层在Z轴从30%间距 → 100%间距 |
| 视角 | 整体 rotateY 从 +15° → -15° |
| 呼吸 | 每层到位后有微小Z轴弹跳 |
| 背光 | 光源 scale 和 opacity 呼吸 |

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 暖米白 / 手工牛皮纸 / 琥珀光 |
| 氛围 | 温暖、手工感、层次丰富 |
| 字体 | Georgia 衬线（层数） |

## 技术要点

- 7种不同 clip-path 形状表现"手工剪纸"感
- 纸张纹理用 repeating-linear-gradient + mask
- 每层纸张颜色由浅入深递变
- 纸张厚度侧边用 rotateX(90deg) + 渐变
- 背光光源呼吸增强立体层次
