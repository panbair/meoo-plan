# CardImageSwayDance — 摇曳舞动

## 概述

图片如同拥有生命般随用户滚动"跳舞"——横向摇曳、纵向浮动、旋转微倾、呼吸缩放，仿佛在跟随音乐律动。流光粒子在画面中飘浮，营造欢快灵动的青春氛围。

## 核心动画

### 入场动画
- 标题四字逐字弹入（`stagger: 0.07`, `back.out(2.2)`）
- 两侧装饰方块持续旋转
- 节奏指示点从无到有

### 滚动控制动画 (ScrollTrigger)

| 阶段 | 动画 | 描述 |
|------|------|------|
| **Phase A — 摇曳入场** (0→0.42) | `x: 80→0`, `rotation: 5°→0°`, `scale: 0.82→1.0`, `blur: 14→0` | 图片从右侧摇摆滑入中心，逐渐清晰 |
| **Phase B — 舞蹈驻留** (0.42→0.62) | `x: 0→-12→10→0`, `rotation: 0°→-1.2°→1°→0°` | 小幅左右摇摆 + 呼吸缩放(1.0→1.04→1.0) |
| **Phase C — 向左退场** (0.62→0.82) | `x: 0→-75`, `rotation: 0°→-4.5°`, `scale: 1.0→0.84`, `blur↑` | 图片向左摇摆滑出并模糊化 |
| **Phase D — 下一帧入场** (0.74→) | 同 Phase A | 新图片从右侧摇摆入场 |

### 辅助动画
- Canvas 流光粒子系统：彩色流线向上飘浮，带正弦波摆动
- 节奏指示点：5个圆点随当前帧高亮
- 光扫层：一道高光从图片表面扫过
- 背景光斑缓慢漂移
- 两侧装饰方块360°旋转

## 设计风格

| 要素 | 说明 |
|------|------|
| 色调 | 珊瑚橙 / 柑橘金 / 薄荷绿 / 薰衣草紫 / 蜜桃粉 |
| 背景 | 暖白到蜜桃色的柔和多层渐变 |
| 氛围 | 欢快、灵动、青春、生命力 |

## 技术要点

- Vue 3 Composition API + `<script setup lang="ts">`
- GSAP ScrollTrigger 滚动驱动动画（`scrub: 1.3`）
- Canvas 2D 流光粒子系统（5色调色板）
- 全部 DOM 引用通过 Vue 3 `ref<T>()` 获取
- 完整动画清理（`onUnmounted` 清理所有 GSAP/ScrollTrigger/rAF）
