# CardImageLightningStrike - 闪电劈裂·雷击碎片重组

## 效果描述

图片被闪电劈裂为6×5碎片，碎片从中心向外放射状弹飞。SVG闪电路径（锯齿形）从撞击点向四周延伸。随滚动推进，闪电消退，碎片沿电弧路径回收归位，伴随辉光闪烁。

## 技术实现

### 核心动画阶段

1. **闪电劈裂** (初始状态)
   - 6×5碎片从中心向外弹飞
   - 弹飞方向和力度基于角度和距离
   - 碎片带旋转和缩放

2. **SVG闪电路径**
   - 锯齿形闪电路径生成
   - 多条分支闪电
   - 不同颜色和线宽

3. **碎片回收** (滚动驱动)
   - 碎片反向归位
   - 辉光逐层消退

4. **闪光爆发** (末段)
   - 全屏白色闪光

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SVG 闪电路径生成
- SCSS 样式

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 55%' | 元素顶部到达视口55%时结束 |
| scrub | 1 | 平滑系数 |

## 视觉效果

- 6×5碎片放射状弹飞
- SVG锯齿闪电路径
- 多分支闪电效果
- 电弧辉光闪烁
- 全屏闪光爆发
