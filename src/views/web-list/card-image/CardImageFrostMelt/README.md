# CardImageFrostMelt - 冰霜消融·水滴凝结显影

## 效果描述

图片表面覆盖一层厚重冰霜，冰晶颗粒随机分布。随滚动推进，扫描热源从上到下融化冰层，冰晶消融为水滴沿表面滑落，蒸汽从表面升起，最终露出清晰图片。

## 技术实现

### 核心动画阶段

1. **冰霜覆盖** (初始状态)
   - 图片被半透明冰霜层遮盖
   - 随机分布冰晶颗粒（大小不一）
   - 水滴初始隐藏

2. **冰霜消融** (滚动驱动)
   - 冰霜层透明度逐渐降低
   - 冰晶颗粒逐个收缩消失
   - 水滴出现并向下滑落

3. **蒸汽升腾** (中后段)
   - 蒸汽效果从表面升起
   - 半透明蒸汽层

4. **清晰显现** (末段)
   - 冰霜完全消融
   - 闪光确认完成

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- SCSS 样式
- CSS 冰晶/水滴粒子

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 10%' | 元素顶部到达视口10%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 冰霜覆盖层 + 随机冰晶
- 冰晶消融动画
- 水滴凝结滑落
- 蒸汽升腾效果
- 冷暖色调渐变
