## CardImageFragmentAssembly — 碎片拼图聚合 (v2)

### 概念

8 张不同主题的图片被切成 48 个不规则碎片（8×6 网格），散落在 3D 空间中。滚动时所有碎片像被中心磁力吸引，逐渐聚合成一张完整的主图。

### 多层级架构

| 层级 | 内容 | 实现 | z-index |
|------|------|------|---------|
| Layer 1 | 50 个背景粒子 | Canvas 呼吸光点 | 0 |
| Layer 2 | 碎片舞台 | `background: inherit` + 48 clip-path 碎片 | 2 |
| Layer 3 | 随机图覆盖层 | 每碎片从 8 图池中独立选取，opacity 1→0 | — |
| Layer 4 | 碎片边框 | 组装后显现淡蓝边框，hover 发光 | — |
| Layer 5 | 磁力场 Canvas | `quadraticCurveTo` 贝塞尔螺旋场线 | 3 |
| Layer 6 | 中心光晕 | radial-gradient 50vw，组装完成时浮现 | 4 |
| Layer 7 | 进度指示器 | X/48 FRAGMENTS + 渐亮进度条 | 15 |
| Layer 8 | 内容覆盖 | 标题 blur→clear + 分隔线 scaleX | 14 |

### 核心技术（v2 改进）

| 技术 | 实现细节 |
|------|----------|
| **共享顶点网格** | `9×7=63 个共享顶点`，边框顶点锁定不 jitter，相邻碎片共用边界顶点 → 完美无缝拼接 |
| **jigsaw jitter** | 内部交点 ±2.4% 随机偏移，外框顶点保持方正 |
| **bg:inherit 拼图** | 48 片各自继承舞台背景，仅通过 clip-path 裁剪区域不同 |
| **磁力曲线** | 前 55% smoothstep 慢移 → 后 45% `1-(1-p)³·⁵` 磁力加速 |
| **磁场 Canvas** | lighter 合成模式，贝塞尔螺旋线，奇偶行列交替螺旋方向 |
| **定位 stagger** | 中心碎片 delay=0 → 边缘 delay=0.5，同心波扩散聚合 |
| **确定性 PRNG** | 顶点网格和碎片参数均使用固定种子生成 |

### 视觉流程

```
p=0:   48 碎片散落 3D 空间（随机图 mosaic），磁场线可见
p=0.3: 中心碎片开始归位，随机图开始褪色
p=0.55: 半数碎片就位，磁场线峰值，中心光晕渐显
p=0.85: 边缘碎片最后一波加速归位，碎片边框浮现
p=1:   所有碎片完美拼接成主图，中心光晕饱满
```
