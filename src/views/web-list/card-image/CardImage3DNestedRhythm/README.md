# CardImage3DNestedRhythm — CSS3 3D 空间嵌套 · 节奏差动画

## 概述

打破单层 3D 局限，用 `transform-style: preserve-3d` 层层传递构建"俄罗斯套娃"式嵌套 3D 空间。外层 Y 轴慢转、中层 X 轴中速反向、内核双轴快速交替 — 三层嵌套以不同速度/方向/轴旋转，形成复杂的"节奏差"，极大增强视觉层次感。

## 核心概念：三层嵌套 + 节奏差

### preserve-3d 传递链

```
.nr-scene (perspective: 1200px)
  └── .nr-level1 (preserve-3d) ← 🔑 外层旋转 + 传递3D
        ├── 6张外层卡片 (rotateY translateZ 340px)
        └── .nr-level2 (preserve-3d) ← 🔑 继承外层3D + 自身旋转 + 传递
              ├── 4张中层卡片 (rotateX translateZ 200px)
              └── .nr-level3 (preserve-3d) ← 🔑 继承两层3D + 自身旋转
                    └── 2张内核卡片 (rotateY translateZ 80px)
```

每一层的 `preserve-3d` 确保子元素继承父级的 3D 变换空间，形成真正的 3D 嵌套。

### 节奏差参数

| 层级 | 卡片数 | 排列方式 | 旋转轴 | 速度倍率 | 方向 | 6阶段完整圈数 |
|------|--------|---------|--------|---------|------|-------------|
| 外层 Layer1 | 6张 | Y轴环 (60°间隔) | Y | 1× | ↻ 正向 | 1 圈 |
| 中层 Layer2 | 4张 | X轴环 (90°间隔) | X | 3× | ↺ **反向** | 3 圈 |
| 内核 Layer3 | 2张 | Y轴对面 (180°间隔) | Y+X 双轴 | 5× | ↻ 正向 | Y:5圈 X:3圈 |

### 节奏差的四个维度

```
     维度         外层          中层          内核
  ─────────────────────────────────────────────────
  空间轴          Y             X            Y+X
  时间倍率        1×            3×           5×
  方向            正向 ↻        反向 ↺       正向 ↻
  嵌套深度        1层           2层          3层
```

### 合成运动复杂度

```
内核的实际运动 = 
  外层Y旋转(1×) 
  + 中层X反向旋转(3×) 
  + 内核Y+X交替旋转(5×)
  = 极其复杂的3D运动轨迹
```

中层卡片 → 在外层Y旋转基础上叠加自身X反向旋转
内核卡片 → 在外层+中层基础上叠加双轴快速旋转

## 卡片尺寸递减

| 层级 | 宽度 | 高度 | 视觉比例 |
|------|------|------|---------|
| 外层 | 240px | 160px | 100% |
| 中层 | 160px | 110px | 67% |
| 内核 | 100px | 70px | 42% |

尺寸递减 + 深度嵌套 = 自然的"套娃"空间感。

## 动画流程

| 滚动 | 外层 rotateY | 中层 rotateX | 内核 rotateY | 内核 rotateX |
|------|-------------|-------------|-------------|-------------|
| 0→1 | 0° → 60° | 0° → -180° | 0° → 300° | 0° → 180° |
| 1→2 | 60° → 120° | -180° → -360° | 300° → 600° | 180° → 360° |
| ... | ... | ... | ... | ... |
| 5→6 | 300° → 360° | -900° → -1080° | 1500° → 1800° | 900° → 1080° |

## 技术要点

- 🔑 `preserve-3d` 三层传递链：scene → level1 → level2 → level3
- 🔑 子级自动继承父级 3D 变换，无需手动计算合成运动
- 🔑 节奏差四维度：轴不同 × 速度不同 × 方向不同 × 深度不同
- 🔑 中层反向旋转与内外层形成"对抗"，增强视觉张力
- 🔑 内核双轴旋转创造最复杂的运动轨迹
- 卡片尺寸逐层递减，强化空间嵌套感
- `backface-visibility: hidden` 防止卡片背面穿透
- `will-change: transform` 每层独立GPU加速
- GSAP ScrollTrigger scrub 驱动全部旋转
