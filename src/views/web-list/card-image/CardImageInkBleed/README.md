# CardImageInkBleed — 水墨晕染

> **从未有过的组合**：墨滴在宣纸上扩散 × 边缘羽化 × 多墨点同时晕开

## 概念

图片如一滴滴浓墨落在湿润宣纸上。5 个着墨点从随机位置同时向外不规则扩散，墨迹边缘呈锯齿状纤维纹理（SVG feDisplacementMap 模拟毛细扩散），颜色从墨心浓黑渐淡至边缘无痕。扩散区域最终相互重叠合并，完整图片从墨色中浮现。

---

## 图层架构（Z 轴 → 下到上）

| Z-Index | 图层 | 说明 |
|:---:|------|------|
| 0 | SVG 滤镜定义 | `feTurbulence` → `feDisplacementMap` 扩散纹理 |
| 1 | 宣纸底色 | `#f3ede4` 米白渐变 + CSS 纤维点阵 + 长丝纹理 |
| 2 | 图片揭示层 | `mask-image: url(#ink-reveal-mask)` 蒙版控制可见区域 |
| 3 | 墨色叠层 | 径向渐变 `multiply` 混合，模拟初始浓郁墨色氛围 |
| 4 | 四角暗框 | vignette，加重纸边墨色，随晕染消退 |
| 8 | 文字信息 | 印章 + 标题 + 分隔线 + 描述 |
| 10 | 飞溅粒子 | 18 颗墨点碎屑，闪现后消散 |

## 核心技术

### SVG 蒙版策略

```
mask (id="ink-reveal-mask")
  ├── <rect> fill="black"           ← 全黑底 → 所有区域初始隐藏
  └── <g filter="url(#ink-edge-distort)">
        ├── circle r=0→0.55  ← 5 个径向渐变圆同时扩大
        ├── circle r=0→0.55
        ├── ...
```

- `maskUnits="objectBoundingBox"`：蒙版坐标归一化到 0-1
- 圆 `fill="url(#ink-spot-grad)"`：中心 `opacity=1` → 边缘 `opacity=0`
- 5 个圆各 `r` 最终 = 0.55（55% 画幅）→ 重叠全覆盖

### SVG 滤镜链

```
SourceGraphic (白色圆形)
  │
  ▼
feTurbulence
  type=fractalNoise  baseFrequency=0.032  numOctaves=5  seed=17
  → 生成模拟宣纸纤维的不规则噪点图
  │
  ▼
feDisplacementMap
  in=SourceGraphic  in2=纤维噪点图  scale=18
  → 沿 R/G 通道偏移像素，产生锯齿状扩散边缘
```

### GSAP 动画时间线（ScrollTrigger scrub）

| 进度 | 事件 | 参数 |
|:---:|------|------|
| 0.00 | 第 1 滴墨 (左上) 开始扩散 | `r: 0→0.55, ease: power2.out` |
| 0.14 | 第 2 滴墨 (中上) | 错开启动 |
| 0.28 | 第 3 滴墨 (右中) | — |
| 0.42 | 第 4 滴墨 (左下) | — |
| 0.56 | 第 5 滴墨 (右下) | — |
| 0.05→0.70 | 墨色叠层消退 | `opacity: 0.85→0, power3.in` |
| 0.10→0.70 | 四角暗框消退 | `opacity: 0.65→0` |
| 0.05→0.45 | 18 颗飞溅粒子闪现 | `scale: 0.3→1.0→1.8, opacity: 0→0.75→0` |
| 0.45→0.95 | 文字信息渐显 | `opacity 0→1, y 30→0` |

### 5 个着墨点分布

| # | 归一化坐标 | 视觉位置 |
|:---:|-----------|------|
| 1 | (0.22, 0.32) | 左上区域 |
| 2 | (0.58, 0.18) | 顶部中央 |
| 3 | (0.78, 0.52) | 右侧中部 |
| 4 | (0.32, 0.66) | 左下区域 |
| 5 | (0.60, 0.72) | 右下区域 |

每个墨点 r=0.55 时水平覆盖约 55% 画幅宽度，5 点重叠确保 100% 覆盖无死角。

## 视觉要点

### 色系
| 元素 | 颜色 | 说明 |
|------|------|------|
| 宣纸底色 | `#f3ede4 → #ede4d5` | 暖米白渐变 |
| 纸纤维纹理 | `rgba(160,130,90,0.04~0.12)` | 4 层径向点阵 + 2 层线性丝纹 |
| 墨色叠层 | `rgba(24,18,12,0→0.8)` | 中心淡边缘浓，multiply 混合 |
| 飞溅粒子 | `rgba(30,20,10,0→0.85)` | 径向渐变小球 |
| 印章 | `rgba(120,30,20,0.55)` | 朱砂红圆形 |
| 标题文字 | `rgba(255,252,248,0.95)` | 三重 text-shadow 发光 |

### 字体
- 印章：`KaiTi/楷体`，传统印篆风格
- 标题：`SimSun/宋体/Noto Serif SC`，中式衬线
- 副标题/描述：系统默认，`letter-spacing: 0.22em` 宽松字距
