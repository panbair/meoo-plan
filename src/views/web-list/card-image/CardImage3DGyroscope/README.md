# CardImage3DGyroscope — CSS3 3D 图片星盘仪

## 概述

纯 CSS3 3D 将陀螺仪（万向节）重新设计为一个**图片展示系统**——三环嵌套旋转 + 多层级图片布局。不再是简单的机械结构，而是每个层级都融入了图片元素：外环4幅全景面板、中环6幅圆形缩略图、内环核心大图 + 6张卫星图、以及8颗在3D空间中独立轨道运行的自由卫星卡片。背景还有一张超大半透明星云图。

## CSS3 3D 核心技术

| 属性 | 值 | 用途 |
|------|-----|------|
| `perspective` | 700px | 3D场景透视 |
| `transform-style: preserve-3d` | 全层级 | 嵌套3D空间 |
| `rotateX(360°)` | 外环 | 带4幅全景面板旋转 |
| `rotateY(540°)` | 中环 | 带6幅缩略图旋转 |
| `rotateZ(720°)` | 内环 | 带核心图+6卫星旋转 |
| `transform-origin: 50% <radius>` | 缩略图/卫星 | 绕环中心旋转定位 |
| `translateZ` + `x/y` | 自由卫星 | 独立3D轨道运动 |

## 动画流程

| 元素 | 动画 |
|------|------|
| 外环+4面板 | rotateX: 0→360° |
| 中环+6缩略图 | rotateY: 0→540° |
| 内环+核心+6卫星 | rotateZ: 0→720° |
| 8颗自由卫星 | 各自3D轨道运动（X/Y/Z三轴） |
| 背景星盘 | translateZ: -500→-150 + opacity: 0.2→0.7 |
| 整体 | rotateX: 12°→-8° |

## 技术要点

- 缩略图和卫星图用 `transform-origin: 50% <radius>` + `rotate(var(--angle))` 定位在环上
- 自由轨道卫星的3D运动通过同时驱动 `x`, `y`, `translateZ` 实现
- 核心大图的标签随 scroll 切换（银河→极光→星空→日出→花海→麦田）
- 背景星盘是一张大图 + radial-gradient 遮罩制造渐隐边缘
- 4层图片系统让简单的陀螺仪变成一个丰富的图片浏览器
