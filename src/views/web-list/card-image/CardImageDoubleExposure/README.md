# CardImageDoubleExposure — 双重曝光融合

> **两张图片叠加曝光 × 滚动控制混合度 × 轮廓遮罩融合**

## 概念

模拟胶片相机的双重曝光（Double Exposure）摄影技术，将前景人像图片与背景风景图片叠加融合。滚动时，前景人像的暗部区域（剪影轮廓）逐渐透明化，露出背后的风景全貌。整个过程像一张胶片从暗房慢慢显影，最终呈现清晰的风景照片。

**视觉叙事**：
- 初始状态：人像剪影内填充风景色彩，暗部轮廓神秘，多层叠加营造胶片质感
- 滚动过程：剪影溶解，混合模式从 multiply → soft-light → screen 逐步退场，风景从朦胧到清晰
- 最终状态：风景完全展露，人像仅存微弱的轮廓残影，文字信息渐入

## 图层架构（Z 轴 → 下到上）

| Z-Index | 图层 | 说明 |
|:---:|------|------|
| 0 | SVG 滤镜定义 | 亮度提取+反转+对比增强蒙版、胶片颗粒纹理、边缘柔光、动态模糊 |
| 1 | **风景背景** | 全彩风景图，初始偏暗模糊（brightness:0.55 + blur），随滚动恢复清晰 |

| 5 | 色调着色层 | 多层渐变叠加（multi：暗调偏蓝色褐色），滚动消退 |

| 15 | **胶片颗粒** | Canvas 实时随机噪点，mix-blend-mode:overlay，模拟胶片颗粒 |
| 20 | 文字信息 | 标题/副标题/描述，滚动结尾渐入 |

## SVG 蒙版策略

### 亮度提取 + 反转 + 对比度增强

```
SourceGraphic（人像图）
  → feColorMatrix[亮度权重: 0.2126R + 0.7152G + 0.0722B]
  → feColorMatrix[反转: -1×RGB + 1]
  → feComponentTransfer[对比度: slope=2.2, offset=-0.45]
  → 输出蒙版
```

**蒙版效果**：
- 人像暗部（头发、眼睛、阴影）→ 亮度提取=低 → 反转=高 → 白色=**不透明**，保留剪影
- 人像亮部（皮肤高光、白色背景）→ 亮度提取=高 → 反转=低 → 黑色=**透明**，露出风景

### 蒙版在 CSS 中的应用

```css
.de-fg-layer {
  mask-image: url(#exposure-mask);
  -webkit-mask-image: url(#exposure-mask);
}
```

蒙版内包含两个元素：
1. `rect` 白色覆盖层 → 控制整体可见区域（GSAP 控制 opacity）
2. `image` 人像图经过 filter → 决定哪部分保持不透明

实际效果 = `white_rect × opacity` ∩ `inverted_portrait_mask`

## GSAP 动画时间线（5 阶段）

| 阶段 | 进度 | 动画内容 |
|:---:|:---:|------|
| **阶段1** | 0–12% | 初始双曝光态稳固：背景微亮、人像微缩、混合加固、暗角微减 |
| **阶段2** | 12–35% | 开始溶解：人像蒙版透明度 1→0.7、混合 multiply→soft-light、边缘发光初显、背景亮度恢复 |
| **阶段3** | 35–60% | 主要转场：人像快速消失 0.7→0.15、混合切换 soft-light→screen、边缘发光先闪后退、漏光峰值、背景完全清晰 |
| **阶段4** | 60–85% | 残影保留：背景完美、人像仅存 4% 鬼影、暗角微回弹、漏光二次闪过 |
| **阶段5** | 85–100% | 文字入场：标题/副标题渐入、暗角稳定、Ken Burns 收束 |

**ScrollTrigger 配置**：`start: top 85%`、`end: bottom 15%`、`scrub: 1.2`

## 视觉要点

- **色调**：暗黑胶片风，底色 `#0a0a0c`，暖橙+冷蓝双漏光
- **字体**：中文标题使用楷体/衬线体表达艺术感，英文标签使用等宽无衬线
- **胶片质感**：Canvas 实时颗粒噪声（60fps 刷新）+ CSS overlay 混合
- **暗角系统**：底层 radial-gradient vignette + 顶层 SVG vignette 双重暗角
- **动态模糊**：背景图初始 `blur(1px)` 制造景深差，滚动时逐渐清晰
