# CardImagePhoenixRise - 凤凰涅槃·烈焰重生

## 效果描述

图片如凤凰涅槃般从灰烬中浴火重生。碎片初始为灰暗灰烬状态，火焰从底部向上吞噬。碎片在烈焰中点燃发光，逐步从灰色恢复为原始色彩并归位，形成凤凰展翅般的重生视觉。

## 技术实现

### 核心动画阶段

1. **灰烬状态** (初始状态)
   - 碎片灰度化 + 低亮度
   - 暗色灰烬背景
   - 底部火焰待燃

2. **烈焰吞噬** (前段)
   - 火焰从底部向上蔓延
   - 碎片逐行被火焰点燃
   - 发光效果

3. **色彩重生** (滚动驱动)
   - 灰度逐步恢复为彩色
   - 亮度逐步恢复
   - 碎片归位

4. **凤凰展翅** (末段)
   - 全部碎片归位
   - 光芒爆发
   - 闪光收尾

### 技术栈

- Vue 3 Composition API
- GSAP + ScrollTrigger
- CSS grayscale/brightness 滤镜
- SCSS 样式
- 火焰粒子效果

### ScrollTrigger 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trigger | parent | 触发器元素 |
| start | 'top 80%' | 元素顶部到达视口80%时开始 |
| end | 'top 20%' | 元素顶部到达视口20%时结束 |
| scrub | 1.8 | 平滑系数 |

## 视觉效果

- 灰烬灰度初始状态
- 烈焰自下而上蔓延
- 碎片点燃发光
- 灰度到彩色渐变重生
- 凤凰展翅光芒爆发
