# CardImage3DExplodedView — CSS3 3D 图层炸裂视图

## 概述

纯 CSS3 3D 构建的"爆炸视图"——同一张图片的5个深度切片在Z轴上分离展开。初始状态所有层重叠为完整图片，用户竖滚驱动各层沿Z轴分散炸开，每层带有独特的色调覆盖和标签，层与层之间有发光的Z轴连接线。

## CSS3 3D 核心技术

| 属性 | 值 | 作用 |
|------|-----|------|
| `perspective` | 800px | 3D透视距离 |
| `transform-style` | `preserve-3d` | 保持层级3D空间 |
| `translateZ(n)` | 0→240px | 图层Z轴分离 |
| `rotateX/Y` | ±4-6° | 各层微小倾斜增加立体感 |
| `rotateX/Y` | 场景整体 | scroll驱动视角旋转 |

## 动画流程

| 滚动进度 | 爆炸状态 | 效果 |
|---------|---------|------|
| 0→1 | 初始重叠 | 五层完全堆叠，看起来像一张图 |
| 1→2 | 开始分离 | translateZ逐渐拉开，各层倾斜显现 |
| 2→3 | 核心展开 | 核心层scale略大，四周围层弹跳就位 |
| 3→4 | 全部展开 | 五层在Z轴完全分离，场景旋转展示深度 |
| 4→5 | 微弹回弹 | 每层有小幅Z轴弹跳，增加物理感 |

## 五层结构

| 层 | 名称 | Z偏移 | 色调覆盖 |
|----|------|-------|---------|
| 0 | 前景层 | 0px | 珊瑚粉 |
| 1 | 中前景 | 60px | 电光蓝 |
| 2 | 核心层 | 120px | 金色（高亮） |
| 3 | 中后景 | 180px | 极光绿 |
| 4 | 背景层 | 240px | 暮光紫 |

## 特色元素

- **连接线系统**：层与层之间有半透明发光的Z轴引线，强化纵深感知
- **核心层高亮**：中间层（核心层）有金色发光边框和微放大效果
- **图例指示器**：底部实时显示当前激活层高亮
- **场景旋转**：整体场景随scroll旋转视角，让Z轴分离更直观可见

## 技术要点

- 纯 CSS3 3D 实现 Z 轴分层爆炸效果
- GSAP ScrollTrigger 驱动分离（`scrub: 1.5`）
- 5层共享同一张 Unsplash 图片，通过 tint 覆盖区分层次
- 每层独立 translateZ + rotateY + rotateX 微调
- 连接线采用 CSS 伪元素 + 3D 变换
