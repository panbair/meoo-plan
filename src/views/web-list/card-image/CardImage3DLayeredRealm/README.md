# CardImage3DLayeredRealm — 三重层境画廊

## 概述
12张照片分布在3个独立的空间平面（层境）上，各层在Z轴上有420px间距。近景层照片最大最清晰，远景层被大气散射柔化。滚动驱动各层以不同速度水平漂移——近层快（±180px）、中层中（±90px）、远层慢（±30px）——产生强烈的多层级差速视差。

## 核心动画
```
3个空间平面 差速水平漂移：
  近景层 (Z=0, scale=1.0)    → X漂移 ±180px, Y漂移 ±25px ⚡快
  中景层 (Z=-420, scale=0.72) → X漂移 ±90px,  Y漂移 ±15px 🌀中
  远景层 (Z=-840, scale=0.5)  → X漂移 ±30px,  Y漂移 ±8px  🌫慢

层间有大气散射雾层分隔 + 各层卡片独立悬浮动画
```

## 与 CardImage3DGalleryFloor 的对比

| 维度 | GalleryFloor (原版) | LayeredRealm (新版) |
|------|-------------------|---------------------|
| **空间模型** | 一维Z轴走廊 | 三维层境（X/Y/Z皆可变） |
| **深度线索** | 亮度+透明度线性衰减 | 层间大气散射+缩放+对比度+饱和度 |
| **运动方式** | translateZ 整体推进 | translateX/Y 各层差速漂移 |
| **Y轴变化** | 无 | 每层不同Y基准 + 各照片独立Y偏移 |
| **缩放编码** | 统一透视缩放 | 每层独立基础缩放(1.0/0.72/0.5) |
| **倒影/光瀑** | 镜面地板 scaleY(-1) | 底部光瀑 rotateX(35deg) 渐变投射 |
| **卡片动画** | 滚动联动 rotateY/亮度 | 独立CSS悬浮动画(每层不同相位) |
| **层间分隔** | 无 | 2层大气散射雾(blur 40px) |
| **scrub** | 1.2 | 1.4(漂移运动需更平滑) |

## 视觉元素
- 深空渐变背景 + 2层星光（正常+微弱）
- 3个空间平面：每层4张照片，共12张
- 卡片光晕（aura）：彩色径向渐变，远景最淡
- 光瀑（beam）：底部向下投射柔光（替代传统镜面倒影）
- 2层大气散射雾（haze）物理分隔各层
- 前景暗角 + 深度雾
- 每层卡片独立的CSS悬浮动画

## 技术要点
- CSS 3D: `perspective:1100px` + `transform-style:preserve-3d` + `translateZ` 分层
- GSAP动画平面容器的x/y属性，保留CSS translateZ深度
- ScrollTrigger scrub:1.4 驱动三层差速漂移
- 深度编码四要素：缩放 + 对比度 + 饱和度 + 亮度
- 每层光晕颜色可独立配置（近=暖色高饱和，远=冷色低饱和）
- 大气散射雾用radial-gradient + blur实现体积光感
- 响应式：移动端所有卡片尺寸等比缩小
