# CardImage3DStereoFlux — CSS3 3D 立体视差流动

## 概述

3条图片轨道在3D空间中同时流动，通过不同的 Z 深度、流动速度和方向，营造极其强烈的立体视差效果。远景缓慢上浮、中景中速下沉、近景快速上浮 — 多轨道逆向运动 + translateZ 深度差 = 爆棚的立体感。

## 核心概念：3轨道立体流动

### 轨道参数

| 轨道 | translateZ | 水平偏移 | 速度倍率 | 方向 | 卡片数 | 视觉效果 |
|------|-----------|---------|---------|------|--------|---------|
| 远景 FAR | -300px | -22vw | 0.5× | ↑ 上浮 | 4张 | 最小、最模糊、蓝色雾化 |
| 中景 MID | 0px | +8vw | 1× | ↓ 下沉 | 4张 | 中等大小、正常清晰度 |
| 近景 NEAR | +200px | +24vw | 2× | ↑ 上浮 | 4张 | 最大、最清晰、镜面高光 |

### 立体感来源

```
近景 (Z:+200, 快速上浮)  ┐
                          │
中景 (Z:0, 中速下沉)      ├─ 3条轨道同时流动
                          │  不同速度 + 不同方向
远景 (Z:-300, 慢速上浮)  ┘  = 极强立体视差
```

**关键设计**：中景与近/远景方向相反（下沉 vs 上浮），进一步强化了层次间的对比，使立体感更加突出。

## 深度视觉处理

| 处理 | 远景 | 中景 | 近景 |
|------|------|------|------|
| 卡片尺寸 | 180×120px | 220×150px | 270×180px |
| 图片滤镜 | brightness(1.1) blur(1px) saturate(0.8) | brightness(1.02) | brightness(0.95) contrast(1.05) |
| 大气雾化 | 蓝色渐变 fog 覆盖 | — | — |
| 镜面高光 | — | — | radial-gradient glint |
| rotateX | +8° (仰视) | -4° (微俯) | -10° (俯视) |

## 动画流程

滚动时3条轨道同时流动 (scrub: 1.4)：

| 轨道 | 起始Y | 终点Y | 位移量 | 速度感 |
|------|-------|-------|--------|--------|
| 远景 | 0vh | -45vh | 45vh↑ | 缓慢 (0.5×) |
| 中景 | 0vh | +50vh | 50vh↓ | 适中 (1×) |
| 近景 | 0vh | -80vh | 80vh↑ | 快速 (2×) |

## 技术要点

- 🔑 3轨道立体流动：不同 translateZ × 不同流速 × 不同方向 = 极强纵深
- 🔑 中景与近/远景反向流动 → 层次对比最大化
- 🔑 远景大气处理：blur + brightness + 蓝色雾化
- 🔑 近景临场处理：contrast + 镜面高光
- 每条轨道使用 flex column + gap 排列，GSAP 驱动整条轨道位移
- `backface-visibility: hidden` 防止流动过程中的视觉异常
- `will-change: transform` 确保GPU加速流畅
- 12张 Unsplash 图片均匀分布在3条轨道上
