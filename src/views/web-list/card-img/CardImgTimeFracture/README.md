# CardImgTimeFracture 时间碎裂

> 图片分裂成不同"时间线"碎片，每片有独立播放速度、色温和模糊度 — 时间流逝的可视化

## 核心效果

### ⏳ 全新视觉概念
- **时间切片**：图片被切割成 8 个不规则条带，每条代表一个"时间线"
- **异步运动**：各切片以不同速度做 Y 轴位移，模拟时间流速差异
- **色温渐变**：过去（蓝冷调）→ 现在（中性）→ 未来（暖金调）
- **模糊层级**：越远离"当前时间"的切片越模糊
- **时间回归**：最终所有切片同步归位，时间线统一

### 动画阶段

| 阶段 | 滚动范围 | 效果 |
|------|---------|------|
| 时间静止 | 0-15% | 完整图片，叠加微妙的扫描线 |
| 时间碎裂 | 15-45% | 图片沿竖向切割成8片，各片开始异速偏移 |
| 时间流逝 | 45-75% | 切片速差最大化 + 色温分离 + 边缘模糊 |
| 时间回归 | 75-100% | 切片减速归位，色温统一，图片复原 |
