# CardImgNovaBirth 超新星诞生

> 图片从奇点爆发，Canvas粒子云聚合成像 — 全站最震撼的图片揭示动画

## 核心效果

### 🌟 超越现有组件的创新点
- **Canvas 粒子系统**：200个粒子从中心爆发，按引力场轨迹运动，最终聚合成图片轮廓
- **SVG 滤镜链**：feTurbulence + feDisplacementMap 实现星云扭曲，随滚动消退
- **4阶段导演级时间线**：奇点脉冲 → 粒子爆发 → 星云凝聚 → 图片显现
- **双层视差**：前景粒子 + 背景星云各自独立运动速度
- **动态色相旋转**：粒子颜色从蓝→紫→金随进度变化

### 动画阶段

| 阶段 | 滚动范围 | 效果 |
|------|---------|------|
| 奇点脉冲 | 0-15% | 中心光点呼吸闪烁，周围暗色 |
| 粒子爆发 | 15-45% | 200颗粒子从中心向外飞散，带拖尾和旋转 |
| 星云凝聚 | 45-75% | 粒子被反向引力牵引，开始聚合成图片形状 |
| 图片显现 | 75-100% | 粒子消散，SVG扭曲消退，完整图片清晰呈现 |

## 技术实现

| 技术 | 说明 |
|------|------|
| Vue 3 Composition API | 响应式组件架构 |
| GSAP ScrollTrigger | 滚动驱动4阶段时间线 |
| Canvas 2D API | 粒子系统渲染（200粒子 + 引力场） |
| SVG Filters | feTurbulence + feDisplacementMap 星云扭曲 |
| CSS 3D Transforms | 多层视差 + 深度感 |

## 性能
- Canvas 使用 `visibilitychange` 自动暂停
- 粒子数量可配置，移动端自动降至100
- `will-change: transform` 硬件加速
