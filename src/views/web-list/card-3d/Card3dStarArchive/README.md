# Card3dStarArchive - 星际档案馆

## 概述
颠覆传统圆形3D相册的创新设计。12张照片以 **4列×3行×3层深度** 的悬浮矩阵排列在深空中，远非圆环排列。滚动时整个档案库在3D空间中旋转变换视角，粒子在照片间以星图连线方式流动，如同操控全息星际数据档案馆。

## 核心创新点

- **3D悬浮矩阵布局**：照片按 X、Y、Z 三轴分布，形成立体数据网格，不是任何形式的圆形/环形
- **层深系统**：3层深度（前景/中景/远景），每层有不同的初始 Z 值与透明度
- **视角变换**：滚动时整个矩阵从平铺观察角度旋转到俯视透视角度（rotateX -45° + rotateY 15°）
- **星图连线**：照片之间绘制虚线连线，如同星座图，增强星际感
- **深度指示器**：右侧实时显示当前探索的层深（前景→中景→远景）
- **散开涟漪**：滚动时卡片向外非均匀散开+微旋转，产生翻页涟漪效果

## 视觉效果

- 🌌 深空星云背景（3层模糊径向渐变 + 动画漂移）
- ✨ 60颗闪烁星空粒子
- 🎴 12张真实Unsplash太空照片（星云/极光/星系/行星等）
- 🔗 照片间虚线粒子连线（星座效果）
- 🖱️ 悬停：照片放大发光+向前浮动 120px
- 📊 SVG环形进度条
- 🔽 底部滚动提示箭头
- 📏 右侧深度层指示器

## 技术细节

- **框架**：Vue 3 + TypeScript + `<script setup>`
- **动画**：GSAP 3 + ScrollTrigger（scrub: 1.8）
- **3D**：CSS transform-style: preserve-3d + perspective(2000)
- **粒子**：Canvas 2D（100个彩色粒子 + 3D透视投影）
- **连线**：SVG line + gsap.ticker 实时同步位置
- **清理**：onUnmounted 完整清理 ScrollTrigger / Timeline / Canvas / GSAP

## 与其他组件的区别

| 对比维度 | CardImage3DAlbum（旧） | Card3dStarArchive（新） |
|---------|----------------------|------------------------|
| 布局模式 | 圆柱体环绕旋转 | **3D矩阵网格 × 层深** |
| 照片排列 | 10张等距环形 | 12张 X-Y-Z 三轴分布 |
| 滚动效果 | 圆柱自转 | **整体矩阵倾斜透视变换** |
| 连线系统 | 无 | **星座虚线实时跟踪** |
| 深度感知 | 光照衰减模拟 | **真实Z轴层深 + 指示器** |
