# Card3dConstellationMap - 星座星图

## 概述
颠覆所有常规3D相册模式。8张照片挂在 **不规则星座星点位置**，形成独特的猎户座+天狼星区域星图。不是圆形、不网格，而是真正模拟夜空星座的散点分布。星座连线（腰带+四肢+天狼星）实时追踪，滚动时整个星系旋转漂移。

## 核心创新

- **真实星座映射**：照片位置模拟猎户座：参宿一到参宿七 + 天狼星，每个位置的X/Y/Z坐标参考真实星图比例
- **天文标签**：每张照片标注拜耳命名（β Ori、α Ori...）和中文名
- **星座连线系统**：12条线段模拟猎户腰带、四肢连线，天狼星独立连线
- **星系旋转**：滚动时整个星座绕Y轴旋转35°+X轴俯视12°，模拟星空视角变换
- **天极指示器**：右侧NCP（北天极）/SCP（南天极）指示方向

## 视觉效果

- 🌌 三层星云背景（紫/蓝/粉色模糊径向渐变+漂移动画）
- ✨ 80颗CSS星空粒子 + 90个Canvas粒子系统
- 🎴 8张Unsplash太空照片（星云/星系/日冕等）
- ⭐ 每张照片带恒星辉光（径向渐变+脉冲动画）
- 📍 照片右上角星点标记（闪烁）
- 🔗 12条星座虚线（腰带+四肢+天狼星）
- 🖱️ 悬停：照片放大发光120px+关联连线加亮
- ⬆️⬇️ 天极指示（NCP/SCP）

## 技术细节

- Vue 3 + TypeScript + GSAP 3 + ScrollTrigger（scrub: 1.8）
- CSS preserve-3d + perspective(2200)
- SVG constellation连线 + gsap.ticker实时同步坐标
- Canvas 2D粒子系统（90个粒子+3D透视投影）
- 完整onUnmounted清理链
