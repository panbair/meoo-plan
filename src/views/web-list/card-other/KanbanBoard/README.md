# KanbanBoard 看板面板

## 效果描述
支持拖拽排序、泳道、WIP限制的任务看板组件。多列看板（待办/进行中/审核/完成），卡片可拖拽在列间移动和列内排序，每列可设置WIP上限，超出时列标题变红警告。卡片支持优先级标签、负责人头像、截止日期。

## 技术实现
- **核心技术**: Vue 3 + 原生Drag API + GSAP动画
- **拖拽排序**: HTML5 Drag and Drop实现跨列移动与列内排序
- **WIP限制**: 列卡片数量超限时视觉警告
- **卡片系统**: 优先级/标签/负责人/日期多维度信息
- **动画**: 拖拽占位符动画，卡片入场stagger动画

## 使用方法
```vue
<KanbanBoard />
```
