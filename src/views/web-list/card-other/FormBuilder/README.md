# FormBuilder 表单构建器

## 效果描述
拖拽式可视化表单设计器组件。左侧为字段组件面板（输入框/下拉/单选/多选/日期等），中间为表单画布，拖拽组件到画布中排列，右侧为选中组件的属性配置面板，底部可查看生成的JSON Schema。

## 技术实现
- **核心技术**: Vue 3 + 原生Drag API + GSAP动画
- **拖拽系统**: HTML5 Drag and Drop API实现组件拖入与排序
- **属性面板**: 选中组件后右侧显示标签/必填/校验等配置
- **JSON Schema**: 实时生成表单对应的JSON Schema结构
- **预览模式**: 切换到预览模式可填写测试表单

## 使用方法
```vue
<FormBuilder />
```
