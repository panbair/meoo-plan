# PortalTransition 传送门转场

## 效果描述
页面间通过 3D 传送门洞穴效果无缝切换的沉浸式组件。Canvas 渲染同心圆环构成的隧道透视效果，圆环脉冲扩张模拟穿越虫洞的视觉冲击。支持多个"场景"切换，点击传送门触发穿越动画，粒子从隧道中心向外飞散，伴随光晕和色彩偏移。

## 技术实现
- **核心技术**: Canvas API + GSAP 时间线动画
- **隧道渲染**: 多层同心椭圆逐帧缩放+旋转，模拟 3D 纵深
- **穿越动画**: GSAP timeline 控制缩放加速→白闪→新场景淡入
- **粒子系统**: 从中心点向外喷射的光粒子，速度随隧道深度变化
- **场景管理**: 多个背景场景，穿越后切换内容

## 视觉效果
- 深色虫洞隧道，同心环带发光描边
- 穿越时加速感 + 径向模糊
- 粒子从隧道中心飞出
- 色彩在蓝紫之间偏移
- 到达新场景时白光闪烁过渡

## 使用方法
```vue
<PortalTransition />
```
