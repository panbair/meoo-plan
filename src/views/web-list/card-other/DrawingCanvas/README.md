# DrawingCanvas - 手绘画板·多图层矢量绘图

## 效果描述

一个功能完备的手绘画板组件，支持压感模拟绘图、多图层管理、撤销/重做操作。使用 Canvas 2D 渲染矢量笔触，提供画笔/橡皮擦/颜色选择等工具栏。图层面板可添加/删除/切换/调整透明度，实现专业级绘图体验。

## 功能特性

### 核心功能

1. **压感模拟笔触**
   - 根据绘制速度动态调整线宽（快速→细，慢速→粗）
   - 贝塞尔曲线平滑插值，消除锯齿
   - 笔触始末端渐细效果

2. **多图层系统**
   - 支持添加/删除/重命名图层
   - 图层可见性切换与透明度调节
   - 图层上下排序拖拽
   - 每个图层独立 Canvas 离屏渲染

3. **撤销/重做**
   - 最多50步历史记录
   - 快捷键支持 Ctrl+Z / Ctrl+Shift+Z
   - 基于快照的状态管理

4. **工具栏**
   - 画笔工具：可调大小(1-50px)、颜色
   - 橡皮擦工具：可调大小
   - 颜色选择器：预设色板 + 自定义颜色
   - 清空画布
   - 导出为 PNG

### 技术栈

- Vue 3 Composition API
- Canvas 2D API
- 贝塞尔曲线插值算法
- GSAP（工具栏入场动画）

## 视觉效果

- 专业绘图界面布局
- 工具栏毛玻璃效果
- 图层面板抽屉式展开
- 笔触实时预览光标
- 撤销/重做按钮状态反馈
- 画布网格背景（可选）
