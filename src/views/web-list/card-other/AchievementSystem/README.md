# AchievementSystem 成就系统

## 效果描述
游戏化成就解锁弹窗与进度追踪组件。展示多个成就卡片，每个成就有图标、名称、描述、进度条和解锁状态。点击触发解锁时弹出华丽的解锁动画弹窗（粒子爆炸+光效），整体进度环显示总完成度。支持成就分类筛选和稀有度标记。

## 技术实现
- **核心技术**: Vue 3 响应式 + GSAP 动画 + Canvas 粒子
- **成就卡片**: 网格布局，锁定/解锁两种状态，进度条动画
- **解锁弹窗**: GSAP timeline 驱动的多阶段动画（缩放→粒子→文字→关闭）
- **进度系统**: 环形进度条 SVG 动画，百分比计数动画
- **分类筛选**: 按稀有度/类别过滤，带过渡动画

## 视觉效果
- 深色科技卡片，未解锁灰度显示
- 解锁瞬间金色粒子爆炸 + 光晕
- 稀有度用颜色区分（普通/稀有/史诗/传说）
- 进度条流光动画
- 整体完成度环形图

## 使用方法
```vue
<AchievementSystem />
```
