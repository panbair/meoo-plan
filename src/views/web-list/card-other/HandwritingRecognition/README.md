# HandwritingRecognition 手写识别

## 效果描述
手写输入转文字组件。提供书写画布，用户用鼠标/触摸手写文字，组件通过笔画分析识别为对应文字。支持连续书写、清除重写、识别结果展示，模拟手写板的交互体验。

## 技术实现
- **核心技术**: Canvas API + 笔画分析算法 + GSAP
- **手写采集**: Canvas 记录鼠标/触摸轨迹点序列
- **笔画分析**: 基于方向特征的简单字符匹配（演示用预设字库）
- **平滑笔触**: 贝塞尔曲线插值实现流畅书写效果
