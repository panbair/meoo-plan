# MarkdownLiveEditor Markdown实时编辑器

## 效果描述
分屏编辑预览的Markdown实时编辑器组件。左侧为代码编辑区，右侧实时渲染预览。支持标准Markdown语法高亮、代码块、表格、列表等，内置工具栏快捷插入常用语法，编辑与预览同步滚动。

## 技术实现
- **核心技术**: Vue 3 + 自实现Markdown解析器 + GSAP动画
- **解析器**: 正则匹配Markdown语法，转换为HTML输出
- **同步滚动**: 编辑区与预览区滚动位置同步
- **工具栏**: 快捷插入标题/粗体/斜体/链接/代码/列表等
- **主题**: 深色科技主题，代码块语法着色

## 使用方法
```vue
<MarkdownLiveEditor />
```
