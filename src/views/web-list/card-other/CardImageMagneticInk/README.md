# CardImageMagneticInk — 磁性墨水

## 概念

画面中央一团像铁磁流体（ferrofluid）的黑色液体，下方隐藏一颗旋转的磁偶极子。滚动驱动磁铁绕液滴轨道运动，磁场变化使液滴沿磁感线方向长出尖刺、变形分裂、重新聚合。22 条发光磁感线可视化磁场，90+ 颗铁屑粒子沿磁感线流动闪烁。

## 核心技术

| 技术 | 用途 |
|------|------|
| **2D 磁偶极子场** | B(r) = (3(m̂·r̂)r̂ - m̂) / r³ 计算磁场向量 |
| **液滴变形** | 72 采样点沿法向位移，位移量 ∝ B 场法向分量 |
| **顶点平滑** | 相邻点 0.2/0.6/0.2 加权平均，消除锯齿尖刺 |
| **磁感线追踪** | 从磁铁北极端 22 个均匀散布起点，双向欧拉积分追踪 |
| **铁屑粒子** | 90 颗沿磁感线位置振荡，距离液滴越近越亮（白→蓝→紫） |
| **液滴渲染** | 阴影光晕 + 纯黑主体径向渐变 + 边缘冷白高光 + 表面反射 |

## 物理模型

```
磁偶极子场（2D）：
  r̂ = (p - m) / |p - m|
  B(p) = [3(m̂·r̂)r̂ - m̂] / |p - m|³

液滴表面位移：
  displacement = B_normal × R² × 0.012
  clamped to [-0.35R, MAX_SPIKE]
```

## 动画参数

| 图层 | start | end | scrub | 说明 |
|------|-------|-----|-------|------|
| 磁铁轨道 | `top 85%` | `bottom 30%` | 1.5 | orbitAngle 0→2π，磁铁绕液滴一周 |
| 标题文字 | `top 75%` | `top 25%` | 1.0 | blur 消除 + y 位移入场 |
| 分割线 | `top 75%` | `top 25%` | 1.0 | scaleX 展开 |
| 副标题 | `top 75%` | `top 25%` | 1.0 | 淡入 + y 位移 |

## 色系

- **背景**：极深暗蓝径向渐变 `#0c0c20 → #010104`
- **磁感线**：冷白→紫渐变描边，双层发光（粗晕 + 细芯）
- **液滴本体**：纯黑渐变 `#0a0a14 → #010104`
- **液滴边缘**：冷白→紫高光线，shadowBlur=8
- **液滴高光**：左上角径向反射光
- **铁屑粒子**：近液滴白亮 → 中距蓝白 → 远距蓝紫
- **文字**：冷白→紫多层 text-shadow

## 性能优化

- **DPR ≤ 2**：高倍屏不爆显存
- **液滴顶点 72 个**：平衡细节和计算量
- **磁感线 22 条 × 80 步**：足够可视化不卡顿
- **铁屑位置伪随机振荡**：避免每帧粒子系统全量更新
- **液滴中心偏移**：磁铁吸引力微调液滴位置，增加真实感
