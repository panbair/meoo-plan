# TerrainGenerator 地形生成器

## 效果描述
基于 Perlin/Simplex 噪声算法实时生成可交互 3D 地形的沉浸式组件。Canvas 渲染等轴测线框地形网格，支持鼠标拖拽旋转视角、滚轮缩放、实时调整地形参数（频率、振幅、层级），地形随时间缓慢流动演变，营造出科幻数字地表效果。

## 技术实现
- **核心技术**: Canvas API + 自实现 Simplex Noise + GSAP
- **噪声算法**: 多层叠加(Octave)噪声，支持频率/振幅/持久度调节
- **3D 投影**: 自定义透视/等轴测矩阵，鼠标控制旋转角度
- **渲染模式**: 线框网格 / 实体填充 / 高度着色三种模式
- **入场动画**: 地形从平面逐渐隆起，GSAP 控制全局振幅

## 视觉效果
- 深色背景 + 发光线框网格
- 高度渐变着色（深蓝→青→绿→黄→红）
- 地形缓慢流动，如数字海洋
- 鼠标交互旋转/缩放
- 参数面板实时调节

## 使用方法
```vue
<TerrainGenerator />
```
