# TimelineRiver 时间河流图

## 效果描述
类似 GitHub Contributions 但更立体的时间流活动可视化组件。以等轴测 3D 视角展示时间网格，每个格子的高度和颜色代表活动强度，形成起伏的"河流地形"效果。支持时间范围切换、分类筛选、悬停查看详情等交互。

## 技术实现
- **核心技术**: Canvas API + GSAP 动画
- **等轴测渲染**: 2D Canvas 模拟 3D 等轴测视角，格子带高度柱体
- **颜色映射**: 活动强度 → 颜色深浅 + 柱体高度双重编码
- **波纹动画**: 自动播放模式下高亮波从左到右流过网格
- **交互系统**: 悬停显示日期/活动详情，点击查看当日明细，分类筛选
- **入场动画**: 格子从平面依次升起到目标高度，波浪式延迟

## 视觉效果
- 深色背景，格子从暗蓝到亮蓝渐变
- 等轴测 3D 透视，柱体带侧面阴影
- 高活跃格子顶部发光
- 波纹流动动画增添生命力
- 时间轴导航 + 分类图例
