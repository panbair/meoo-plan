# EmotionHeatmap 情感热力图

## 效果描述
基于文本情感分析的实时热力可视化组件。输入一段文字，逐句分析情感极性（积极/消极/中性），以热力图色块展示每句话的情感强度。支持整体情感分布统计、关键词高亮、时间轴情感波动曲线。

## 技术实现
- **核心技术**: Canvas API + 自实现情感词典 + GSAP 动画
- **情感分析**: 基于情感词典的规则匹配，计算句子情感分值
- **热力渲染**: Canvas 绘制色块矩阵，颜色映射情感极性
- **统计可视化**: 饼图分布 + 折线趋势图

## 使用方法
```vue
<EmotionHeatmap />
```
