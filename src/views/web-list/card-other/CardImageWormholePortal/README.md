# CardImageWormholePortal — 虫洞传送门

## 概念

画面中心一个深不见底的黑洞漩涡，周围光粒子被极端引力拉伸成细长光线弧，形成《星际穿越》Gargantua 风格的爱因斯坦环。1200+ 粒子沿螺旋轨道构成高温吸积盘，越靠近中心越白热。滚动控制漩涡旋转速度和引力强度。

## 核心技术

| 技术 | 用途 |
|------|------|
| **吸积盘粒子系统** | 1200 粒子开普勒轨道运动，角速度 ∝ 1/√r，内圈快外圈慢 |
| **引力吸入** | `drift = gravityPull × (1/max(r-R_inner, α))`，粒子向内漂移，到达视界后重生 |
| **色温渐变** | 5 段离散步长：外冷橙 → 金橙 → 亮金 → 黄白 → 内纯白热 |
| **椭圆轨道模拟** | 每个粒子有独立离心率和相位，Y 轴压缩 0.6 + 垂直偏移，模拟 3D 盘面 |
| **爱因斯坦环** | 光子球半径处双层发光环 + 5 个旋转光子聚集热点 |
| **引力透镜弧** | 上下各 7 条弧，渐变厚度和模糊，模拟光弯曲效果 |
| **相对论喷流** | 上下极轴方向锥形渐变喷流 |
| **CSS Bloom** | 独立 `bloom-overlay` 层，`filter: blur(35px)` 径向渐变，叠加中心光溢出 |

## 物理结构

```
事件视界（纯黑圆形）
  ↑ r = 50px
光子球（爱因斯坦环）
  ↑ r = 78px  (≈ 1.5× 视界半径)
吸积盘内缘
  ↑ r = 66px
吸积盘外缘
  ↑ r = 360px
引力透镜弧
  ↑ r = 81~137px（上下对称）
背景星场
  ↑ r = 15%~85% 画布对角线
```

## 动画参数

| 图层 | start | end | scrub | 说明 |
|------|-------|-----|-------|------|
| 旋转/引力 | `top 85%` | `bottom 30%` | 1.5 | progress 0→1，旋转 0.25x→2.75x，引力 0.05→0.40 |
| CSS Bloom | `top 85%` | `top 40%` | 1.2 | opacity 0→1 |
| 标题文字 | `top 75%` | `top 25%` | 1.0 | blur 消除 + y 位移入场 |
| 分割线 | `top 75%` | `top 25%` | 1.0 | scaleX 展开 |
| 副标题 | `top 75%` | `top 25%` | 1.0 | 淡入 + y 位移 |

## Scroll 驱动效果

| progress | 视觉效果 |
|----------|----------|
| 0.0 | 缓慢旋转，粒子分散在外圈，暗弱 |
| 0.3 | 旋转加速，粒子开始向内聚集 |
| 0.6 | 快速旋转，粒子里密外疏，吸积盘明亮 |
| 1.0 | 全速旋转，内圈白热发光，爱因斯坦环最亮，喷流最强 |

## 色系

- **背景**：纯黑 `#000103`
- **吸积盘**：外圈暖橙 `rgb(240,95,15)` → 中圈金黄 `rgb(255,190,70)` → 内圈白热 `rgb(255,252,245)`
- **爱因斯坦环**：纯白高亮 + 暖金 shadow，shadowBlur 22~36
- **透镜弧**：暖白描边 + 金橙模糊外晕
- **喷流**：白→金→青紫渐变锥形
- **光溢出**：CSS `blur(35px)` 白→金→橙径向
- **文字**：暖金发光 text-shadow 四层

## 性能优化

- **DPR ≤ 2**：限制高倍屏像素密度
- **1200 粒子外到内排序绘制**：确保远处粒子先画被近处覆盖，正确深度
- **粒子重生机制**：到达视界后在外圈重生，保持粒子池恒定
- **颜色查表法**：5 段 if 比 HSL 动态计算快
- **背景星闪烁**：仅 opacity 调制，零位置计算
- **透镜弧预设**：14 条弧初始化后仅微量漂移，不每帧重建
