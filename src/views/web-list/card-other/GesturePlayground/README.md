# GesturePlayground - 手势操控台·3D物体控制

## 效果描述

一个交互式手势识别操控台，支持触摸/鼠标的捏合(缩放)、旋转、滑动(平移)手势来操控中央的3D物体。通过 CSS 3D Transform 渲染可交互的3D立方体/球体，手势操作实时映射到物体变换。手势轨迹可视化显示，并附带操作提示面板。

## 功能特性

### 核心功能

1. **手势识别系统**
   - 单指拖拽：旋转3D物体（X/Y轴映射）
   - 双指捏合：缩放物体（0.3x - 3x）
   - 双指旋转：沿Z轴旋转物体
   - 快速滑动(Fling)：惯性旋转动画
   - 双击：重置到默认视角

2. **3D物体渲染**
   - CSS 3D Transform 实现立方体
   - 6面可自定义颜色/贴图
   - 实时反射/阴影效果
   - 透视深度可调

3. **手势轨迹可视化**
   - 触摸点实时圆圈标记
   - 滑动轨迹拖尾线条
   - 捏合手势距离线可视化
   - 旋转角度弧线标注

4. **操作提示面板**
   - 当前识别手势名称显示
   - 操作参数实时数据（角度/缩放/位移）
   - 手势教学提示图标

### 技术栈

- Vue 3 Composition API
- CSS 3D Transform (perspective, rotateX/Y/Z, scale3d)
- Touch Events / Pointer Events API
- GSAP（惯性动画、弹性回弹）
- 手势识别算法

## 视觉效果

- 3D立方体实时旋转
- 触摸点涟漪标记
- 手势轨迹线条渐隐
- 惯性旋转动量衰减
- 暗色科技感操控台界面
- 参数数据实时刷新
