# CardImageCoralParadise — 珊瑚天堂

## 概述

深海荧光珊瑚从底部向上分形生长，微小发光浮游生物环绕飘动，半透明水母缓缓漂过。灵感来自《阿凡达：水之道》海底生态系统。

## 核心技术

| 特性 | 实现 |
|------|------|
| **L-system 分形** | 递归分支规则，5 丛珊瑚，每丛 4~6 层分支，80+ 枝蔓 |
| **生长动画** | ScrollTrigger 驱动生长进度 0→1，深度越深越晚出现 |
| **枝蔓绘制** | Canvas lineTo + 粗→细渐变 + round cap + 荧光端点 + shadowBlur |
| **浮游生物** | 500 粒荧光粒子，布朗运动 + 微弱上升流 + 正弦呼吸脉冲 |
| **水母** | 4 只各 6~11 触手，钟状体椭圆 + 收缩动画 + Bezier 触手波动 |
| **焦散光斑** | 30 个随机多边形，金色径向渐变，微旋转漂移 |
| **体积光** | 5 道从顶射入的渐变光柱 |
| **海底沙地** | 底部 12% 高渐变 + 闪烁砂粒 |

## 渲染层次

```
1. 深海背景渐变 (#051530 → #041020)
2. 体积光柱 (5道)
3. 焦散光斑 (金色多边形)
4. 珊瑚枝蔓 (按深度排序绘制)
5. 海底沙地
6. 浮游生物粒子
7. 水母 (4只)
```

## Scroll 驱动

- **珊瑚生长**：每个分支 `growthAmount = clamp((progress - depth * 0.08) * 3.5, 0, 1)`
  - depth=0 主枝在 progress≈0 时开始
  - depth=5 末梢在 progress≈0.4 时开始
- **水母活跃度**：`opacity = (0.3 + progress * 0.4) * (0.8 + 0.2 * sin(...))`
  - 越往下滚动，水母越明显越活跃

## 色系

- **背景**：深海蓝 `#051530 → #041020`
- **珊瑚**：荧光粉 `#e04090`、荧光绿 `#30d0a0`、`#20e8b0`
- **浮游生物**：荧绿/蓝 mix `#66ffaa` `#44aaff`
- **焦散光斑**：金橙 `rgba(255,240,200,...)`
- **水母**：半透明蓝白 `rgba(200,230,255,0.5)`
- **文字**：荧光绿白 + 三层 text-shadow

## 参数配置

```ts
// 珊瑚
coralDefs: [{ xPct, color, maxDepth }, ...] // 5丛
generateBranch(...) // 每丛递归 4-6 层

// 浮游生物
count: 500
size: 0.6 ~ 2.2px
speed: vx=±0.17, vy=-0.05~0.3 (上升)

// 水母
count: 4
size: 0.7 ~ 1.8 (×50px)
tentacles: 6~11 条

// 焦散光斑
count: 30
verts: 4~6 边形
opacity: 0.05 ~ 0.23
```
