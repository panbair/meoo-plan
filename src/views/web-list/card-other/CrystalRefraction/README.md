# CrystalRefraction 水晶折射

## 效果描述
模拟真实光线折射效果的水晶棱镜组件。Canvas 渲染多面体水晶形状，光线穿过时产生色散彩虹效果。水晶缓慢旋转，内部折射光束随角度变化，表面有菲涅尔反射高光。鼠标移动控制光源方向，水晶表面呈现动态的彩虹色散和焦散光斑。

## 技术实现
- **核心技术**: Canvas API + 光线追踪简化算法 + GSAP
- **水晶建模**: 2D 多边形表示水晶截面，多条光线射入
- **折射计算**: Snell 定律计算折射角度，RGB 三通道不同折射率模拟色散
- **菲涅尔效应**: 表面反射率随入射角变化
- **焦散渲染**: 折射光线汇聚区域产生高亮光斑

## 视觉效果
- 透明水晶体，表面高光反射
- 光线穿过产生彩虹色散
- 鼠标控制光源角度
- 水晶缓慢旋转
- 背景焦散光斑
- 深色背景突出光学效果
