# CardImageParticleSculpture — 粒子雕塑变形

## 概述

4000 个粒子组成的 3D 点云，滚动时从人头像散开、旋转重构为飞鸟。粒子间保持微弱连线，散落阶段模拟重力/风力效果。

## 核心技术

| 特性 | 实现 |
|------|------|
| **3D 点云生成** | 斐波那契球面分布 + 椭球体采样，均匀覆盖形状表面 |
| **形状 A：人头半身像** | 60% 头部球体（含鼻凸/眼窝调模）+ 15% 颈部 + 25% 肩部椭球 |
| **形状 B：飞鸟** | 35% 身体椭球 + 10% 头部球 + 27%×2 双翼参数曲面 + 1% 尾羽 |
| **三阶段过渡** | 散开 (0-25%) → 飞行 (25-75%) → 聚拢 (75-100%) |
| **散开阶段** | easeOut 径向散开 + 重力下落，粒子像被抛洒 |
| **飞行阶段** | easeInOut 从散开位置飞向目标形状 |
| **聚拢阶段** | easeOut quartic 精确收敛到目标坐标 |
| **粒子连线** | 空间哈希桶（55px 格），最近邻 38px 阈值，最大 800 根 |
| **投影** | Y 轴旋转矩阵 + 弱透视 `1/(1+z*0.25)` |
| **滚动驱动** | ScrollTrigger scrub 1.5 驱动 `progress 0→1` |

## 三阶段过渡逻辑

```
Phase 1 (0-25%): Source → Scatter
  - 粒子从源形状沿径向 + 噪声方向散开 1.8 单位
  - 叠加重力下沉 0.4 单位
  - 缓动: easeOut cubic

Phase 2 (25-75%): Scatter → Target
  - 粒子从散开位置飞向目标形状
  - 缓动: easeInOut quadratic

Phase 3 (75-100%): Converge
  - 粒子逐步逼近目标位置
  - 缓动: easeOut quartic
```

## 性能设计

| 策略 | 说明 |
|------|------|
| **DPR ≤ 1.5** | 高粒子数限制像素比，避免显存压力 |
| **空间哈希** | 55px 桶，仅检查相邻桶配对 |
| **连线上限** | 最多绘制 800 根，避免显示卡死 |
| **粒子光照** | 仅 >1.2px 粒子绘制光晕，小粒子跳过 |
| **单层 Canvas** | 连线 + 粒子在同一画布，零 DOM 开销 |
| **每帧重建桶** | 粒子位置每帧变化，桶重建 O(n) |

## 参数配置

```ts
PARTICLE_COUNT: 4000
BUCKET_SIZE: 55px
CONNECT_DIST: 38px
MAX_LINES: 800

// 形状 A
head: 60% sphere r=0.85, face modulation (nose +0.15z, eye socket -0.08z)
neck: 15% cylinder r=0.3, y=-0.4~-0.75
shoulder: 25% ellipsoid rx=1.0, ry=0.35, rz=0.45

// 形状 B
body: 35% ellipsoid rx=1.0, ry=0.28, rz=0.22
head: 10% sphere r=0.22
wings: 54% parametric surface, span=0.1~1.6, z=-0.5~-2.8
```

## 色系

- **背景**：深灰渐变 `#0a0d15 → #080a10`
- **粒子**：白蓝 `rgba(200,235,255,0.85)` + 光晕 `rgba(130,210,255,0.12)`
- **连线**：半透明青 `rgba(130,210,255,α)` 随距离和阶段变化
- **文字**：冰蓝三层 text-shadow
