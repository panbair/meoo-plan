# DragPhysicsEngine - 物理拖拽引擎·真实力学模拟

## 效果描述

一个基于真实物理引擎的拖拽交互组件。场景中散落多个可拖拽元素（方块、圆球、多边形），它们具备真实的重力、碰撞检测、弹性反弹、摩擦力物理属性。用户可拖拽抛掷元素，元素间和边界碰撞产生真实的弹跳效果。支持调节重力方向/强度、弹性系数、摩擦力等物理参数。

## 功能特性

### 核心功能

1. **刚体物理模拟**
   - 重力加速度模拟（可调方向和强度）
   - AABB 碰撞检测 + 碰撞响应
   - 弹性系数控制反弹力度（0-1）
   - 摩擦力减速
   - 空气阻力衰减

2. **拖拽与抛掷**
   - 鼠标/触摸拖拽物体
   - 拖拽时物体脱离重力（跟随指针）
   - 释放时根据拖拽速度计算初速度
   - 抛掷后物体在重力和碰撞下自然运动

3. **多种物体类型**
   - 方块：带旋转的矩形刚体
   - 圆球：圆形碰撞体
   - 多边形：三角形/五边形
   - 每种可自定义颜色、大小、质量

4. **物理参数面板**
   - 重力强度滑块（0 - 20 m/s²）
   - 重力方向（四方向 + 自定义角度）
   - 弹性系数滑块（0 - 1）
   - 摩擦力滑块（0 - 1）
   - 一键重置场景
   - 添加/删除物体按钮

5. **碰撞可视化**
   - 碰撞瞬间闪光粒子
   - 速度矢量箭头（可选）
   - 碰撞力大小数值显示
   - 轨迹拖尾线

### 技术栈

- Vue 3 Composition API
- Canvas 2D / DOM 混合渲染
- 自研轻量物理引擎（Verlet积分）
- requestAnimationFrame 物理循环
- GSAP（UI面板动画）
- Pointer Events API
