# VoiceVisualizer - 语音可视化器·实时频谱动画

## 效果描述

通过浏览器麦克风 API 实时采集声音数据，将音频信号转换为多种可视化形态：频谱柱状图、波形曲线、环形频谱、粒子反应器。支持可视化模式切换，颜色主题自定义，灵敏度调节。静默时展示优雅的待机动画。

## 功能特性

### 核心功能

1. **麦克风音频采集**
   - Web Audio API + AudioContext
   - AnalyserNode 实时 FFT 频谱分析
   - 可调 FFT 大小（256/512/1024/2048）
   - 灵敏度/增益调节滑块

2. **可视化模式**
   - **频谱柱状图**：经典频率柱形图，低频到高频从左到右
   - **波形曲线**：时域波形正弦曲线，流畅的线条动画
   - **环形频谱**：圆形排列的频率条，从中心向外辐射
   - **粒子反应器**：音频能量驱动粒子运动，低音=大粒子，高音=快粒子

3. **主题与自定义**
   - 预设颜色主题：霓虹、海洋、日落、矩阵绿
   - 自定义渐变色配置
   - 背景暗/亮模式
   - 柱状图样式：圆角/方角/圆点

4. **待机与交互**
   - 静默时优雅呼吸动画
   - 开始/停止录制按钮
   - 麦克风权限引导提示
   - 音量峰值指示器

### 技术栈

- Vue 3 Composition API
- Web Audio API (AudioContext, AnalyserNode)
- Canvas 2D API (高性能渲染)
- requestAnimationFrame 动画循环
- GSAP（UI动画、模式切换过渡）

## 视觉效果

- 实时频谱柱状图跳动
- 流畅波形曲线绘制
- 环形频谱辐射效果
- 粒子能量反应动画
- 色彩渐变映射频率
- 静默时呼吸光效
- 麦克风按钮脉动
