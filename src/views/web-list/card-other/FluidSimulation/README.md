# FluidSimulation 流体模拟

## 效果描述
基于简化 Navier-Stokes 方程的 2D 流体交互模拟组件。鼠标/触摸在画布上拖动时注入速度和染料，流体自然扩散、对流、卷曲，形成绚丽的流体艺术效果。支持多种染料颜色、粘度调节、涡度增强，营造出流动的数字水墨画面。

## 技术实现
- **核心技术**: Canvas API + 速度场/密度场双缓冲计算
- **物理模拟**: 扩散(Diffusion) + 对流(Advection) + 投影(Projection) 三步求解
- **交互注入**: 鼠标移动方向作为速度源，位置作为染料源
- **涡度约束**: Vorticity confinement 增强流体卷曲细节
- **渲染**: 将密度场映射为 RGBA 像素，逐帧绘制到 Canvas

## 视觉效果
- 烟雾/水墨般的流体效果
- 鼠标拖动产生彩色流体轨迹
- 流体自然扩散和涡旋
- 多种颜色混合
- 参数面板调节粘度、扩散率、涡度

## 使用方法
```vue
<FluidSimulation />
```
