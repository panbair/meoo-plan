# PixelArtEditor 像素画编辑器

## 效果描述
网格式像素画创作工具组件。提供可缩放的像素网格画布，支持画笔、橡皮擦、填充桶、取色器等工具，多帧动画编辑与预览播放，调色板与自定义颜色，支持导出 PNG 图片。操作简洁直观，适合创作像素风格图标和简单动画。

## 技术实现
- **核心技术**: Canvas API + GSAP 动画
- **网格系统**: 可配置分辨率(8x8 ~ 64x64)的像素网格
- **工具系统**: 画笔/橡皮擦/填充桶(Flood Fill)/取色器/矩形选区
- **动画帧**: 多帧时间轴，帧复制/删除，动画预览播放
- **导出**: Canvas toDataURL 导出 PNG，动画导出 GIF 序列

## 视觉效果
- 网格线辅助对齐
- 工具栏图标化操作
- 调色板 + HSL 颜色选择器
- 帧时间轴缩略图预览
- 动画播放窗口
