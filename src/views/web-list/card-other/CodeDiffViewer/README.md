# CodeDiffViewer 代码差异对比器

## 效果描述
支持行内/并排对比的语法高亮Diff查看器组件。输入两段代码，自动计算差异并以增删改三色高亮展示。支持并排(side-by-side)和行内(inline)两种对比模式，行号显示，折叠未变更区域。

## 技术实现
- **核心技术**: Vue 3 + 自实现Diff算法(Myers) + GSAP动画
- **Diff算法**: 基于最长公共子序列(LCS)的行级差异计算
- **渲染模式**: 并排双栏/行内单栏两种展示
- **语法着色**: 基于关键词的简单语法高亮
- **交互**: 折叠相同区域，展开查看上下文

## 使用方法
```vue
<CodeDiffViewer />
```
