# TreemapZoom 矩形树图缩放

## 效果描述
可无限层级下钻的矩形树图可视化组件。数据以嵌套矩形表示，面积与数值成正比。点击任一矩形可平滑缩放进入其子层级，顶部面包屑导航支持逐级返回。每个矩形带渐变色填充和标签自适应，营造出层级分明的数据探索体验。

## 技术实现
- **核心技术**: SVG/DOM 渲染 + GSAP 动画
- **布局算法**: Squarified Treemap 算法，最优化矩形宽高比
- **缩放动画**: GSAP 驱动矩形位置/尺寸平滑过渡到下一层级
- **面包屑导航**: 记录下钻路径，支持任意层级跳转
- **标签算法**: 根据矩形尺寸自动调整字号，过小则隐藏
- **入场动画**: 矩形从中心向外依次展开

## 视觉效果
- 渐变色填充区分类别，深色科技主题
- 悬停时矩形边框发光 + 浮起阴影
- 下钻/返回时矩形平滑变形过渡
- Tooltip 显示名称、数值、占比
- 面包屑导航带动画切换

## 使用方法
```vue
<TreemapZoom />
```
