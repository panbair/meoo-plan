# AIImagePromptBuilder AI图像提示词构建器

## 效果描述
可视化拼接Stable Diffusion/MidJourney提示词的构建器组件。通过分类标签面板（主题/风格/光影/色彩/构图/质量等）点击选择关键词，自动拼接为完整提示词。支持权重调节、负面提示词、一键复制，实时预览提示词结构。

## 技术实现
- **核心技术**: Vue 3 响应式 + GSAP 动画
- **分类系统**: 多维度标签分组，点击添加/移除
- **权重语法**: 支持 (keyword:1.5) 格式的权重调节
- **提示词管理**: 正面/负面提示词分区，拖拽排序
- **预设模板**: 一键加载常用风格预设

## 使用方法
```vue
<AIImagePromptBuilder />
```
