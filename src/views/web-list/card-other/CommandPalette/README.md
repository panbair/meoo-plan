# CommandPalette 命令面板

## 效果描述
类VSCode Ctrl+Shift+P的模糊搜索命令面板组件。按快捷键弹出居中命令面板，支持模糊搜索命令列表，键盘上下选择+回车执行，分组显示命令分类，最近使用记录置顶。

## 技术实现
- **核心技术**: Vue 3 + GSAP弹出动画
- **模糊搜索**: 自实现fuzzy match算法，高亮匹配字符
- **键盘导航**: 上下键选择、回车执行、ESC关闭
- **命令系统**: 分组命令注册，支持快捷键显示
- **动画**: GSAP驱动弹出/收起过渡

## 使用方法
```vue
<CommandPalette />
```
