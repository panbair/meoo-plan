# SankeyFlow 桑基图流向图

## 效果描述
交互式桑基图数据流向可视化组件。展示数据/能量从源头经中间处理到最终输出的完整流动过程。节点分布在多列中，流线以贝塞尔曲线连接，粒子沿路径流动表示数据传输，营造出科技感十足的数据可视化体验。

## 技术实现
- **核心技术**: Canvas API + GSAP 动画
- **布局算法**: 多列节点自动排列，流线宽度按数值比例缩放
- **路径渲染**: 三次贝塞尔曲线连接节点，支持渐变色填充
- **粒子系统**: 沿贝塞尔曲线运动的发光粒子，模拟数据流动
- **交互系统**: 鼠标悬停高亮关联路径，点击节点聚焦，Tooltip 显示流量值
- **入场动画**: GSAP 驱动节点依次弹入 + 流线渐显 + 粒子启动

## 视觉效果
- 深色科技背景，节点带发光边框
- 流线半透明渐变色，悬停时高亮
- 粒子沿曲线流动，带拖尾光效
- 节点悬停时放大并显示详情 Tooltip
- 流量数值标注在流线上
