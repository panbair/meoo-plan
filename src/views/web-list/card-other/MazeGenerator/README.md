# MazeGenerator 迷宫生成器

## 效果描述
可玩的随机迷宫生成与求解可视化组件。支持多种迷宫生成算法（递归回溯、Prim、Kruskal），实时动画展示生成过程。玩家可用键盘/鼠标操控角色从起点走到终点，支持一键展示最短路径求解动画（BFS/A*），迷宫大小可调。

## 技术实现
- **核心技术**: Canvas API + GSAP 动画
- **生成算法**: 递归回溯(DFS)，逐步打通墙壁，动画可视化每一步
- **求解算法**: BFS 最短路径，A* 启发式搜索，路径高亮动画
- **玩家控制**: 键盘 WASD/方向键移动，碰撞检测
- **入场动画**: 迷宫墙壁从中心向外逐步生成

## 视觉效果
- 深色背景，墙壁发光线条
- 玩家角色带脉冲光效
- 求解路径渐变高亮
- 生成过程实时动画
- 起点/终点标记动画

## 使用方法
```vue
<MazeGenerator />
```
