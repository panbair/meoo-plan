# RadarMorphChart 雷达变形图

## 效果描述
支持多维数据对比的动态变形雷达图组件。多组数据以半透明多边形叠加在雷达网格上，切换数据集时多边形顶点平滑变形过渡。支持数据集切换、轴高亮、自动轮播等交互，适合产品能力对比、团队评分等场景。

## 技术实现
- **核心技术**: SVG 渲染 + GSAP 变形动画
- **雷达网格**: 同心多边形网格 + 轴线 + 刻度标签
- **变形动画**: GSAP 驱动 SVG polygon points 属性平滑插值
- **多数据集**: 支持叠加多组半透明数据多边形
- **交互系统**: 悬停轴显示数值，切换按钮触发变形，自动轮播模式
- **入场动画**: 网格从中心扩展 + 数据多边形从零放大到实际值

## 视觉效果
- 深色背景下发光网格线
- 数据多边形渐变填充 + 顶点脉冲光点
- 切换数据集时多边形顺滑变形
- 悬停轴线高亮 + Tooltip 数值
- 图例按钮带选中态动画
