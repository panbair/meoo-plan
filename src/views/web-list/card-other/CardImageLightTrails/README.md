# CardImageLightTrails — 流光拖尾轨道

## 概念

5 个霓虹发光球体沿不同轨道运动（正圆 → 椭圆 → ∞字形 → 利萨如曲线），每个球体后面拖着 50 帧渐隐光粒子拖尾。轨道交叉时球体碰撞产生金色火花粒子爆散。滚动驱动轨道形状动态变形。

## 核心技术

| 技术 | 用途 |
|------|------|
| **Canvas 2D** | 粒子拖尾渲染，维持最近 50 帧位置历史 |
| **径向渐变叠加** | 球体三层光晕（外层大光晕 + 中间色光 + 核心白亮） |
| **轨道参数方程** | x(t)=R₁cos(ω₁t+φ₁), y(t)=R₂cos(ω₂t+φ₂) |
| **四段形态混合** | 圆 → 椭圆 → ∞字 → 利萨如，逐段 lerp |
| **碰撞检测** | O(N²) 距离检测，阈值 < 70px 触发火花 |
| **GSAP ScrollTrigger** | 驱动轨道形状 `orbitShape` 0→1 平滑过渡 |

## 动画参数

| 图层 | start | end | scrub | 说明 |
|------|-------|-----|-------|------|
| 轨道变形 | `top 85%` | `bottom 30%` | 1.5 | orbitShape 0→1，圆形→利萨如 |
| 标题文字 | `top 75%` | `top 25%` | 1.0 | blur消除 + y位移入场 |
| 分割线 | `top 75%` | `top 25%` | 1.0 | scaleX 展开 |
| 副标题 | `top 75%` | `top 25%` | 1.0 | 淡入 + y位移 |

## 轨道形态过渡

| 滚动阶段 | 形态 | 方程 |
|----------|------|------|
| 0% ~ 33% | 正圆 → 椭圆 | x=er·cos(t+φ), y=(1/er)·sin(t+φ) |
| 33% ~ 66% | 椭圆 → ∞字形 | x=sin(t+φ), y=sin(2t+2φ) |
| 66% ~ 100% | ∞字形 → 利萨如 | x=cos(3t+φ), y=cos(2t) |

## 色系

- **背景**：深海暗黑径向渐变 `#070c1a → #000208`
- **球体发光**：5 色霓虹渐变（青/品红/金/青柠/紫）
- **拖尾光带**：对应色系 hsl 半透明渐隐
- **火花粒子**：金色 → 橙红 → 渐隐消失
- **文字**：七彩多层 text-shadow 霓虹发光

## 性能优化

- **Canvas 渲染**：所有粒子在一张 Canvas 上绘制，零 DOM 开销
- **DPR 限制**：最大 `devicePixelRatio = 2`，避免高倍屏过度绘制
- **拖尾长度 50 帧**：平衡视觉效果和计算量
- **火花上限 120**：防止碰撞时粒子数爆炸
- **ResizeObserver**：响应容器尺寸变化，自动调整 Canvas
