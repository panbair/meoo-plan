# CardTimeTypewheel 打字轮

## 效果描述
打字机滚轮旋转，每个字符/卡片逐个"击打"上纸。模拟老式打字机的机械节奏感。

## 技术实现
### 动画阶段
1. **滚轮待机** — 打字轮在顶部旋转待命
2. **击打入场** — 滚轮选中字符后"啪"地击打，卡片从上方弹入纸面
3. **逐张打印** — 从左到右逐张打印，每次带有击打震动和墨迹效果
4. **换行回车** — 一行打满后滑动回车，换行继续

### 核心技术
- GSAP timeline 序列击打动画
- bounce.out 模拟击打弹跳
- stagger 逐张从左到右
- CSS打字机纸张+墨带效果
