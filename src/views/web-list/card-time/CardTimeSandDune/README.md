# CardTimeSandDune 沙丘流动

## 效果描述
卡片像沙丘一样在"风力"驱动下波浪式迁移流动。模拟沙漠沙丘的缓慢迁徙。

## 技术实现

### 动画阶段
1. **静止沙丘** — 卡片排列成波浪起伏的沙丘形
2. **风力驱动** — 滚动触发沙丘整体向右流动
3. **波浪迁移** — 卡片高度随正弦波起伏
4. **沙粒飘散** — 沙丘顶部粒子随风飘散

### 核心技术
- GSAP ScrollTrigger scrub 驱动流动
- sin/cos 计算波浪高度
- 粒子系统模拟飞沙
- 暖色沙漠配色

## 使用方法
