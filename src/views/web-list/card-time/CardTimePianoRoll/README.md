# CardTimePianoRoll 钢琴卷帘

## 效果描述
卡片像MIDI音符一样在钢琴键上方滚动触发，模拟DAW钢琴卷帘编辑器。

## 技术实现
### 动画阶段
1. **钢琴键盘** — 底部黑白键盘布局
2. **音符滚动** — 卡片作为彩色音符块从右向左滚动
3. **触发播放** — 音符到达播放线时键盘对应键高亮
4. **时间轴** — 顶部时间刻度跟随滚动

### 核心技术
- GSAP ScrollTrigger scrub 驱动音符滚动
- translateX 水平移动
- 键盘高亮联动
- 网格背景对齐

## 使用方法

```vue
<CardTimePianoRoll />
```
