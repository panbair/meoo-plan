# CardTimeShadowTheater 影子剧场

## 效果描述
卡片是剪影形态，背后光源随鼠标移动产生实时阴影变形和投影拉伸效果。

## 技术实现

### 动画阶段
1. **暗场** — 舞台暗黑，只有一束聚光灯
2. **剪影入场** — 卡片从下方升起，显示为剪影轮廓
3. **光源交互** — 鼠标移动控制光源方向，阴影实时变形
4. **彩色揭示** — 特定角度的光照射时剪影"点亮"显示彩色

### 核心技术
- 鼠标位置→光源方向→CSS drop-shadow动态计算
- GSAP ScrollTrigger入场 + mousemove实时更新
- CSS filter: drop-shadow 动态阴影
- 光源角度计算投影偏移

## 视觉效果
- 皮影戏/剪影风格
- 实时阴影随光源变形
- 聚光灯锥形光束
- 舞台幕布氛围

## 使用方法
```vue
<CardTimeShadowTheater />
```
