# CardTimeElevator 电梯升降

## 效果描述
卡片在多层"电梯井"中升降交错，门开门关的过渡效果。模拟大楼电梯运行。

## 技术实现
### 动画阶段
1. **楼层显示** — 多层电梯井结构，层号指示器
2. **电梯门开** — clipPath从中间向两侧展开
3. **卡片升降** — 卡片在井道中垂直移动到目标楼层
4. **到达开门** — 到达后门打开露出卡片内容

### 核心技术
- GSAP ScrollTrigger scrub 控制升降
- clipPath 模拟电梯门开关
- translateY 垂直移动
- 楼层指示器数字跳动
