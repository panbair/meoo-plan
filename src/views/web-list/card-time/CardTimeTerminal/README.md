# CardTimeTerminal 终端打印

## 效果描述
卡片内容像终端命令行一样逐行"打印"输出，绿色字符+光标闪烁。模拟黑客终端。

## 技术实现
### 动画阶段
1. **启动画面** — 终端窗口出现，显示boot序列
2. **命令输入** — 逐字符"打字"输入命令
3. **结果输出** — 卡片内容逐行打印显示
4. **光标待命** — 打印完毕光标闪烁等待

### 核心技术
- GSAP timeline 逐字符打字效果
- stagger + onUpdate 字符级动画
- CSS光标闪烁
- 绿色终端配色
