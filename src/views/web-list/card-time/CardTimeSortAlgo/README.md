# CardTimeSortAlgo 排序算法

## 效果描述
卡片按冒泡/快排/归并排序可视化交换位置。数据结构与算法的动态展示。

## 技术实现
### 动画阶段
1. **乱序状态** — 卡片随机高度排列
2. **比较阶段** — 当前比较的两张卡片高亮
3. **交换动画** — 需要交换的卡片平滑互换位置
4. **排序完成** — 全部有序后彩虹渐变庆祝

### 核心技术
- GSAP timeline 序列交换动画
- 冒泡排序逻辑驱动
- x位置交换 + 高亮色变化
- 比较次数/交换次数统计
