# CardTimeConveyorBelt 传送带

## 效果描述
卡片在工业传送带上匀速移动，到达工位时停下展开。模拟工厂流水线。

## 技术实现
### 动画阶段
1. **传送带运转** — 底部传送带滚轮持续转动
2. **卡片上线** — 卡片从右侧进入传送带
3. **到站展开** — 到达检测工位时卡片弹起展开显示内容
4. **继续传送** — 检测完毕卡片缩回继续向左传送

### 核心技术
- GSAP ScrollTrigger scrub 驱动传送
- CSS滚轮旋转动画
- translateX 水平移动
- scale弹起展开
