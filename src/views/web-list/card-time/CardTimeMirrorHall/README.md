# CardTimeMirrorHall 镜厅反射

## 效果描述
卡片在无限镜像中递归缩小，scroll控制镜像深度层数。模拟凡尔赛宫镜厅的无限反射效果。

## 技术实现

### 动画阶段
1. **单卡片** — 中央一张实体卡片
2. **镜像生成** — 滚动触发左右两侧递归生成镜像副本（缩小+透明）
3. **深度控制** — 滚动进度控制显示多少层镜像（最多7层）
4. **无限隧道** — 完全展开后形成无限镜像隧道感

### 核心技术
- GSAP ScrollTrigger scrub 控制镜像层数
- CSS transform: scaleX(-1) 镜像翻转
- 递归缩放 + 递减透明度
- perspective 3D深度

## 视觉效果
- 无限递归镜像缩小
- 镜面反射光泽
- 进入隧道的纵深感
- 镜框金色装饰
