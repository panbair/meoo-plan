# CardTimePrismSplit 棱镜分光

## 效果描述
白色光束射入三棱镜后分裂为彩虹7色光谱，每色化为一张卡片。展示光的色散原理。

## 技术实现

### 动画阶段
1. **白光入射** — 白色光束从左侧射入
2. **棱镜折射** — 光束穿过三棱镜SVG，产生折射角变化
3. **色散分裂** — 白光分裂为7色光带，每条光带末端生成对应颜色卡片
4. **卡片展开** — 7张卡片沿扇形展开归位

### 核心技术
- GSAP ScrollTrigger scrub 驱动分光过程
- SVG 三棱镜 + 光束路径动画
- 7色 stagger 扇形展开
- CSS hue-rotate 彩虹渐变

## 视觉效果
- 白光→彩虹色散过程
- 三棱镜玻璃折射质感
- 光束路径实时绘制
- 卡片颜色对应光谱色
