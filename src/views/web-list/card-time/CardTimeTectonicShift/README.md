# CardTimeTectonicShift 板块漂移

## 效果描述
卡片像大陆板块一样从盘古大陆分裂漂移到各自位置。模拟大陆漂移的地质变迁。

## 技术实现

### 动画阶段
1. **盘古大陆** — 所有卡片紧密贴合为一块完整大陆
2. **裂缝出现** — 滚动触发卡片间裂缝扩大
3. **板块漂移** — 各板块沿不同方向缓慢漂移分离
4. **定位归位** — 漂移到最终网格位置

### 核心技术
- GSAP ScrollTrigger scrub 控制漂移进度
- 每张卡片独立的漂移方向和速度
- SVG裂缝线动画
- CSS地壳纹理

## 使用方法
