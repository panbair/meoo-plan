# CardTimeDebugger 调试器断点

## 效果描述
滚动=单步执行，每个卡片是一个断点，变量值实时变化。模拟IDE调试体验。

## 技术实现
### 动画阶段
1. **代码加载** — 代码行号显示
2. **设置断点** — 红色断点标记出现
3. **单步执行** — 滚动驱动逐行高亮，变量面板实时更新
4. **条件命中** — 条件断点触发时卡片展开详情

### 核心技术
- GSAP ScrollTrigger scrub 逐行推进
- 变量值插值动画
- 高亮行跟随滚动
- 断点红色指示器

## 使用方法
```vue
<CardTimeDebugger />
```
