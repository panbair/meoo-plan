# CardTimeCrystallize 结晶生长

## 效果描述
卡片从中心"种子"开始，像冰晶一样沿六角方向分枝生长铺满画面。

## 技术实现

### 动画阶段
1. **种子态** — 中心一个极小的晶核
2. **晶枝生长** — 沿六角方向逐级分枝延伸
3. **卡片结晶** — 每个晶枝末端生成卡片
4. **完整晶体** — 所有卡片形成完美六角对称

### 核心技术
- GSAP timeline 递归生长序列
- 六角坐标系计算位置
- scale + opacity 逐级生长
- CSS冰晶质感边框

## 使用方法
```vue
<CardTimeCrystallize />
```
