# CardTimeMagneticPoles 磁极翻转

## 效果描述
卡片像磁铁S/N极一样先互相排斥弹开，再翻转极性互相吸引归位。模拟真实磁场力学，卡片间存在斥力/引力交互。

## 技术实现

### 动画阶段
1. **初始态** — 卡片紧密堆叠在中心，标记为交替S/N极
2. **排斥阶段** — 滚动触发同极相斥，卡片以弹性力向四周弹射散开
3. **翻转阶段** — 卡片在空中翻转180°（极性反转），伴随磁场线动画
4. **吸引归位** — 异极相吸，卡片被"磁力"拉回网格位置，弹性着陆

### 核心技术
- GSAP ScrollTrigger scrub 驱动三阶段动画
- `elastic.out` 模拟磁力弹性
- CSS磁场线动画（径向渐变+旋转）
- `rotateY(180deg)` 翻转极性视觉

### ScrollTrigger 参数
```js
{ trigger: container, start: 'top 80%', end: 'top 10%', scrub: 1.5 }
```

## 视觉效果
- 红色S极 / 蓝色N极 双色主题
- 磁场线从极点辐射
- 排斥时卡片间有斥力波纹
- 翻转时颜色渐变过渡
- 归位时磁力吸附粒子拖尾
