# CardTimeAvalanche 雪崩连锁

## 效果描述
最顶部卡片坠落触发连锁反应，整个阵列雪崩式倒塌再重建。模拟雪崩的多米诺效应。

## 技术实现

### 动画阶段
1. **堆叠态** — 卡片金字塔状堆叠
2. **触发崩塌** — 顶部卡片失稳坠落，碰撞下层卡片
3. **连锁倒塌** — 从上到下逐层坍塌，碎石粒子飞溅
4. **重建归位** — 卡片从废墟中弹性重建回网格位置

### 核心技术
- GSAP ScrollTrigger scrub 驱动崩塌→重建
- stagger 从上到下连锁延迟
- elastic.out 弹性重建
- CSS粒子碎屑效果
