## 🎨 全新多图/多层级动画组件设计

基于您的需求（**多张图片 + 多层级组合**），我设计以下**8个全新高级组件**：

---

### 1. `CardImageDoubleExposure` — 双重曝光融合

> **从未有过的组合**：两张图片叠加曝光 × 滚动控制混合度 × 轮廓遮罩融合

**概念**：前景人像图片与背景风景图片叠加，滚动时前景人像的暗部区域逐渐透明，露出背后的风景。模拟胶片相机的双重曝光效果。

**多层级架构**：
```
Layer 1: 背景风景图 (全彩)
Layer 2: 前景人像图 (混合模式: multiply)
Layer 3: 轮廓遮罩层 (SVG 人像轮廓作为蒙版)
Layer 4: 颗粒噪点层 (模拟胶片颗粒)
```

**核心技术**：
- **SVG 轮廓提取**：使用 `feColorMatrix` + `feComponentTransfer` 提取人像暗部轮廓
- **动态混合模式**：`mix-blend-mode` 从 `normal` → `multiply` → `screen` 随滚动变化
- **暗部透明**：`mask-image` 绑定滚动进度，人像暗部先透明露出背景

---

### 2. `CardImageParallaxDepth` — 视差深度图

> **从未有过的组合**：深度图分离 × 多层视差 × 3D 倾斜

**概念**：一张图片配合深度图（depth map），将画面按深度分离成5-8个层级，每层独立视差移动，鼠标移动时产生3D倾斜效果。

**多层级架构**：
```
Layer 1: 远景天空 (z: -100px, parallax: 0.1x)
Layer 2: 远景山脉 (z: -60px, parallax: 0.3x)
Layer 3: 中景建筑 (z: -30px, parallax: 0.5x)
Layer 4: 近景树木 (z: 0px, parallax: 0.8x)
Layer 5: 前景人物 (z: 30px, parallax: 1.2x)
```

**核心技术**：
- **深度图采样**：Canvas 读取深度图灰度值，按阈值分离图层
- **多层位移**：每层根据滚动速度不同产生视差
- **3D 倾斜**：鼠标位置映射为 `rotateX/Y`，每层响应幅度不同

---

### 3. `CardImageBeforeAfter` — 前后对比滑动

> **从未有过的组合**：before/after 双图 × 滑动揭示 × 放大镜细节

**概念**：左右/上下分屏展示两张图片（如修图前后、季节对比、年代对比），中央有可拖动的分割线，拖动时揭示另一侧图片。鼠标悬停时放大镜显示细节对比。

**多层级架构**：
```
Layer 1: Before 图片 (左半/上半)
Layer 2: After 图片 (右半/下半, clip-path 动态裁剪)
Layer 3: 分割滑动条 (中央 draggable 手柄)
Layer 4: 放大镜层 (鼠标悬停时显示 2x 放大对比)
Layer 5: 标签指示器 (Before/After 角标)
```

**核心技术**：
- **clip-path 揭示**：`inset(0 ${100-p}% 0 0)` 动态裁剪 after 图
- **拖拽交互**：`pointer-events` + GSAP Draggable 实现顺滑拖拽
- **放大镜同步**：鼠标位置映射，两侧放大镜同步移动对比细节

---

### 4. `CardImageMorphTransition` — 变形转场

> **从未有过的组合**：图片 A → 液态变形 → 图片 B × 网格顶点变形

**概念**：图片A通过液态变形效果逐渐扭曲变形，最终定格为图片B。使用网格顶点变形（mesh warping）实现流体般的过渡。

**多层级架构**：
```
Layer 1: 图片 A (初始)
Layer 2: 变形网格层 (Canvas 网格顶点插值)
Layer 3: 图片 B (目标)
Layer 4: 液态波纹遮罩 (SVG 涟漪扩散)
```

**核心技术**：
- **网格变形**：10×10 网格顶点，GSAP 插值顶点坐标
- **液态扭曲**：`feDisplacementMap` 结合正弦波动
- **交叉淡化**：变形 50% 时开始图片B淡入

---

### 5. `CardImageKaleidoscopePrism` — 万花筒棱镜

> **从未有过的组合**：6面棱镜反射 × 旋转分割 × 多图拼接

**概念**：6张不同图片置于虚拟六棱镜的各面，旋转时各面内容相互反射、分割、重组，形成万花筒般的对称图案。

**多层级架构**：
```
Layer 1: 六棱镜底面 (6张图片三角形切片)
Layer 2: 反射层 (Canvas 实时反射计算)
Layer 3: 中心图案 (随旋转变化的主体)
Layer 4: 光晕层 (棱镜边缘彩虹折射)
```

**核心技术**：
- **三角形切片**：6张图片各切为 60° 扇形
- **镜像反射**：CSS `scaleX(-1)` 模拟镜面
- **旋转同步**：滚动控制整体旋转，各层速度不同

---

### 6. `CardImageCinematicWipe` — 电影划像转场

> **从未有过的组合**：多图序列 × 电影划像 × 遮罩路径动画

**概念**：3-5张图片序列，使用经典电影转场效果（水平划像、垂直百叶窗、圆形扩展、星形擦除）依次切换，模拟电影剪辑的节奏感。

**多层级架构**：
```
Layer 1-5: 图片序列 (堆叠)
Layer 6: 划像遮罩层 (SVG path 动画)
Layer 7: 电影边框 (上下黑边 + 颗粒)
Layer 8: 字幕层 (图片说明文字)
```

**核心技术**：
- **SVG 划像路径**：5种经典电影划像形状（线形、圆形、星形、百叶窗、菱形）
- **序列触发**：滚动进度触发不同图片切换
- **胶片颗粒**：Canvas 噪点叠加模拟电影质感

---

### 7. `CardImageLensReveal` — 镜头聚焦揭示

> **从未有过的组合**：多图层对焦 × 景深模糊 × 镜头光晕

**概念**：3张图片分别位于不同焦平面，初始全部模糊。滚动时模拟相机对焦过程：先对焦远景（背景清晰），再对中景，最后近景清晰，展现层次分明的景深效果。

**多层级架构**：
```
Layer 1: 远景图 (z: -100px, 初始模糊 blur(8px))
Layer 2: 中景图 (z: -50px, 初始模糊 blur(5px))
Layer 3: 近景图 (z: 0px, 初始模糊 blur(3px))
Layer 4: 镜头光晕 (径向渐变, 对焦时增强)
Layer 5: 对焦框 (中央对准框随对焦层变化颜色)
```

**核心技术**：
- **动态模糊**：`filter: blur()` 随滚动从清晰→模糊变化
- **焦平面切换**：滚动进度 0-33% 远景清晰，33-66% 中景清晰，66-100% 近景清晰
- **光晕增强**：对焦时该层光晕增强模拟镜头眩光

---

### 8. `CardImageHologramStack` — 全息图层堆叠

> **从未有过的组合**：RGB分色 × 多层偏移 × 全息扫描线

**概念**：一张图片分离为红/绿/蓝三个通道层，每层有轻微偏移产生色差效果。滚动时三层逐渐对齐合并，同时全息扫描线从上到下扫描，最终呈现完整的全息图像。

**多层级架构**：
```
Layer 1: 红色通道层 (偏移 x:-8px, mix-blend-mode: screen)
Layer 2: 绿色通道层 (无偏移, mix-blend-mode: screen)
Layer 3: 蓝色通道层 (偏移 x:+8px, mix-blend-mode: screen)
Layer 4: 全息扫描线 (横向移动的绿色扫描线)
Layer 5: 网格线叠加 (模拟全息底片网格)
Layer 6: 闪烁噪点层 (RGB随机闪烁)
```

**核心技术**：
- **通道分离**：CSS `filter: url(#red-channel)` 使用 `feColorMatrix` 提取单通道
- **色差偏移**：`translateX` 产生 RGB 分离效果
- **扫描线动画**：水平线从上到下扫描，经过处色差减小

## 🎯 我的推荐

**如果要实现最震撼的效果，我推荐以下顺序**：

1. **首推 `DoubleExposure`** — 双重曝光是摄影艺术经典，两层图片融合效果极具艺术感，且技术上使用 SVG 蒙版+混合模式，实现优雅
2. **次推 `LensReveal`** — 相机对焦的模拟非常独特，景深效果是摄影师最熟悉的视觉语言，三层图片的焦平面切换体验沉浸感强
3. **第三 `ParallaxDepth`** — 如果配合深度图，可以实现真正的伪3D效果，多层级视差是当前最前沿的网页视觉技术
