# AURELION 黑金紫电光高端品牌站设计方案（镜头脚本级）

## 1. 项目定位

**项目类型**：高端品牌官网（非电商、非社区）  
**目标**：用全屏段落级常驻动画建立“高价值、强记忆、可转化”的品牌感知  
**核心人群**：企业决策者、高净值客户、战略合作方  
**品牌气质**：权威、克制、未来、奢华

**一句话策略**：
> 用黑金紫电光的“电影化镜头叙事”，把品牌实力从“看到”升级到“被震撼并记住”。

---

## 2. 视觉总纲（已锁定）

### 2.1 视觉方向
- **主方向**：黑金紫电光
- **空间感**：深色背景 + 金属高光 + 紫电体积光 + 微粒子漂浮
- **风格关键词**：高端、秩序、未来感、力量感、仪式感

### 2.2 品牌色与材质

```scss
$bg-0: #050507;          // 深黑底
$bg-1: #0b0b12;          // 次深黑
$gold-1: #D9B46B;        // 主金
$gold-2: #8C6A2F;        // 暗金阴影
$purple-1: #7B3BFF;      // 主紫电
$purple-2: #B387FF;      // 紫电高光
$electric: #6A00FF;      // 电光强调
$text-main: #F5F2EB;     // 主文本
$text-sub: #B8B3A8;      // 次文本
$line-glass: rgba(255, 255, 255, 0.12);
```

### 2.3 字体与排版
- H1：56-88px，字重 700-900，字距 0.02em
- H2：36-52px，字重 600-700
- Body：16-18px，行高 1.7
- 数字与指标：使用等宽数字风格，强化“精密与可信”

## 3. 动画总纲（全屏段落级常驻）

### 3.1 全局原则
1. **每屏 100vh**，每屏都有独立动画主轴（主镜头）
2. **常驻动效**：屏内至少 2 层持续微动（环境层 + UI层）
3. **滚动即导播**：ScrollTrigger 控制镜头推进，而非简单入场
4. **统一节奏**：慢入场（权威）+ 中段张力（科技）+ 慢收束（高级）
5. **高动效但有秩序**：禁止“全元素同时动”，采用主次分层

### 3.2 动效节奏参数（建议）
- 主镜头过渡：`1.2s - 2.4s`
- 常驻微动循环：`4s - 12s`（linear / sine）
- 滚动 scrub：`1.2 - 2.0`
- 关键强调 easing：`power3.out`, `expo.out`, `back.out(1.4)`

### 3.3 全局层级（固定）
- L0：暗场渐变底 + 体积雾
- L1：金属几何/线框（低频运动）
- L2：主体内容（标题、卡片、数据）
- L3：电光粒子/扫描线（高频细节）
- L4：交互反馈（hover / click / magnetic）

## 5. 每屏“镜头脚本级”动效节奏

## S1 首屏宣言（0-100vh）

**目标**：3秒内建立“高端权威”第一印象。

**画面构成**：
- 背景：黑场 + 紫电云层 + 金属徽标纹理
- 中景：品牌主标题（两行）
- 前景：一句价值宣言 + 主CTA + 次CTA

**镜头脚本**：
- `00:00-00:01.2`：黑场中一道纵向紫电扫描，Logo 浮现
- `00:01.2-00:02.8`：主标题逐字高光揭示（非打字机，采用光刃扫过）
- `00:02.8-00:04.0`：CTA 从下方 40px 升起并伴随金边脉冲
- `00:04.0+`：常驻微动（紫电雾缓慢流动 + 金属线条 12s 循环）

**滚动联动**：
- 向下滚动前 30%：标题轻微后移（`z:-80` 视觉）
- 到 80%：首屏整体缩放到 `0.94`，让位 S2

---

## S2 品牌主张（100-200vh）

**目标**：把“品牌哲学”做成可感知的视觉秩序。

**画面构成**：
- 左：三条核心主张（权威、精度、前瞻）
- 右：几何金环 + 紫电轨迹

**镜头脚本**：
- `进入屏幕后 0-20%`：右侧金环从线框到实金过渡
- `20%-55%`：三条主张逐条点亮，当前条目高亮、其余降亮度
- `55%-85%`：紫电轨迹连接三条主张，形成闭环
- `85%-100%`：整屏轻微景深模糊，交接到 S3

**常驻动效**：
- 金环缓慢自转（`rotation: 360, duration: 24, repeat:-1, ease:'none'`）
- 文本边缘微闪（低频，避免炫目）

---

## S3 能力矩阵（200-300vh）

**目标**：展示“体系化能力”，而不是功能罗列。

**画面构成**：
- 3x2 能力卡阵列（战略、设计、技术、增长、数据、服务）
- 中央发光坐标轴

**镜头脚本**：
- `0-25%`：六卡由远到近分批归位（stagger）
- `25%-60%`：每张卡依次抬升并显示“高价值证据”（一句指标）
- `60%-90%`：中央坐标轴延展，连线所有卡片
- `90%-100%`：收束，保留最核心两卡高亮进入下一屏

**交互**：
- Hover 卡片：金边电流描边一圈 + 轻微磁吸

---

## S4 标杆案例（300-400vh）

**目标**：用“电影式案例轮播”传达实绩与格调。

**画面构成**：
- 全屏案例画布（每次主显 1 个案例）
- 右下角显示行业/成果/年份

**镜头脚本**：
- `0-15%`：案例A从暗场推入（镜头推近）
- `15%-45%`：案例A关键指标浮层上升，背景保持低速粒子
- `45%-60%`：镜头横移过渡到案例B（带紫电切幕）
- `60%-85%`：案例B同样流程
- `85%-100%`：定格最强案例，准备转入方法论

**常驻动效**：
- 画面边缘金属眩光缓慢游走（8s）

---

## S5 方法论流程（400-500vh）

**目标**：让客户感到“可控、可复制、可交付”。

**画面构成**：
- 五阶段流程带（洞察→策略→创意→实现→增长）
- 顶部里程碑节点

**镜头脚本**：
- `0-20%`：主流程线从左到右电流点亮
- `20%-75%`：每阶段到达时卡片弹出，展示输入/输出
- `75%-95%`：五个节点全部点亮，形成闭环回路
- `95%-100%`：相机轻微上拉，过渡到数据屏

**交互**：
- 点击节点：展开“可交付清单”抽屉（保留当前滚动位置）

---

## S6 数据与信任（500-600vh）

**目标**：建立“可信赖的高端品牌”证据链。

**画面构成**：
- 左：核心数字（交易规模、满意度、复购率、交付周期）
- 右：合作品牌墙（低调高光）

**镜头脚本**：
- `0-30%`：数字由粒子聚合成型（非机械跳数）
- `30%-65%`：品牌墙逐排点亮，出现“已服务行业”标签
- `65%-90%`：数字与品牌墙之间建立动态连线
- `90%-100%`：整体降噪收束，进入证言屏

**常驻动效**：
- 数字卡片图标微浮动（±4px）

---

## S7 客户证言（600-700vh）

**目标**：输出“高管口碑”，增强决策信心。

**画面构成**：
- 中央 3D 证言卡轮播
- 两侧为公司标识与职位信息

**镜头脚本**：
- `0-25%`：证言卡从景深虚化状态进入清晰
- `25%-70%`：3张证言卡依次旋转到中心位（每张停留 1.8s）
- `70%-90%`：评分与关键词（“专业”“可靠”“超预期”）分层浮现
- `90%-100%`：主证言卡放大 1.04 倍，衔接联系屏

**交互**：
- 点击任一证言卡：展开完整采访摘要

---

## S8 转化收口（700-800vh）

**目标**：以高端仪式感完成咨询转化。

**画面构成**：
- 左：一句收口主张 + 联系方式
- 右：高端表单（预约咨询）
- 背景：紫电粒子沿圆弧轨道汇聚到提交按钮

**镜头脚本**：
- `0-30%`：表单容器由线框转为玻璃金属质感
- `30%-75%`：字段逐一激活（focus 发光，不闪烁）
- `75%-100%`：提交按钮出现“能量蓄力”动效

**提交反馈**：
- 成功：金色环形扩散 + “Request Accepted”
- 失败：轻微横向抖动 + 精准错误提示（不破坏高级感）

## 7. 动效设计规范（必须遵守）

1. 不做“花里胡哨并行动画”，始终保证 1 个主镜头 + 2 个辅动效
2. 文本动画避免高频闪烁，保持可读性优先
3. 每屏第一焦点出现时间 < 1.5s
4. 屏与屏之间必须有“过渡态”（模糊/暗场/光刃）
5. CTA 交互反馈时间不超过 220ms

---

## 8. 性能与工程约束（高动效版本）

### 8.1 目标指标
- 桌面端：主流设备滚动过程保持 50-60fps
- 移动端：降级后保持 40fps+
- 首屏可见内容：优先加载，重资源延迟

### 8.2 强制策略
- 使用 `defineAsyncComponent` 对大模块懒加载
- 每屏创建独立 `gsap.context()`，离屏即 `revert()`
- 分类/路由切换统一执行 `cleanupAllAnimations()`
- 粒子层按设备分级：Desktop 100%，Tablet 60%，Mobile 35%

### 8.3 降级策略
- `prefers-reduced-motion`：关闭高频粒子与复杂3D，仅保留淡入与位移
- 低性能设备自动关闭景深与模糊滤镜

## 10. 验收标准

1. **品牌感**：黑金紫电光统一度 >= 90%
2. **动效感**：全站 8 屏均有常驻动效且主次清晰
3. **可读性**：标题 2 秒内可完整识别
4. **流畅性**：桌面端主要动效段无明显卡顿
5. **转化力**：联系屏 CTA 与表单提交链路完整可用

- 全屏段落级常驻动画提升沉浸感与停留时长
